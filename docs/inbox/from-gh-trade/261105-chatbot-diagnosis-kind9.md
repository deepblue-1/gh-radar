## 배포 순서 제약

gh-trade 서버 먼저 배포가 안전한가: 예 — kind 9 는 StrategyEventKind 에 값만 채우는 말미 사용이라 구 relay 는 모르는 kind 로 무시(예약 번호라 충돌 없음). 정확한 판정은 필드 목록 확정 뒤 구현 노트에서 다시 적는다.

gh-radar 쪽 순서는 항상 DB → relay → webapp 이고, push 가 곧 webapp 프로덕션 배포다.
