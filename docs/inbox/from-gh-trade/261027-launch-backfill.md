### 채운 규칙(해석)

- `result` "515": key=N 레인(09:00:30 NXT)은 재전송 대상 거부가 515 다. 로그 문구 "101" 은 재전송 대상 거부의 공용 표기라, 그 레인의 `retry_rc=515` 를 보고 "515" 로 바꿨다(서버 실로그 `[OpenArb] NXT 매수 거부 rc=515` 와 같다). `result_code` 도 515.
- `result_code`: 접수 0 · 101 · 515 · 기타는 브로커 원 거부 코드 문자열(KB `F083` 10건 · 교보 `E124` 9건 · `E127` 5건). 저널은 숫자 아닌 거부코드를 `-1000`(공용 표기)으로만 갖고 있어 브로커 거부 줄의 원 코드를 실었다.
- `retry`: 프로파일은 줄의 `retry=` 그대로. Q16 은 조각별 재전송 로그가 없어 예약 `결과` 줄 합계로 정해지는 경우만 — 이 기간 Q16 은 전부 `retries=0` 이라 0.
- `abandoned`: 그룹(Q16 예약 · 프로파일 레인 회차)의 `abandoned` 수와 「첫 발 101 · 515 이고 저널에 접수가 없는」 조각 수가 같을 때 그 조각을 1 로 — 이 기간 전 그룹이 맞아떨어졌다(Q16 101 47건 = 1, 나머지 0).
- `round`: 라운드 index(0 · 1 · 2, 셋째 이후 2). Q16 실제 지연은 날짜별로 다르다 — 10/12 은 간격 도입 전(−305/−303/−302µs 처럼 붙어 나감), 10/13 ~ 10/21 은 +10/+20µs, 10/22 부터 +10/+30µs(데이터로 확인). A · N 은 전부 0.
- `queued_id`: A · N 은 판정 key 문자("A"/"N"). key=N 레인의 매도 행(A 둘째 다리)도 queued_id 는 레인 key "N" 이고 profile 만 "A" 다.
- `fire_base`: A 는 기동 줄 `KRX > NXT 발사 27000ms` → "09:00:27". 10/27 A 코스피 wire 3(idx 6)은 09:00:29.5 재확인 회차 조각이라 `sent_rel_us=2500001`(+2.5초)이 정상이다.
- 10/26 N 은 사전 발사(pre-trigger, −20ms 대)라 rel 이 −20,1xx µs 로 크게 음수인 것이 정상이다.
- `accept_time`: 재전송 조각이면 마지막 주문번호의 것이다(`order_no` 도 마지막 번호).
