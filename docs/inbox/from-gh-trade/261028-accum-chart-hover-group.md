**규칙**

1. 씨앗 = 지금처럼 마우스 세로선이 지나는 원(가로로 |mx − cx| ≤ r + 2) 중 마우스와 세로로 가장 가까운 원.
2. 묶음 = 씨앗 + 씨앗과 **직접** 닿는 보이는 원(중심 거리² ≤ (r씨앗 + r)², 화면 px 기준). 닿은 원의 닿은 원은 넣지 않는다(사슬 금지).
   매수/매도·KRX/NXT 는 가리지 않는다. 화면 기준이라 확대하면 갈라지고 축소하면 묶인다. 보이는 범위 밖·가격 0 원은 대상 아님.
3. 정렬 = 시간순(같으면 인덱스순). 묶음 크기 1 이면 지금 한 원 툴팁 그대로.
4. 강조 = 묶음 원 전부에 지금의 호버 고리(gh-trade hoverRim, 1.5px). 묶음(2개 이상)이면 **고른 원만 굵은 고리**(gh-trade 2.5px 검정) — 툴팁 첫 줄이 어느 원인지 보이게. 원 하나면 지금 고리 그대로.
5. 툴팁 — 원 하나면 지금 한 원 툴팁 그대로. 묶음이면 3줄:
   - 1줄 = **고른 원**: 지금 한 원 툴팁 줄과 똑같다(시각·방향·금액@가격 + 그 시점 맥락 조각 당일 순매수·누적 / 등락률 / 평단 대비)
   - 2줄 = 묶음 요약: `묶음 N건 HH:MM:SS ~ HH:MM:SS`(같은 초면 하나) · 방향 · `가격 {첫} → {끝} (±0.00%)`(첫 주문가 대비 끝 주문가)
     - 방향: 한쪽만이면 `팀 매수 N건 합계 0.00억`(매도도 같은 꼴), 섞이면 `팀 매수 N건 0.00억 · 팀 매도 M건 0.00억`, NXT 가 하나라도 있으면 끝에 ` (NXT 포함)`
   - 3줄 = `큰 주문 ` + 금액 내림차순(같으면 시간순) 상위 3개 `0.00억@가격` 을 ` · ` 로, 매수·매도가 섞였을 때만 앞에 `매수 `/`매도 `
   - 묶음 쪽에는 맥락 줄을 **넣지 않는다** — 고른 원 줄에 이미 있고, 마지막 주문 시점 맥락을 또 넣으면 기준 시각이 다른 같은 항목이 두 번 나온다.
6. 씨앗이 바뀌면(같은 묶음 안에서 다른 원으로 옮겨도) 툴팁 첫 줄·굵은 고리가 바뀌니 다시 그린다.

예시(묶음):

```text
10:12:34 팀 매수 0.85억 @ 12,350 · 당일 순매수 +3.20억 · 누적 +5.10억 · 등락률 +4.12% · 당일 평단 대비 +1.05%
묶음 7건 10:05:12 ~ 10:18:40 · 팀 매수 5건 3.10억 · 팀 매도 2건 0.90억 · 가격 12,200 → 12,400 (+1.64%)
큰 주문 매수 1.20억@12,300 · 매수 0.85억@12,350 · 매도 0.60억@12,380
```

## 확인 방법
