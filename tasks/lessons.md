# Lessons

현행 규칙 한 줄씩. 전문은 tasks/lessons-archive.md(같은 날짜·제목). 새 교훈은 여기 한 줄 + archive 에 서사.

- **2026-04-16 dev 포트** — 포트·호스트·URL 설정은 `./dev.sh` 를 먼저 읽고 그 값만 쓴다(webapp 3100); 기본값 3000 가정 금지.
- **2026-05-12 KRX 승인** — KRX OpenAPI 는 endpoint 별 승인; 새 endpoint 쓰는 phase 는 첫 wave 에 401 사전 확인 task.
- **2026-06-09 양쪽 극단 검증** — 입력 규모가 시장 상황으로 10배 변하는 fix 는 양쪽 극단에서 검증; `.in()` 대량 조회는 500개 청크 + error 처리; 폐기 가설은 반증 전엔 「보류」.
- **2026-06-09 Turbopack re-export** — `packages/shared/src/index.ts` re-export 는 확장자 없이; 첫 런타임 값 re-export 추가 시 `pnpm -F webapp dev` 로 페이지 확인.
- **2026-06-09 인계 PASS/FAIL** — 인계 노트의 통과/실패 주장은 직접 돌려 확인; 회귀 의심은 pre-change baseline 과 분리; deferred 기록은 파일:라인 + 실제 assertion.
- **2026-06-09 배포 완결성** — 새 라우트·스키마를 노출하는 모든 서비스(server·webapp·worker)를 배포하고 완료 전 prod URL 을 curl; verifier 는 배포 revision 을 안 본다.
- **2026-06-10 응답 계약 드리프트** — 프론트 `apiFetch<T>` 와 서버 `res.json` 은 같은 shared 타입이거나 계약 테스트 1개; 한쪽 mock 은 계약 증명 아님; `error.tsx` 는 렌더 중 throw 신호.
- **2026-06-10 db-max-rows** — 입력 청크(414)와 결과 행 페이지네이션(db-max-rows 1000)은 다른 축 — 여러 부모 `.in()`/`.eq()` 는 `.range()` 로 끝까지; 합계가 1000 배수면 절단 의심; mock 에도 캡.
- **2026-06-10 정량 주장 실측** — 커버리지·비율 등 정량 주장은 말하기 전에 직접 집계(`workers/master-sync/.env` probe); subagent 의 「대부분」을 % 로 승격 금지.
- **2026-06-10 커밋 범위** — 승인은 pathspec 없는 `git status --short` 전체를 보여주고 스테이징은 보여준 경로만; scoped 미리보기 뒤 `git add -A` 금지.
- **2026-06-11 Phase 11** — AskUserQuestion 설명은 question 본문에; 점수 설계는 「무엇을 재는가」부터; 대면 수치는 raw, 내부 점수는 strength 로 분리.
- **2026-07-07 시간창 확장** — cron 확장·갱신 커버리지 축소 시 하류 쿼리가 신선도 조건 없이 누적 테이블을 읽는지 grep; 새 시간대 첫 라이브 사이클을 확인한다.
- **2026-07-13 주기 변경** — 스케줄·주기·임계값 리터럴은 리포 전체 grep 해 설정처(deploy)와 검증처(smoke·test)를 한 커밋에서 갱신.
- **2026-07-20 stale 응답** — 외부 시세 배치는 「비었나」 뿐 아니라 「어제와 같나」(표본 ≥30·일치 ≥0.8 → skip)를 검사; 비교 조회 error 는 fail-fast.
- **2026-09-05 UI/IA 결정 순서** — 결정 목록을 순서대로 적고 다이얼로그당 질문 1개; 목업은 요청한 안만; 우리 코드 선택값을 「불가」 근거로 쓰지 마라; 390px 모바일 먼저.
- **2026-09-06 표면 안 시각 결함** — 손보는 화면 안의 줄바꿈·잘림·겹침은 묻지 않고 고치고 한 줄 보고; 왕복은 취향·타표면만; 폭은 Playwright 실측.
- **2026-09-07 min-w-0** — 반응형 그리드/플렉스 자식은 `min-w-0` 기본(`display: contents` 래퍼는 자식에); 잘림 진단은 의심 요소 실측 폭으로(조상 `overflow-hidden` 이면 scrollWidth 0); 현재가 표시는 폭 미점유.
- **2026-09-08 필터 완화** — 넓히기 전에 「통과하게 될 전부」를 세고 하류 분류·집계를 따라간다; 모르는 코드에 기본 신원(`'주권'`) 금지 — sentinel `'미확인'`; 주석의 외부 전제는 근거 아님; 블랙·화이트 둘 다 점검.
- **2026-09-08 목업 게이트** — 목업 open ≠ 검토; 사용자 답 전엔 checker·UI-SPEC 확정·커밋·push 금지; `commit_docs: true` 는 커밋 허가 아님; 「열어 두었다」를 완료처럼 쓰지 마라.
- **2026-09-13 단순 설정** — 설정·권한 문제는 「가설 1 → 확인 1회 → 수정」; 권한 차단 시 규칙 한 줄만 제시, 설명 반복 금지.
- **2026-09-14 preview 안 보임** — AskUserQuestion 옵션 `preview` 는 안 보인다; 예시·비교는 question 텍스트에 [A]/[B] 로.
- **2026-09-16 선택지 기준** — 옵션이 갈리는 기저 메커니즘을 한 줄로 먼저; 각 옵션이 건드리는 범위를 근거와 함께; 상위집합 관계도 명시.
- **2026-09-16 executor 독서량** — 이미 읽은 구조 정보(줄 번호·앵커·실측)를 프롬프트에 싣는다; 대형 파일 여럿이 필요한 태스크는 쪼개거나 직접 실행; 잘린 방식 그대로 재시도 금지.
- **2026-09-16 커널만 반영** — VM 설정은 생성물(저장소 → 메타데이터 → startup.sh) 경유; 재부팅·재적용 전 파일↔커널 대조(`nft -c`·`iptables -S`); sha 가 바뀌면 끝까지 좁힌다.
- **2026-09-18 목업은 플랜 전** — 화면에 새로 보이는 것이 하나라도 있으면 planner 전에 HTML 목업 → 답을 CONTEXT D-xx 에 박제; 전제 불일치도 같은 목업에; 도구 `frontend:false` 는 참고값.
- **2026-09-23 한글 보고** — 사용자 대면 텍스트는 표·헤더까지 전부 한글; 보내기 전 첫 문장 언어 확인.
- **2026-09-23 planner 과잉** — 원인이 특정됐고 상수 몇 줄이면 planner 없이 직접(gsd-fast); 서브에이전트는 탐색이 필요한 일에만.
- **2026-09-23 목업 없는 UI** — 보이는 것이 바뀌면 아무리 작아도 standalone HTML 목업 승인 먼저; 컨트롤 교체는 자리·정렬·여백까지 설계.
- **2026-09-23 relay 배포 HEAD** — 배포 직전 `git status -sb` 로 ahead·수정 파일 확인; 남의 커밋이 있으면 내 커밋의 detach worktree 에서 배포; 배포 게이트 걸린 남의 커밋은 안 내보낸다.
- **2026-09-23 복합 명령 차단** — 허용 규칙 있는 배포·적용 명령은 단독 명령으로(cd·파이프·&& 금지); 거부되면 규칙 모양과 명령 모양부터 대조.
- **2026-09-23 「안 된다」 오독** — 「X 가 안 된다」는 X 가 되면 보일 상태를 먼저 한 줄로 확인; 이연 항목의 해법을 지금 의도로 삼지 마라(거래소 토글 = 키 전환).
- **2026-09-23 격리 sentinel** — 순차 quick 은 `--force-isolation none` → `.gsd/dispatch-isolation-sentinel.json` cat → 바로 Agent(); plain query 재확인 금지.

- **2026-09-25 단계 경계 멈춤** — GSD 명령 하나가 끝나면 요약 + 「`/clear` 후 다음 명령」 안내만; 체이닝은 `--chain`/`--auto` 명시 때만; 무거운 에이전트 전엔 예상 시간.
