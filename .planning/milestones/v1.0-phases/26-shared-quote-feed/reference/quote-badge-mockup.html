배지 2축 목업 — 「시세」 · 「주문」 (Phase 26 · D-14)

채택: 안 B 점형 · 2026-10-01 · 수정 없음 — 메모 ①~⑤ 는 권장 기본값(① (b) 상수 「서버 연결 중…」 · ② 재연결 중 마지막 quoteState 유지 · ③ 한도는 title 만 · ④ My page 톤 점). 안 A 행은 기록으로 남겨 두었습니다(data-rejected="true"). 26-14 정본은 파일 머리 주석.

두 상태줄(/trading 작업대 · My page)에 「시세」 필이 새로 서고 기존 「DMA」 필은 「주문」 으로 바뀝니다. 시세 공유 연결이 끊기면 시세 필만 적색으로 바뀌고, 오른쪽 호가 조각의 숫자는 흐려지지 않습니다(D-04). 안 A 문구형과 안 B 점형을 라이트/다크 × 상태 5종으로 나란히 비교하고, 맨 아래에 폰 폭 360px과 프레임→필 매핑 표를 둡니다. 목업 폭은 데스크톱 실제 상태줄보다 좁습니다(좁은 쪽 기준으로 줄바꿈을 봅니다).

결정 전에 볼 메모

  1. ① 「주문 서버 연결 중…」 접두 겹침 — 라벨 상수를 그대로 「주문 서버 연결 중…」 으로 바꾸면 필이 「주문 주문 서버 연결 중…」 이 됩니다. 두 안 모두 화면에는 접두 「주문」 + 굵은 「서버 연결 중…」(읽으면 「주문 서버 연결 중…」)으로 그렸습니다. 방법은 둘 — (a) 상수 「주문 서버 연결 중…」 + 「라벨이 『주문 』 으로 시작하면 접두 생략」 규칙, (b) 상수를 중립 「서버 연결 중…」 으로 두고 접두 「주문」 이 붙게 함(보이는 글자는 같음 · 예외 규칙 없음). connecting 은 브라우저→relay 소켓(시세 · 주문 둘 다 싣는다) 첫 시도라 (b) 를 권합니다. 답에 a/b 를 적어 주세요 — 없으면 (b).
  2. ② 브라우저 소켓 자체가 끊긴 재연결(④ · status connecting/reconnecting 이 브라우저 쪽일 때) — 이때 시세 필은 마지막으로 받은 값을 계속 보입니다(quoteState 는 재연결에서 지우지 않음). 호가는 기존 isStale 흐림이 켜집니다(이번 변경 아님). 이 경우 시세 필을 회색 「시세 —」 로 낮출지는 답에 적어 주세요 — 없으면 목업대로(마지막 값 유지) 갑니다.
  3. ③ 구독 한도 표시 수명 — 스토어는 최신 1건만 보관하고 스스로 지우지 않습니다. 안 A 칩은 클릭하면 닫히고 다음 거부 때 다시 서는 것으로 제안합니다(안 B 는 title 문구가 남음).
  4. ④ My page 점 색 — 지금은 늘 회색입니다. 두 안 모두 작업대와 같은 톤(초록 · 회색 점멸 · 적색)을 씁니다.
  5. ⑤ since 표기 — KST HH:MM:SS. since 가 없는 down 은 「시세 갱신 없음」(A) / 「시세 멈춤」(B).
