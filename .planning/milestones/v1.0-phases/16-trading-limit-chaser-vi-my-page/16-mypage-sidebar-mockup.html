시나리오:
D-24(c) 추가 목업. /me 세로 순서 = 전략 현황 → (계좌별) 미체결 → 잔고(D-20). 계좌가 2개 이상이면 계좌 섹션을 세로로 반복하고 계좌번호는 전체 표시(D-21 · Phase 15 D2). 미체결·잔고 표는 orderbook/account-panel.tsx 재사용.
사이드바: 홈 / 종목검색(상승률 상위·테마·관심종목) / 트레이딩(상따 + 등록 전략 목록 · VI) / My page / AI 애널리스트. 그룹 헤더는 클릭 불가 소제목, 항상 펼침(D-16). DMA 매핑 없음·비로그인이면 트레이딩·My page 항목을 숨긴다(D-19) — 아래 「사이드바 상태 3종」 참조.
신규 토큰 0개. D-24(b) 준수. 목업 초안의 --warn(주황)은 globals.css 에 존재하지 않아(실측) 사용하지 않는다. 「대기 / 중지 / 발주됨」은 중립(--muted/--muted-fg) + 도트 형태(채움·속빔)로 구분하고, 방향 의미가 있는 상태만 --up(매수)·--down(매도)을 쓴다. 색 없이도 텍스트·형태로 읽힌다(WCAG 1.4.1).
R2 반영 — ① 모바일 미체결·잔고는 2줄 카드 행. 이전에는 .acct-grid 자식 div 에 min-width:0 이 없어 표의 콘텐츠 최소폭(미체결 439px · 잔고 444px)만큼 자식이 부풀었고, 프레임의 overflow-x:hidden 아래에서 스크롤이 아니라 잘림으로 나타났다(lessons.md). ② 사이드바 전략 항목은 글자 없이 동그라미 2개(좌 매수 --up · 우 매도 --down, ON=채움/OFF=속빔)만 남겼다.
전체 비활성화(DisableStrategiesReq 14, key="")는 전략 현황 카드 하단에 두고 확인 다이얼로그 필수(D-09). 기본 포커스는 「닫기」.
