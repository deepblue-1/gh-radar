잔량진행률 목업 — 상따창 미체결 그리드

대기 중인 매수 주문이 체결까지 얼마나 남았는지를 미체결 목록 안에 넣는 세 가지 안입니다. 숫자는 기획서 예시(체결예상 1,100,000 · 현재 누적 1,088,000 → 12,000주 남음, 88%)와 형식 설명용 값입니다. 진행률은 서버가 계산해 미체결 상태와 함께 내려주고 클라이언트는 그리기만 합니다.

A 컬럼 추가 — 「진행률」 「남음」 두 열

기존 열은 그대로 두고 오른쪽에 막대+% 한 열과 남은 거래량 한 열을 붙입니다. 행 높이는 그대로라 목록 밀도가 유지됩니다. 상따 대기 주문이 아닌 행(수동·VI·매도)은 빈칸입니다.

B 2줄 행 — 주문 밑에 진행 문장 한 줄

대기 주문 행만 2줄로 키우고, 둘째 줄에 기획서 문장 「줄서기매수 · 체결예상까지 12,000주 남음 [막대] 88%」 를 그대로 넣습니다. 진행 정보가 없는 행은 1줄 그대로입니다. 열 폭은 변하지 않습니다.

대안 조합

  • A 의 「진행률」 열만 넣고(막대+%), 남은 거래량은 툴팁이나 로그 탭에서 보는 절충안.
  • C 는 구현이 가장 가벼워 첫 배포용으로 두고 B 로 옮기는 경로도 가능.
공통 전제: 진행률·남은 거래량·체결예상 누적은 서버가 계산합니다(누적거래량과 상한가 잔량은 서버 시세에만 있음). 미체결 상태 푸시에 필드를 덧붙이면 WinForms 와 gh-radar 가 같은 값을 그립니다. 첫 체결이 나거나 취소되면 진행 표시는 사라집니다.
