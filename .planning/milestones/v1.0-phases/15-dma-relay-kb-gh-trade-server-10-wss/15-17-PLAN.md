`SessionNotReady()` = 409 `SESSION_NOT_READY` "호가창을 먼저 열어 주세요"
`OrderTimeout()` = **502** `ORDER_TIMEOUT` "접수 응답이 늦어지고 있어요" — **"실패했어요"라고 쓰지 않는다**(Pitfall 9 / UI-SPEC C9). 상태코드는 5xx 로 두되 code 로 구분한다.

`AccountNotAllowed()` = 403 `ACCOUNT_NOT_ALLOWED` "선택한 계좌로는 주문할 수 없어요"

**`server/src/schemas/orders.ts`**: `OrderPostBody = z.object({ code: z.string().regex(/^\d{6}$/), accountNo: z.string().min(1).max(12), exchange: z.enum(["KRX","NXT"]), side: z.enum(["B","S"]), orderType: z.enum(["N","C"]), orgOrderNo: z.string().min(1).optional(), qty: z.number().int().positive(), price: z.number().int().positive() })`. **금액·수량 상한을 넣지 않는다**(D-20 — 사용자 결정). `orderType === "C"` 일 때 `orgOrderNo` 필수를 `superRefine` 으로 강제한다. `isin` 은 **바디에서 받지 않는다** — 서버가 `stocks` 에서 조회한다(브라우저 입력을 신뢰하지 않음). `OrderListQuery = z.object({ date: z.string().regex(/^\d{4}-\d{2}-\d{2}$/).optional() })`.
