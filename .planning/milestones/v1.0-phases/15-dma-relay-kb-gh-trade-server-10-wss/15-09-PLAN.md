## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PostgREST(anon/authenticated) → dma_credentials / dma_orders | 브라우저가 Supabase 에 직접 접근할 수 있는 표면. 여기서 막지 못하면 자격증명·주문 이력이 노출된다 |
| service_role(relay/server) → 두 테이블 | RLS bypass. 애플리케이션이 `WHERE user_id` 명시 필터로 소유권을 강제한다 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-05 | Information Disclosure | `dma_credentials` | mitigate | RLS 활성 + **정책 0개**(default deny) + `REVOKE ALL FROM PUBLIC` + **`REVOKE ALL FROM anon, authenticated` 명시**(플랫폼 auto-grant 회귀 방어) + `GRANT TO service_role`. 비밀번호는 평문이 아니라 AES-256-GCM 암호문이고 키는 DB 밖(Secret Manager) |
