3. **종목명 패턴 fallback 금지** — home-sync `isExcludedProduct` 의 `/ETN|ETF|인버스|레버리지/i`
   선례가 있으나 그 fallback 은 `570127` 오분류 대응이었다. 실측상 현재 `570127` 은
   `security_group='ETN'` 으로 정정되었고, 이름에 ETN/ETF/인버스/레버리지를 포함하면서 group 이

4. **`limit 20` · `order name asc` · `MASTER_COLS` · `sanitizeSearchTerm` 은 손대지 않는다** —

   PostgREST 는 select 하지 않은 컬럼으로도 필터할 수 있으므로 `MASTER_COLS` 에 `security_group`
