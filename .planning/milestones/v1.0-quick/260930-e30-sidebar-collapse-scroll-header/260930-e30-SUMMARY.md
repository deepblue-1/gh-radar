## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Tailwind v4 에서 `transition-[transform,…]` 로는 translate 전환이 안 됨**
- **Found during:** Task 2
- **Issue:** Tailwind v4.2 의 `translate-*` 는 `transform` 이 아니라 CSS `translate` 속성을 씁니다. 플랜대로 `transition-[transform,opacity]` 를 두면 헤더가 전환 없이 순간 이동합니다.
- **Fix:** 전환 목록을 바꿨습니다.
  - header-bg: `transition-[translate]`
  - 로고·nav: `transition-[translate,opacity]`
  - 햄버거: `…,translate`
  - 이 이유를 app-header 주석에 적었습니다. B4 는 `transform` 과 `translate` 가 둘 다 none 인지 봅니다.
- **Commit:** `0df77a97`

**2. [Rule 1 - Test 정확성] reduced-motion 판정을 duration 0s 에서 `transition-property: none` 으로 변경**
- **Found during:** Task 2 (B6)
- **Issue:** v4 의 `motion-reduce:transition-none` 은 `transition-property: none` 이고 duration 은 250ms 로 남습니다. 그래서 플랜의 「모두 0s」 단언은 동작이 올바른데도 실패합니다.
- **Fix:** B6 는 이제 보통 상태에서 property ≠ none · duration ≠ 0 인지 확인합니다. reduce 상태에서는 햄버거·header-bg·로고의 property 가 전부 none 인지 확인합니다.
- **Commit:** `0df77a97`

**3. [Rule 3 - Blocking] e2e D2 창 스크롤 확보용 스페이서**
- **Found during:** Task 2
- **Issue:** 390x640 홈 픽스처는 로딩 시점에 따라 스크롤 여유가 0~257px 뿐이라 300 을 만들 수 없었습니다.
- **Fix:** `scrollTo300` 이 main 과 헤더가 보이기를 기다린 뒤 main 끝에 2000px 스페이서를 붙입니다(떨어지면 다시 붙임). 그래도 부족하면 여유 px 를 담은 메시지로 실패합니다. 판정 대상은 본문 내용이 아니라 창 scrollY 입니다.
- **Commit:** `0df77a97`

**4. [Rule 3 - Blocking] home.spec 「접기」 조회를 exact 로 변경**
- **Found during:** Task 2 회귀(home.spec 인라인 확장 케이스)
- **Issue:** 새 토글의 접근 이름 「사이드바 접기」(CONTEXT D1 잠금 문구)가 Playwright 기본 부분 일치 `getByRole('button', { name: '접기' })` 에 함께 잡혀 strict 모드 위반이 났습니다.
- **Fix:** 해당 조회 한 곳에 `exact: true` 를 붙이고 이유를 주석으로 남겼습니다. 불변식 테스트 완화가 아니라 조회 정밀화입니다. e2e 와 src 에서 같은 충돌을 전수 grep 했고, 다른 곳은 `▴/▾` 접미나 RTL 기본 exact 라 영향이 없었습니다.
- **Commit:** `0df77a97`
