①사이드바 접기 / 펼치기 — 데스크톱(≥1024)

토글 버튼은 모바일 햄버거와 같은 자리(헤더 왼쪽, 로고 앞)에 둡니다. 모바일(<1024)은 지금처럼 햄버거→드로어라 변화 없음. 접힘 상태는 브라우저에 기억(새로고침·페이지 이동 후에도 유지).

A. 아이콘 레일로 접기 (240 → 64px)

아이콘만 남고 라벨·전략 하위목록은 숨김. 트레이딩 아이콘에 켜진 전략 수 배지, 마우스를 올리면 이름 툴팁. 접어도 메뉴 이동은 한 번에 됩니다.

↑ 헤더 왼쪽 패널 아이콘을 눌러보세요

B. 완전히 숨기기 (240 → 0)

본문이 전체 폭을 씁니다. 메뉴를 쓰려면 다시 펼쳐야 합니다(또는 ⌘/Ctrl+B 같은 단축키를 추가할 수 있음).

↑ 헤더 왼쪽 패널 아이콘을 눌러보세요

②스크롤하면 헤더가 사라지고 원형 햄버거만 — 모바일(<1024) · 앱

햄버거가 있는 화면에만 적용합니다(데스크톱은 사이드바가 있어 헤더 유지). 헤더 배경·로고·검색 아이콘이 위로 빠지고, 햄버거는 그 자리에서 반투명 원형 배경을 입고 떠 있습니다.

상태: 헤더 보임
정지 화면: 스크롤된 상태
  1. 원형 버튼은 44px(터치 타깃 유지) 반투명 + 흐림(유리 느낌), 그림자로 본문과 분리. 좌측 8px·상단 8px 띄움(현행 헤더 햄버거는 화면 끝에 붙어 있어 원형이면 잘려 보임).
  2. 앱에서는 상태바(시계) 띠는 흐린 배경을 유지 — 헤더가 빠져도 본문 글자가 시계 밑으로 비치지 않게.
  3. 상따·작업대 알림 토스트(헤더 바로 아래 고정)는 헤더가 숨어도 같은 자리 유지.
  4. 드로어를 연 상태·키보드 포커스 중에는 헤더가 강제로 보이게 유지.
