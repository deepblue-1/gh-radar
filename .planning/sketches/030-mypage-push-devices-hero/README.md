# Sketch 030: /me 알림 받는 기기 자리

## Design Question
설정 탭은 매매 설정(상따 기본설정)만 남긴다. 돌파 알림음(「이 기기」 카드)은 쓰지 않으니 숨기고,
「알림 받는 기기」 카드는 설정 탭이 아닌 상단 계정 카드(히어로) 근처로 옮긴다. 어떤 모양으로?
또 푸시는 체결만이 아니라 접수 · 체결 · 거부 · 자동 취소 · 자동매도 시작/완료(Phase 40 7종)라 「이 기기 체결 알림」 이름과 설명을 바꾼다.

같이 반영: 탭 순서 현황 → 잔고 → 주문 → 손익 → 설정.

## Variants
- **A: 계정 카드 종 아이콘** — 테마 · 로그아웃 옆 40×40 종 버튼(켜짐이면 초록 점). 폰 바텀 시트 / 데스크톱 팝오버에 이 기기 스위치 + 다른 기기 목록. 화면 변화 최소.
- **B: 계정 카드 안 알림 줄** — 프로필 아래 hairline + 「종 · 매매 알림 · 이 기기 켜짐 · 다른 기기 2대」 + 스위치 바로. ⌄ 로 카드 안에서 기기 목록 펼침. 상태가 늘 글자로 보임(+52px).
- **C: 히어로 + 알약** — 계정 카드를 히어로로(폰 가운데 정렬 아바타 64), 아래 알약 「● 매매 알림 켜짐 · 라이트 · 로그아웃」. 알림 알약 → 시트/팝오버. 세로 가장 김.

## 문구 후보
- 이름: 「매매 알림」(권고) / 「주문 알림」 / 「주문·체결 알림」
- 설명(앱): 「주문 접수 · 체결 · 거부 · 자동 취소와 자동매도 시작 · 완료를 이 기기로 알려 드려요.」
- 설명(PC 웹): 「… 소식을 받을 기기예요. 켜기는 그 기기의 GH Trade 앱에서 해요.」

## What to Look For
- 앱에서 이 기기 알림이 꺼져 있다는 걸 바로 알아채는가(A 점 하나 vs B 글자 vs C 알약 글자)
- 켜기까지 몇 번 누르나(A·C 2번 · B 1번)
- PC 웹(스위치 없음 · 목록만)에서도 자연스러운가
- 계정 카드 높이 증가가 탭 위 공간을 얼마나 먹나(폰)

## Decision (2026-11-07)
- **A 계정 카드 종 아이콘** 채택 — 테마 · 로그아웃 옆 40×40 종 버튼(이 기기 켜짐이면 초록 점). 폰 바텀 시트 / 데스크톱 팝오버에 이 기기 스위치 + 다른 기기 목록. 설정 탭에서 「알림 받는 기기」 카드 제거.
- 이름 **「매매 알림」** — 스위치 「이 기기 매매 알림」 · 설명(앱) 「주문 접수 · 체결 · 거부 · 자동 취소와 자동매도 시작 · 완료를 이 기기로 알려 드려요.」
- 돌파 알림음(「이 기기」 카드)은 숨기고 **소리 재생도 끈다**(저장값과 무관하게 꺼짐).
- 탭 순서 현황 → 잔고 → 주문 → 손익 → 설정.
