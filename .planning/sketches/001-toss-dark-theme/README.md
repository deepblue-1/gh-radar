# Sketch 001: Toss Dark Theme

## Design Question
사용자가 제공한 토스증권 다크 스크린샷 6장(홈·차트·호가/주문·종목정보·리서치·옵션)의 인상을
gh-radar 종목상세(`/stocks/[code]`) 와 트레이딩 작업대(`/trading`)에 입히면 어느 강도가 맞는가.

## How to View
open .planning/sketches/001-toss-dark-theme/index.html

상단 바: 변형(현재/A/B/C) × 화면(종목상세/트레이딩) × 테마(다크/라이트) × 폭(폰 390/데스크톱 1280). 모든 변형이 같은 DOM 을 쓰고 토큰만 다르다.

## 라이트 모드 (2차 — 사용자 지적 반영)
B·C 의 여백·radius·숫자 서체·행 높이·섹션 띠·CTA 는 테마 공통 구조라 라이트에도 그대로 적용된다. 따라서 B·C 는 라이트 색 토큰을 토스 라이트(TDS grey 스케일 · #191f28 / #f2f4f6 / #3182f6 / #f04452)로 함께 정의했다.
- B 라이트: 종목상세 = 흰 바탕 + #f2f4f6 띠, 작업대·호가주문 탭 = #f2f4f6 면 + 흰 카드 (흰 위 흰 카드는 경계가 사라지므로)
- C 라이트: 두 화면 모두 #f2f4f6 바탕 + 흰 카드
- A 는 `.dark` 만 바꾸므로 라이트가 현재와 같다

## Variants
- **현재** — 프로덕션 `.dark` 토큰(oklch→hex). 순흑 #020202 · 1px 테두리 카드 · Geist Mono 숫자.
- **A: 토큰만 교체** — 레이아웃·테두리·radius 유지, 색만 토스 팔레트(#17171c/#202027/#2c2c35, 상승 #f04452, 하락 #3485fa). globals.css `.dark` 한 블록 수정으로 끝.
- **B: 토스 풀 스킨** — 테두리 0, 명도 단계로 면 구분, radius 16~20, 종목상세 섹션은 풀폭 면 + 짙은 띠, 숫자 Pretendard 굵게, 알약 세그먼트, 사다리 행 44px, 폰 하단 「주문하기」 CTA(제안).
- **C: 하이브리드** — 토스 팔레트 + 무테두리 둥근 카드(16) + 알약 세그먼트, 트레이딩 밀도(Geist Mono · 사다리 28px · 입력 38px)는 유지.

## What to Look For
- 바탕 명도: 순흑(현재) vs #17171c(토스) — 장시간 보는 트레이딩 화면에서의 피로감
- 테두리 유무: 트레이딩 카드 2~3단 격자에서 카드 경계가 명도차만으로 충분히 읽히는가 (B/C)
- 숫자 서체: Pretendard 굵게(B, 토스식) vs Geist Mono(현재/A/C) — 호가 사다리 자릿수 정렬
- 사다리 밀도: B 44px 행은 폰에서 보이는 호가 수가 절반 가까이 준다
- 종목상세 섹션 구분: 카드(현재/A/C) vs 풀폭 띠(B)
