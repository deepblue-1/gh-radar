# Sketch 005: `/search` 페이지 · `/me` 계정 카드

## Design Question
Phase 21 D-07(전용 `/search` 페이지 신설) · D-08(`/me` 상단 계정 카드 — 웹·앱 공통) 의 **모양**. 둘 다 웹 페이지라 브라우저(데스크톱 1280, 사이드바 있음)와 앱(iPhone 390, 네이티브 탭바 A 위)에서 함께 본다. 채택안이 UI 계약이 된다.

## How to View
open .planning/sketches/005-search-page-me-account/index.html

상단 바: 화면(/search · /me) × 변형(A/B/C) × 「검색어 입력 중」 상태 × 다크/라이트 × iPhone(앱)/데스크톱(웹). 폰 프레임은 창 높이에 맞춰 줄어들고 하단에 채택된 탭바 A 가 깔린다(검색·마이 탭 활성).

## Variants — `/search`
- **A: 세로 진입 카드 3장** — 검색 입력 48px + 상승률 상위·테마·관심종목 카드(아이콘 44 · 제목 · 한 줄 설명 · ›). 사이드바 「종목검색」 그룹의 이식. 가장 단순.
- **B: 3열 타일 + 최근 검색 + 상승률 미리보기** — 진입은 타일 3개로 압축, 최근 검색(localStorage) 리스트, 「지금 상승률 상위 5」 미리보기(기존 scanner API 재사용). 탐색 허브. 만들 것이 가장 많음.
- **C: 입력 중심** — 진입 칩 3개 + 최근 검색만. 가장 가볍고 진입점 존재감이 약함.
- 공통: 입력 중에는 진입 영역을 감추고 기존 GlobalSearch 결과 리스트(종목명 · 코드 · 시장 · 현재가/등락률)를 카드로 표시. 선택 → `/stocks/{code}`.

## Variants — `/me` 계정 카드
- **A: 한 줄 + 아이콘 버튼** — 아바타 44 · 이름 · 이메일 | 테마(해/달) · 로그아웃 아이콘 버튼 40. 높이 72. 사이드바 유저 섹션과 같은 정보량.
- **B: 가운데 아바타 + 버튼 2개** — 아바타 64 가운데 · 이름 · 이메일 · 풀폭 버튼 「라이트/다크 모드로」 「로그아웃」. 토스 「내 정보」 톤. 높이 ≈190.
- **C: 설정 리스트형** — 상단 아바타·이름·이메일, 아래 「테마 [라이트|다크]」 「로그아웃 · Google 계정 ›」 48px 행(Phase 20 리스트 행 톤). 항목이 늘면 행 추가.

## What to Look For
- `/search`: 앱에서 탭을 눌렀을 때 첫 화면이 「검색」인지 「탐색 허브」인지 — B 는 볼 것이 많고, A/C 는 검색이 주인공.
- `/search` 데스크톱: 사이드바에 이미 3항목이 있는데 본문에도 진입 카드가 있으면 중복이 거슬리는가(A/B) — 그렇다면 C 가 웹에 더 맞는다.
- `/me`: 계정 카드가 전략 현황(첫 정보)을 얼마나 아래로 미는가 — A 72 · C ≈150 · B ≈190.
- 테마 토글 표현: 아이콘(A) · 문장 버튼(B) · 세그먼트(C) — 라이트/다크 어느 쪽에서도 현재 상태가 읽히는가.
- 로그아웃 접근성: 아이콘만(A) vs 글자(B/C). 실수 탭 위험 vs 발견 가능성.

## 결정 (2026-09-25)
- **`/search` = B 채택.** 제목 「검색」 22/700 · 검색 입력 48 · radius 14 · `--raised` 바탕 · placeholder 「종목명 또는 코드」 · 입력 중 우측 ✕ 지우기(18 원). 진입 **타일 3열**(gap 8 · `--card` · radius 16 · padding 14/12): 아이콘 36 radius 12 틴트 면(상승률 상위 `--up-bg`/`--up` · 테마 `--down-bg`/`--primary` · 관심종목 `rgba(250,204,21,.16)`/`#eab308`) · 제목 14/700 · 보조 12 `--muted-fg`(「25%↑ N종목」「오늘 N개」「N종목」 — 실데이터). **최근 검색** 섹션(제목 15/600 muted · 우측 「지우기」 `--primary` 13/600 · 카드 안 44 행 · 시계 아이콘 16 `--faint-fg` · 행 우측 ✕ 개별 삭제 · localStorage `gh-radar:recent-search` 최대 10). **지금 상승률 상위** 5행 미리보기(제목 + 「더보기 ›」 → `/scanner` · 44 행 · 순위 13 muted · 종목명 14.5/600 · 등락률 우측 600 up/down · 기존 scanner API 재사용, 자동 폴링 없음). **입력 중**에는 진입·최근·미리보기를 감추고 결과 카드(52 행: 종목명 15/600 · 코드 12.5 muted · 시장 배지 11/700 `--raised` · 현재가+등락률 우측 14/600)만 → 선택 시 `/stocks/{code}` 이동 + 최근 검색 저장. 데스크톱: 본문 max-width 900 · 사이드바 홈 아래 「검색」 링크 추가(활성 blue50/blue600).
- **`/me` 계정 카드 = A 채택.** `--card` radius 16 · padding 14/16 · 높이 72 · 아바타 44(`avatar_url` → 이니셜, `--raised-2` 바탕, 17/700) · 이름 16/700 · 이메일 12.5 `--muted-fg` · 우측 아이콘 버튼 2개 40×40 radius 12 `--raised`: 테마(다크일 때 Sun · 라이트일 때 Moon, lucide 18, `aria-label="테마 전환"`) · 로그아웃(LogOut 18 · 색 `--up` · `aria-label="로그아웃"`). 카드 아래 16 여백 후 기존 상태줄→전략 현황→계좌 카드 순서 불변(Phase 16 D-20). 웹·앱 공통 표시. 로그아웃 = `useAuth().signOut`(하드 리다이렉트 `/login`).
- 과정: 1차 렌더에서 계정 카드 A/B/C 가 동시에 보이던 결함(`.acct-* { display:flex }` 가 `.v { display:none }` 을 덮어씀)을 `.v:not(.on) { display:none !important }` 로 고친 뒤 검토.
