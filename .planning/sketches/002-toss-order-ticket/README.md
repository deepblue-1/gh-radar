# Sketch 002: 토스식 호가주문

## Design Question
토스 호가 화면(좌 호가 · 우 주문창)과 gh-radar 호가주문/트레이딩 카드는 같은 역할인데 구조가 다르다.
색만 바꾼 001-B 로는 닮지 않는다. 주문 패널을 토스 구조로 재구성하고, 토스에 없는 「상따 자동 설정」을 어떤 토스 패턴으로 담을지 비교.

## Variants
- **A: 박스형 입력** — 토스 「구매할 가격」 상자를 모든 설정값에 (라벨 위 · 값 · −/+), 체크박스 → 스위치
- **B: 리스트 + 바텀시트** — 토스 설정 화면식 「라벨 ─ 값 ›」 행, 누르면 바텀시트에서 수정
- 공통: 매수/매도 + 자동(상따)/직접 주문 2단 세그먼트, 직접 주문 = 토스 주문창 구조, 상단 상태줄 1줄 압축
- 토글: 서체 Pretendard / 시스템 / 나란히, 테마 다크 / 라이트 — 색 @toss/tds-colors 0.1.0 공식 값, 글자 TDS t5/t6/t7

## 2차 (2026-09-25) — B 채택 방향, 폭·입력 방식 확인
- v1(A vs B) 는 `v1-a-vs-b.html` 로 보존. `index.html` 은 B 기준 2차.
- 폭 토글: 폰 390(42% | 패널, 매수/매도 세그먼트, 바텀시트) · 태블릿 768(본문 736 → 컴팩트 밴드, 호가 260 | 매수·매도 두 목록 나란히, 가운데 440 시트) · 데스크톱 1280(본문 992 → 3단 호가 440 | 두 목록, 시트 대신 인라인 편집: Enter/Esc/↑↓ 한 호가)
- 입력 키보드 토글(폰·태블릿): 자체 키패드(시트 안 숫자판 + 단위별 단축 칩) vs 시스템 키보드(inputmode=numeric 시뮬레이션, 시트가 키보드 위로 밀림)

## 3차 (2026-09-25) — Phase 20 논의 결과 반영 (20-CONTEXT.md D-08~D-11 · D-15)
- 「자동(상따) | 직접 주문」 세그먼트 제거 → 진입은 Phase 18 D-19 그대로: 폰 「매수 | 매도 | 수동」 3탭, ≥700 우상단 「수동주문」 버튼이 옵션을 덮고 ✕로 닫음
- 수동주문 = D-20 필드(가격 · 수량 · 조각 수 · 주문유형 · 주문금액), ±·% 없음. 버튼은 매수(빨강)·매도(파랑) 48px 2열 + 정정·취소 38px 회색(미체결 선택 시만 활성)
- 입력: 터치는 상자 탭 → 같은 키패드 시트(값만 채움), 데스크톱은 상자에 직접 타이핑(↑↓ 한 호가). 호가 클릭 → 가격 채움 유지
- 키패드 시트: 호가 단위·상한가 위반 시 확인 잠금 + 이유 표시(D-15), 확인 = 「반영 중…」 → 닫힘(D-04/05 시뮬레이션)
- 4차(사용자 피드백): 매수 탭 = 「매수가격(매수가격·주문금액, 스위치 없음)」 섹션 맨 위 → 매수주문 → 한방체결 / 매도 탭 = 「매도가격(매도가격·매도비율)」 맨 위 → 매도주문 → **매수취소(매도 탭 하단으로 이동)**. 데스크톱 인라인은 행 높이 그대로(안내 문구·「저장」 없음, Enter/Tab/blur 저장 · Esc 취소). 입력칸 포커스·키패드 시트 열림 = 값 전체 선택 상태(첫 입력이 덮어씀).
- 5차(사용자 피드백): 데스크톱 인라인 편집 중 다른 행 클릭 → 저장 후 그 행이 **한 번 클릭으로** 편집 모드(pointerdown 기록 → finish 가 이어받음). 감시대상(매도잔량/매수잔량)은 시트가 아니라 **행 안 토글**(즉시 반영). 매도 탭 매수취소에 「체결」 필드 복원(취소잔량 · 체결 · 잔량추적).
- 6차(사용자 피드백): 감시대상 행 제거 → 「잔량」 행 라벨 앞 접두 토글 **[매도|매수]**(변형 목업 `watch-target-variants.html` 의 D안, 글자는 「매도/매수」로 축약). 매수/매도 탭 맨 위 가격 섹션은 카드 제목 없이 행만.
- 7차(사용자 결정): 감시대상 = **폭별 두 모양** — 본문 <700(폰): 라벨 없이 풀폭 세그먼트 [매도잔량|매수잔량] (변형 B) · 본문 ≥700: 왼쪽 「감시대상」 라벨 + 오른쪽 토글. D안(잔량 행 접두)은 폰 360 에서 넘칠 위험으로 철회. 잔량 행은 원래대로.
- 8차(사용자 피드백): 모든 리스트 행 높이 44px 고정(패딩 대신 min-height) — 감시대상 토글 행도 44 라 태블릿 2열에서 매수주문·매도주문 카드 높이가 같다(측정 172 = 172).
