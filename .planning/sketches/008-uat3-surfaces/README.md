# Sketch 008: UAT 3차 세 표면

## Design Question
UAT 3차(2026-09-26)에서 새 화면 요소가 세 곳 생긴다. 구현 전에 자리를 고른다.

- **① /me 전 종목 전략 로그 (G-21-R3-2)** — 앱에서 /trading 하단 공용 패널(잔고/미체결/전략 로그)을 숨기고, 전 종목 전략 로그는 마이 탭에서 본다. 어디에 둘까?
- **② 종목상세 넓은 폭 「트레이딩」 (G-21-R3-9)** — 「주문하기」 → 「트레이딩」(/trading?code= · 그 종목 카드 펼침·포커스). 폰은 하단 바 라벨만 바뀐다. 넓은 폭(≥768)엔 버튼이 없어 자리를 새로 정한다.
- **③ 트레이딩 카드 수동주문 주문유형 (G-21-R3-10)** — 종목상세 호가주문 탭을 없애면 시간외종가 신규 주문은 카드 수동주문에서만 된다. 주문유형(지정가/시간외종가)을 카드 어디에 둘까?

## Variants

### ① /me 전략 로그 (폰 390 · 로그 예시 5줄, 종목명 포함 · 기존 전략 로그 카드 문법 11px)
- **A: 전략 현황 바로 아래 독립 카드 「전략 로그」** — 상태와 기록이 붙어 첫 화면 안. 대신 계좌 카드가 한 화면 아래로.
- **B: 전략 현황 카드 안 「현황 | 로그」 전환** — 세로 길이 불변. 대신 둘을 동시에 못 보고 한 번 더 눌러야 한다(기본 = 현황).
- **C: 오늘 주문 아래 맨 끝 카드** — 기존 세로 순서(D-20) 무변경. 대신 끝까지 스크롤해야 보인다.

### ② 넓은 폭 「트레이딩」 (1024 · 브라우저판 + 앱판(「AI 분석」 있음) · 색은 폰 CTA 와 같은 --up · 자리/크기만 다름)
- **A: 히어로 첫 줄 끝(32 알약)** — 「AI 분석」과 같은 액션 줄. 앱판에서 알약 두 개가 붙어 붐빈다.
- **B: 가격 줄 끝(40 · r12)** — 가격을 보고 매매하러 가는 흐름. 존재감이 가장 강하다.
- **C: 갱신시각 행 「새로고침」 옆(32 · r10)** — 히어로 무변경 · 구현 최소. 주 동작처럼 안 보인다.
- 참고: 폰(<768) 하단 바 = 56 · r16 · 17/600 · --up 그대로, 라벨만 「트레이딩」.

### ③ 카드 주문유형 (카드 폭 344 · 창 열림(시간외종가 선택) / 창 닫힘(비활성 + 안내) 두 상태)
- **A: 호가 탭과 같은 44px 행 「주문유형 지정가 ›」(주문금액 위)** — 지금 호가 탭 UI 그대로 이전(네이티브 선택 시트). 현재 유형이 행 오른쪽 글자로만 보인다.
- **B: 가격 칸 위 세그먼트 「지정가 | 시간외종가」** — 가장 잘 보이고 한 번에 전환. 카드 높이 +40, 창 닫힌 대부분 시간 비활성 칸.
- **C: 가격 라벨 옆 칩** — 높이 증가 없음. 칩이 작아 존재감·터치 영역 약함(44 히트 확장 필요).
- 공통: 판정은 `affordanceOf` 그대로(KRX ∧ G2/G3 창 열림일 때만 시간외종가) · 창이 닫히면 지정가 복귀 · 시간외종가 = 가격 잠김(참고 종가) · 주문금액 「종가 확정 후」.

## Winner
**①B ②A ③A** (2026-09-26 사용자 확정 · 21-25 Task 2 — 한 다이얼로그에 질문 하나씩). CONTEXT 정본 = D-25a(①) · D-30(②) · D-31(③).

- **① /me 전 종목 전략 로그 = B 「현황 | 로그」 전환** — 전략 현황 카드 머리 오른쪽 알약 세그먼트(`--seg-on-*` · 버튼 26 높이 · 12/600) 「현황 | 로그」. **기본 = 현황** · 「로그」를 누르면 같은 카드 본문이 전 종목 전략 로그(기존 전략 로그 카드 문법 11px · 시각 tnum · 종목명 600 · 거부 빨강)로 바뀐다. 카드가 하나라 **/me 세로 길이 불변** · 계좌 카드 위치 그대로(D-20 순서 무변경).
- **② 넓은 폭 「트레이딩」 = A 히어로 첫 줄 끝** — 종목명 줄 끝(`ml-auto` 액션 자리) **32 높이 알약** · 채움 `--up` · 흰 글자 · 누르면 `/trading?code={code}`. 앱판은 「AI 분석」 옆에 나란히(두 알약 공존 · 긴 종목명이면 줄바꿈 허용). **폰(<768)은 하단 바 56 · r16 · 17/600 · `--up` 그대로, 라벨만 「트레이딩」.** 매매 불가 종목은 버튼 없음.
- **③ 카드 주문유형 = A 44px 행** — 주문금액 바로 위 44px 행 「주문유형 지정가 ›」(현재 호가주문 탭 UI 를 카드로 이동 · 투명 select → 네이티브 선택 시트). 판정 `affordanceOf` 그대로 — KRX ∧ G2/G3 창 열림일 때만 시간외종가 선택 가능 · 창이 닫히면 지정가 복귀 + 행 아래 캡션 안내 · 시간외종가 = 가격 잠김(참고 종가) · 주문금액 「종가 확정 후」.

재확인 답(같은 체크포인트):
- **잃는 동작 = 동의(범위 밖)** — 앱에서 /trading 하단 패널을 숨기면 ② 잔고 행 탭 → 그 종목 카드 생성·포커스 ③ 카드 없는 종목의 미체결 정정 진입이 앱에서 없어진다.
- **리다이렉트 = 동의** — `/stocks/{code}/news` · `/discussions` → `/stocks/{code}?tab=news&view=news|discussions` (G-21-R3-8 · 북마크 호환).
- **WR-03 Android 브리지 = a** — `androidx.webkit` 1.14.0 을 app 모듈에 선언(`variables.gradle` 의 `androidxWebkitVersion` 공유) + `WebMessageListener`, 허용 출처 · 메인 프레임만.

## What to Look For
- ① 폰 첫 화면(스크롤 전)에 무엇이 들어오는가 — 전략 현황 · 로그 · 계좌 카드의 우선순위.
- ② 앱판(iPad)에서 첫 줄 「AI 분석」과 「트레이딩」이 함께 설 때의 밀도 · 긴 종목명.
- ③ 창 닫힘(대부분의 장중 시간)에서 주문유형 자리가 얼마나 공간을 쓰는가 · 시간외종가를 골랐을 때 한눈에 보이는가.
