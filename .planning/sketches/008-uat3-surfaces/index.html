③ 트레이딩 카드 수동주문 주문유형 배치 (G-21-R3-10)

종목상세 호가주문 탭을 없애면 시간외종가 신규 주문은 트레이딩 카드 수동주문에서만 된다. 카드 폭 344(폰). 판정은 지금 그대로(affordanceOf — KRX ∧ G2/G3 창 열림일 때만 시간외종가 선택 가능 · 창이 닫히면 지정가로 복귀). 각 변형마다 창 열림(시간외종가 선택) · 창 닫힘(비활성 + 안내) 두 상태. 시간외종가를 고르면 가격은 잠기고(참고 종가) 주문금액은 「종가 확정 후」.

변형 A — 호가 탭과 같은 44px 행 「주문유형 지정가 ›」(주문금액 위) ＋ 지금 호가 탭 UI 를 그대로 옮긴다(토스식 행 문법 · 누르면 네이티브 선택 시트)
－ 현재 유형이 행 오른쪽 글자로만 보인다 · 닫힘 안내는 행 아래 캡션
변형 B — 가격 칸 위 세그먼트 「지정가 | 시간외종가」 ＋ 현재 유형이 가장 잘 보이고 한 번 눌러 전환
－ 카드 높이 +40 · 창이 닫힌 대부분 시간 동안 비활성 칸이 자리를 차지
변형 C — 가격 라벨 옆 칩 ＋ 높이 증가 없음 · 가격과 유형이 한 상자에서 읽힌다
－ 칩이 작아 존재감이 약하다(터치 영역은 44 로 확장 필요)
