# Sketch 011: 상한가 보고서 리스트 펼침 · 사건 차트

## Design Question
하루 격자 → 종목 리스트(행 클릭 = 그 자리 펼침) + 사건 차트 가독성(번호 마커 ↔ 사실 문장, 20%/25% 기준선, 첫 상한가 체결 시각·가격, 「진입 1분」 → 「상한가 직전 1분」, 「잠김 전 구간」 → 「잠김 구간」)을 하나의 목업에서 비교.
함께 반영한 확정 사항: 사이드바 「AI 애널리스트」를 「분석」 하위(상한가 보고서 밑)로 이동 · 상한가 미도달(첫 상한가 체결 없음) 종목은 목록에서 제외.

## Variants
- **A: 번호 연결** — 아코디언(한 번에 하나). 한 줄 요약 → 「상한가 도달까지」 · 「잠김 구간」 두 차트 → 오른쪽 사실 문장. 차트 라벨 띠의 번호 = 사실 문장 번호, 호버 시 서로 강조.
- **B: 타임라인 우선** — 왼쪽 사건 세로 타임라인(사건 간격 +N분), 오른쪽 차트 하나. 사건을 누르면 차트가 그 구간으로 전환.
- **C: 요약 카드 먼저** — 4단계 카드(20% 도달 → 첫 상한가 → 최대 잔량 → 결과) + 하루 가격 차트. 「자세히」로 A 의 두 차트 + 사실 문장.

## What to Look For
- 펼쳤을 때 「언제 무엇이 있었나」가 한눈에 들어오는지(번호 연결 vs 타임라인 vs 요약 카드)
- 기준선 토글(탐지 20% / 25% / 둘 다) — 사실 문장과 차트가 같은 기준을 말하는지
- 파란 면 「상한가 직전 1분」 · 「깨짐 직전 1분」 이 창구 막대의 뜻을 설명하는지
- 폰 390 에서 라벨 띠·번호가 읽히는지

## Data
덕우전자 · 엑시온그룹 · 형지글로벌(제외) = workers/limitup-sync/tests/fixtures/export/20261002 실데이터(data.js, 추출 스크립트는 세션 scratchpad). 에스제이그룹 = 사용자 스크린샷 사실 문장 기준 근사 합성.

## Decision (2026-10-05)
- **A 번호 연결** 채택 — 아코디언(한 번에 하나) · 한 줄 요약 → 「상한가 도달까지」 · 「잠김 구간」 두 차트(라벨 띠 번호 + 지시선) → 오른쪽 사실 문장(같은 번호, 호버 상호 강조) · 창구 막대.
- 기준선 = **탐지 20%만**(사실 문장과 같은 기준). 25% 선 · 「25% 도달」 마커 · KPI 「25%↑ 미도달」 제거.
- 「진입 1분」 → 「상한가 직전 1분 (HH:MM:SS~HH:MM:SS)」 + 차트 파란 면 · 「깨짐 직전 1분」 도 같은 방식. 「잠김 전 구간」 → 「잠김 구간」. 사실 문장 앞 시각 중복 제거.
- 상한가 미도달(첫 상한가 체결 없음) 종목 목록 제외 + 「N종목 뺐어요」 한 줄.
- 사이드바: 「AI 애널리스트」 를 「분석」 하위(상한가 보고서 밑)로 — **트레이딩 권한자에게만** 노출(권한 없는 사용자 메뉴에서 사라짐).
