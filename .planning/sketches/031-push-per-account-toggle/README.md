# Sketch 031: 매매 알림 계좌별 켜고 끄기

## Design Question
지금 매매 알림은 기기 단위(이 기기 켜기 · 다른 기기 끄기)뿐이다. 계좌마다 알림을 켜고 끄려면 어디에, 어떤 모양으로?

## How to View
open .planning/sketches/031-push-per-account-toggle/index.html

## Variants
- **A: 시트 안 계좌 스위치 줄** — 종 → 「매매 알림」 시트(폰) · 팝오버(데스크톱)의 이 기기 스위치 아래 소제목 「받을 계좌」 + 계좌마다 상품명 · 번호 · 서버 한 줄 + 스위치. 다른 기기 목록은 그 아래. PC 웹에서도 바꿀 수 있다.
- **B: 시트 안 계좌 알약** — 같은 자리에 알약 한 줄(켜짐 파랑 · 꺼짐 빈 알약). 짧지만 번호 · 서버가 안 보인다.
- **C: 설정 탭 · 고른 계좌** — /me 계좌 칩으로 고른 계좌의 설정 탭 맨 위 「이 계좌 매매 알림」 스위치.

## 공통 규칙
- 계좌를 끄면 **내 모든 기기**에서 그 계좌 소식만 안 온다(기기 스위치와 별개 — 둘 다 켜져야 온다).
- 처음엔 전부 켜짐. 같은 계좌를 함께 쓰는 다른 사람은 영향 없음.
- 종의 초록 점은 지금처럼 「이 기기 켜짐」 기준.

## Decision (2026-11-09)
- **A 시트 안 계좌 스위치 줄** 채택.
