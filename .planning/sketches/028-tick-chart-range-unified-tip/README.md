# Sketch 028: 틱뷰어 타임라인 — 범위 합계 · 통합 툴팁

## Design Question
2026-11-04 사용자 요청 4건을 한 화면에서 본다.
1. 마우스로 범위를 끌면 그 구간 팀 매수 · 매도 · 순매수 금액.
2. 근처 팀 주문 묶음 툴팁(지금 규칙 그대로)을 읽기 좋게 — 주문마다 한 줄 표.
3. 당일 순매수 판에 당일 매수 누적 · 매도 누적 선.
4. 판별로 따로 뜨던 툴팁을 그 시각 네 판 값이 한 상자에 정리된 통합 툴팁으로.

## Variants (통합 툴팁 모양)
- **A: 따라다니는 세로 카드** — 마우스 옆 폭 268 · 머리(시각 · 가격 · 등락률) 아래 「당일 팀 · 10분 칸 · 누적」 섹션이 라벨 : 값 두 열. 원 위면 맨 위에 묶음 표. 키가 크다.
- **B: 차트 위 고정 띠 ★ 채택(2026-11-04)** — 머리 아래 높이 고정 4칸 띠(가격 | 당일 팀 | 10분 | 누적). 마우스 = 그 시각 · 떼면 현재 틱. 차트를 안 가림. 묶음만 원 옆 작은 상자.
- **C: 판별 행 표** — 마우스 옆 넓고 낮은 상자(≈ 470) · 판마다 한 행 · 값은 가로. 원 위면 표 아래 묶음 블록.

## 상단 토글(세 안 공통)
- 범위 끌기: 「끌기 = 범위 · Shift+끌기 = 이동」 / 「Shift+끌기 = 범위 · 끌기 = 이동 그대로」
- 순매수 판 매도선: 「0선 아래(거울)」 / 「위로 같이」 · 판 높이 50 / 70

## 결정(2026-11-04)
- 통합 툴팁 = **B 고정 띠**(마우스 = 그 시각 · 떼면 현재 틱 · 팀 주문 묶음만 원 옆 작은 상자 · 주문마다 한 줄 표).
- 범위 끌기 = **Shift+끌기**(그냥 끌기 = 창 이동 그대로). 결과는 차트 아래 줄 · Esc · ✕ · 빈 곳 클릭으로 지움.
- 순매수 판 = **매도 누적 0선 아래(거울) · 판 높이 50 → 70**(폰 36 → 50).

## What to Look For
- 원 위 · 원 밖 · 다른 판에서 상자가 가격 판을 얼마나 가리는가(A 키 · C 폭 · B 없음).
- 구간 결과는 차트 **아래** 줄 — 손을 뗄 때 차트가 밀리지 않는가.
- 순매수 판 선 4개(보라 · 빨강 · 파랑 · 회색)가 50 / 70 높이에서 읽히는가.
- 폰 390 — B 띠가 2×2 로 커지는 것 · 폰 범위 선택은 1차 제외 안.
