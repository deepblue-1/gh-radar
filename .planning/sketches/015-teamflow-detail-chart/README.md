# Sketch 015: 팀 매집 상세 · 표 vs 차트

## Design Question
014 에서 구조(상한가 보고서 동형 · 행 펼침 · 기본 접힘)는 정했다. 펼친 상세 안의 세 덩어리 — 등락 구간별 팀 체결(6열) · 10분 단위 흐름(7열 · 37행) · 다섯 창구 거래원 — 를 어떤 모양으로 보여야 폰에서도 「언제 · 어느 가격대에서 팀이 모았나」 가 읽히나. 요약 문장 · 판정 기준은 세 변형 공통.

## How to View

(데이터는 `../014-teamflow-list-detail/data.js` 재사용 — 014 디렉터리와 나란히 있어야 한다)

## Variants
- **A: 표 그대로** — gh-trade 샘플의 표 3개. 숫자가 전부 보이지만 폰은 가로 스크롤 · 10분 표 37행.
- **B: 차트** — 구간 = 가로 막대(중앙 0선 · 20% 점선 · 오른쪽 「매수 중 팀」 %) · 10분 = 순매수 막대 + 보라 선(매수 중 팀 %) + 아래 등락률 범위 띠(20% 점선) · 보라 음영 = 최대 매집 창 · 첫 상한가 세로선 · 거래원 = 매수/매도 2단 막대. 표 없음, 수치는 툴팁.
- **C: 혼합** — B 의 차트 + 각 차트 아래 「구간표 보기」 · 「10분 표 보기」 접힌 표(기본 접힘).

## What to Look For
- 「펼친 종목」 셋: 한선(20% 아래 매집 → 위에서 매도) · 에스엠벡셀(상한가 직전 집중 · 상한가 가격 행 · 첫 상한가 선) · 동양고속(팀 거의 없음 — 빈 차트가 초라하지 않은지)
- 폰 390 에서 10분 차트의 37칸 막대 + 보라 선이 읽히는지(막대 폭 ≈ 7px)
- 10분 등락률 범위 띠가 「몇 %에서 모았나」 를 표의 「등락 범위」 열만큼 답하는지
- C 의 접힌 표가 「숫자 확인」 요구를 받아 주는지, 아니면 그냥 A 가 나은지

## Decision (2026-10-16)
- **C 혼합** 채택 — 펼친 상세 = 요약 문장 → [구간 가로 막대 차트 | 거래원 2단 막대] 2열(폰 1열) → 10분 흐름 차트(순매수 막대 + 매수 중 팀 % 선 + 등락률 범위 띠 · 최대 매집 창 음영 · 첫 상한가 세로선) → 판정 기준 접힘. 구간 차트 아래 「구간표 보기」, 10분 차트 아래 「10분 표 보기」 접힌 표(기본 접힘).
- 차트 규칙: 중앙 0선 · + 빨강 / − 파랑 · 20% 경계 점선(구간 차트 가로 · 10분 띠 가로) · 팀 비중 ≥ 30% 보라 강조 · 수치는 막대 `<title>` 툴팁.
- 계약 영향 없음 — gh-trade 초안 payload(bands share · buckets lo/hi · window start/end · first_limit_ms)로 전부 그린다.

## Data
014 data.js(10/14 실측 3종목 + 합성 4행). 차트는 추가 필드 없이 같은 payload 로 그린다 — bands[].share(매수 중 팀) · buckets[].lo/hi(등락률 범위) · window(start/end) · first_limit_ms 만 있으면 된다(gh-trade 계약 초안에 전부 있음).
