# Sketch 007: 라벨 없는 탭바

## Design Question
UAT 2차 G-21-1. 탭 아이콘 아래 라벨을 빼기로 확정(2026-09-26)했다. 라벨이 빠진 알약 탭바를
weekly-wine-app 특성과 어디까지 맞출지 고른다. 기준은 sketch 004 A(= D-27a).

## Winner
**C · 캡슐 인디케이터, 높이 60** (2026-09-26). 테두리 없음 · 아이콘 뒤 가로 캡슐 56×36(primary 16%) · 유리(블러 28 + 채도) · 그림자 0 4 24 .14 + 0 1 2 .08 · radius = 높이/2 · 바닥 max(inset−14, 14) 유지 · 웹 본문 하단 여백 98(= 60 + 20 + 18).
근거: 테두리 없는 명도 분리 원칙(토스 다크)과 일치 · iOS 26/Material 3 캡슐 관례라 양 플랫폼에서 네이티브답다 · 라벨 없는 5탭에서 선택이 가장 잘 읽힌다. 주의: Android 는 실블러가 없어 유리감이 약해진다 — 에뮬 캡처로 확인. 다크 기본에서 유리 면 불투명도·아이콘 대비 확인.

## Variants
- **A: 현행에서 라벨만 제거** — 46pt 원 활성 · 1px 테두리 · 그림자 0.18/r8 · card 82%+블러 · 색 페이드 120. 구현 변경 최소.
- **B: weekly-wine 충실** — 테두리 없음 · 안쪽 여백 6 · 셀을 채우는 둥근 사각형(r22 · 12%) · 그림자 0.12/r16 · 밝은 유리 · 점진 블러 페이드 · 옅은 비활성.
- **C: 캡슐 인디케이터** — 테두리 없음 · 아이콘 뒤 가로 캡슐 56×36 · 가장 강한 유리 · 넓고 옅은 그림자.
- **D: 미니멀 점** — 배경 표시 없음 · 채운 아이콘 + primary + 아래 점.

## What to Look For
- 다크(기본)에서 탭바가 본문과 얼마나 분리돼 보이는가(테두리 유무).
- 활성 표시의 무게 — 원 / 사각형 / 캡슐 / 점.
- 탭바 뒤로 목록이 비칠 때 읽힘(유리 · 페이드).
- iPad 560 가운데 배치에서의 비례.
