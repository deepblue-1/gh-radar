# Sketch 003: 토스 라이트 팔레트

## Design Question
theme/toss-b 의 라이트 모드는 quick-260925-0pf 에서 공식 `@toss/tds-colors` 값으로 이미 고정됐다(흰 바탕 · grey100 면 · grey900 글자 · blue500 / red500).
그런데 다크(001-B)에 비해 「디자인된 느낌」이 약하다. 팔레트 값 자체보다 **면 위계와 선택·활성 표현**이 라이트에서 어떻게 읽히는지가 문제라, 세 방향을 같은 화면(001 DOM 재사용)에 입혀 비교한다.

## How to View
open .planning/sketches/003-toss-light-palette/index.html

상단 바: 라이트 팔레트(현재/A/B/C) × 화면(종목상세/트레이딩) × 폭(폰 390/데스크톱 1280). 종목상세 안 「호가주문」 탭을 누르면 상따 패널도 본다. 모든 변형이 같은 DOM · 같은 구조 토큰(001-B 채택 구조)을 쓰고 **색 토큰만** 다르다. 변형 설명 줄에 핵심 hex 스와치를 같이 띄운다.

## Variants
- **현재 · TDS 순정** — 프로덕션 `globals.css :root` 그대로. 종목상세 = 흰 바탕 + grey100 12px 띠, 작업대·호가주문 = grey100 면 + 흰 카드, 선택 = 검정 알약.
- **A · 순정 + 블루 선택** — 팔레트 값은 TDS 그대로(`tds-tokens.test` 무변경). 선택·활성만 검정 알약 → `blue50 #e8f3ff` + `blue600 #1b64da`(토스 라이트의 선택 관례). 사이드바 흰색 + 파란 활성, 탭 선택 파랑, 「내 바스켓」 칩 파랑. **최소 변경안.**
- **B · 쿨 네이비** — 두 화면 모두 푸른 기 회색 바탕 `#eef1f6` 위 흰 카드(옅은 그림자 2겹) + 남색 글자 `#0f172a` / 보조 `#64748b`. 종목상세도 띠 대신 카드. 상승/하락/주색은 TDS 그대로. **TDS 밖 회색**이라 채택 시 `tds-tokens.test.ts` 라이트 기대값을 갱신해야 한다.
- **C · 순백 하이라인** — 토스 PC 웹 톤. 회색 바탕·그림자 없이 순백 위 1px hairline `#e5e8eb` 로 카드·입력·칩 경계. 종목상세 섹션은 12px 띠 대신 1px 선, 표 행 선 복원, radius 16/12 로 한 단계 작게. 팔레트 값은 TDS 그대로(`--border` 를 hairline 으로 승격 — globals.css 주석의 「무테 유지」 원칙과 충돌하므로 채택 시 그 주석·가드 테스트 재검토).

## What to Look For
- **면 위계**: 흰 바탕 + 띠(현재/A) vs 회색 바탕 + 카드(B) vs 흰 바탕 + 선(C) — 트레이딩 작업대 2열 카드에서 경계가 읽히는가, 종목상세에서 섹션이 갈리는가
- **선택 표현**: 검정 알약(현재/B/C) vs 파란 면+글자(A) — 정보/미체결/잔고 알약, 세그먼트, 사이드바 활성
- **텍스트 톤**: grey900 `#191f28`(현재/A/C) vs 남색 `#0f172a`(B) — 숫자와 상승 빨강의 대비
- **장시간 피로**: 순백(현재/A/C) vs 저채도 회색 바탕(B)
- **구현 비용**: A = 토큰 몇 개 · B = 라이트 블록 전체 + 테스트 기대값 · C = 테두리 토큰 규율 변경(가드 테스트 · 카드 컴포넌트)

## 제약
- 값은 hex/rgba 만(차트가 oklch 거부). 다크 토큰은 손대지 않는다.
- 상승 `#f04452` · 하락 `#3182f6` · 주색 `#3182f6` 은 세 변형 모두 고정 — 데이터 색은 이 스케치의 질문이 아니다.
- 호가주문 패널 구조는 001 폼(입력 상자)이다. 002 리스트+시트 구조는 Phase 20 에서 만들어지므로 팔레트 판정에는 반영하지 않았다.

## 결정 (2026-09-25)
**A 채택.** 팔레트 값은 TDS 공식값 유지. 바꾸는 것은 선택·활성 표현뿐:
- 알약 선택(`--pill-on-bg`/`--pill-on-fg`) 검정 `#191f28`/흰 → `blue50 #e8f3ff` / `blue600 #1b64da`
- 사이드바 바탕 `#f9fafb` → 흰색, 활성 항목 blue50 면 + blue600 글자
- 탭 선택 글자 blue600 + 밑줄 blue500, 「내 바스켓」 칩 blue50/blue600, 세그먼트 선택 글자 blue600
- 스펙트럼 현재가 점 blue500 + 파란 링
- `tds-tokens.test.ts` 라이트 기대값 중 `pill-on-bg`·`side-bg` 두 줄만 갱신(값은 여전히 TDS 팔레트)
- 다크 토큰은 무변경. B(쿨 네이비)·C(순백 hairline)는 보류.
