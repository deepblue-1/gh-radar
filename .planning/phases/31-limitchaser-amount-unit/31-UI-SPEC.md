### 두 줄 행 문자열 (D-07)

**위 줄** = 언제나 `{만원, 천 단위 쉼표}만`. 0 도 「0만」 이다(목업 C 「0만 / 무제한」). 의미어를 위 줄에 쓰지 않는다.

**아래 줄** = 위에서부터 첫 일치 하나:

| 순위 | 조건 | 글자 | 색 |
|---|---|---|---|
| 1 | 금액 > 0 ∧ 그 그룹 비교가 = 0 | 「비교가격 필요」 | `--destructive` |
| 2 | 제출 주(= `qtyForSubmit`, D-06 메모 포함) = 0 ∧ 의미어가 있는 칸 | 줄매수 최대 「무제한」 · 줄매수 최소 「1주」 · 후매수 최소 「없음」 | `--muted-fg` |
| 3 | 그 밖 | 「{주, 천 단위 쉼표}주」 (0 이면 「0주」) | `--muted-fg` |

- 아래 줄의 주는 **제출과 같은 값**이다(D-02 내림 · D-06 추적 ON 되싣기 메모 포함). 다른 식으로 다시 계산하지 않는다.
- 비교가 0 ∧ 금액 0 은 순위 2/3 으로 떨어진다(「0주」 또는 의미어) — 빨강이 아니다.
- 그룹 스위치가 꺼져 흐린 행도 같은 규칙을 그린다(목업 C 매도 꺼짐 + 「비교가격 필요」). 흐림은 행 전체(위 · 아래 줄 함께)에 한 번만 건다.

예시(비교가 12,870원): 매도잔량 「1,000만 / 777주」 · 체결량 「500만 / 388주」 · 줄매수 최소 「2,000만 / 1,554주」 · 줄매수 최대 「0만 / 무제한」 · 후매수 최소 「84만 / 65주」 · 매도 비교가 0 인 매도 매수잔량 「1,500만 / 비교가격 필요」.

### 파생 행 문자열 (D-05)

| 상태 | 위 줄 | 아래 줄 |
|---|---|---|
| 값 > 0 ∧ 그룹 비교가 > 0 | 「{round 역산}만」 (발동잔량 「32,175만」 `--up` 15/600 · 기준선 `--fg-2` 15/500) | 「{주}주」 「25,000주」 `--muted-fg` |
| 값 > 0 ∧ 그룹 비교가 = 0 | 「{주}주」 (위 줄 스타일 그대로 — 발동잔량이면 `--up`) | (비움 — 행 높이 56 유지) |
| 발동잔량 0 ∧ 잠금 해제선 > 0 | 「{해제선 역산}만」 `--muted-fg` 15/500 (sr 접두 「잠금 해제선」 유지) | 「{해제선}주」 `--muted-fg` |
| 값 0 (해제선도 0) | 「—」 `--muted-fg` (sr 「없음」 유지) | (비움) |

그룹 비교가: 발동잔량 = 매수 `buyWatchPrice`, 잔량추적 기준선 = 매도 `sellWatchPrice`. 취소 기준선 파생 행은 만들지 않는다(Open Q4 — 새 능력 금지).

### 접힌 카드 요약 줄 (Open Q5 — 이 계약이 정한다)

요약 kv 값은 **위 줄 글자 하나**만 쓴다(한 줄 폭 보존 — 주 병기 없음). 단, 금액 0 이고 의미어가 있는 칸은 의미어를 쓴다(위 「값 0 표시」 표).

| 카드 | 전 | 후 |
|---|---|---|
| 선매수 | 매도잔량 10,000주 · 체결량 30,000주 | 매도잔량 1,000만 · 체결량 500만 (체결량 꺼짐이면 「꺼짐」 그대로) |
| 줄매수 | 최소 1주 · 최대 무제한 | 최소 2,000만 · 최대 무제한 (0 이면 의미어) |
| 후매수 | 최소 100,000주 · 발동잔량 25,000주 | 최소 84만 · 발동잔량 32,175만 (매수 비교가 0 이면 「25,000주」) · 해제선은 꺼진 kv 색 + sr 「잠금 해제선」 그대로 |

발동잔량은 요약에서 빨강을 쓰지 않는다(기존 규칙 유지).

## 폭 백스톱 (Pitfall 7 · §2.2b 경계 불변)

- **최악값 글자(e2e P20-3 · P24-7 갱신):** 위 줄 「999,999,999만」(키패드 9자리 상한) · 아래 줄 「2,147,483,647주」(주 좁힘 상한 int.MaxValue · Pitfall 5) · 파생 행 위 줄 「999,999,999만」. 위 줄 최악값은 옛 최악값 「177,000,000주」 와 글자 구성(숫자 9 · 쉼표 2 · 한글 1)이 같고 tabular 숫자라 폭이 같다 → **685 경계 · 최소 여유 +1.2px 이 그대로**다. 아래 줄은 12px 라 위 줄보다 좁다.
- **높이 단언:** 수량 8행 + 파생 2행(그려질 때) = 56px, 나머지 상따 행 = 44px — 편집 전후 동일. 「행이 전부 44」 단언(P24-7 · P20-3)을 이 둘로 나눈다.
- **L4(이번 신설 · 두 줄 행 한정):** 값이 넓어 라벨 자리가 모자라면 라벨이 **낱말 경계(공백)에서만** 두 줄로 접힐 수 있다(`break-keep` · 말줄임 금지 · 글자 크기 불변 · 행 높이 56 불변). 실제로 걸리는 행은 폰 밴드 본문 344 의 「잔량추적 기준선」(→ 「잔량추적 / 기준선」)뿐이다 — 옛 최악 「100,000주」(+0.9px)가 만원 역산(예 100,000주 × 1,274,000원 = 「12,740,000만」)에서 넓어지기 때문이다. 44px 행 · 낱말 하나짜리 라벨은 해당 없다. L0~L3 규칙은 그대로다.
- P24-8(폰 한 화면 ≤ 660px)은 세 카드가 접힌 상태라 영향이 없다 — 회귀만 확인.
