| Destructive | `--destructive` #f04452 / #f04251 | 사전 검증 줄 · 추가매수 상태 「포기」 · 기존 실패 링/말풍선/시트 실패 문구 — **그 외 금지** |

**Accent 전용 자리(Phase 20 목록 그대로 — 이 phase 가 더하는 자리 없음):** ① 켜진 그룹 스위치 트랙(마스터 포함 4개) ② 켜진 원형 체크 채움(체결량 · 한방 · 매도/취소 체크) ③ 시트 「{필드명} 적용」 버튼 면 ④ 인라인 편집 1.5px 링 ⑤ 시트 캐럿·선택 강조 ⑥ 확정 뒤 값 900ms 강조 ⑦ 포커스 링. 접기 쉐브런 · 요약 줄 · 상태 문구에는 **쓰지 않는다**.

**상태색(기존 토큰 재사용 — 새 토큰 0):**

| 상태 문구 | 토큰 | 근거 |
|---|---|---|
| 감시 중 | `--led-armed` | 기존 「감시 중」 색(Phase 20 §1) |
| 보유중 | `--led-latent` | D-12 — LED 주황과 **같은 토큰**(판정 한 곳, 두 표면). ⚠ globals.css `--led-latent` 주석(「이 phase 밖에서 재사용하려면 의미가 같은지 먼저 확인」)에 소비처 「후매수 보유중(Phase 24 D-12)」 한 줄을 더한다 — 의미: 무장돼 있으나 지금 매수 판정을 하지 않는 단계 |
| 포기 | `--destructive` | 서버가 조건 위반으로 포기한 상태(스케치 `.s.bad`) |
| 소진 · 꺼짐 · 켜짐 · 켠 매수 없음 · 무장 · 대기 | `--muted-fg` | 중립 |

**그 밖의 색:**
- 발동잔량 값(있을 때) = `--up`(매수 방향색 축 — 매수 발동 기준값이다). `--destructive` 와 hex 가 같지만 **축이 다르다** — 오류가 아니므로 destructive 를 쓰지 않는다. 없을 때 「—」 = `--muted-fg`.
- 요약 줄 값 = `--fg-2` · 요약 키 = `--muted-fg` · 꺼진 하위 항목(「체결량 꺼짐」「한방 꺼짐」「발동잔량 —」「금액 —」) = `--muted-fg`.
- 접기 쉐브런 = `--faint` · 접기 버튼 hover 면 = `color-mix(in srgb, var(--fg) 5%, transparent)`(행 hover 와 같은 값).
- 소진 안내 줄 = `--muted-fg`(빨강 아님 — 오류가 아니라 안내다).

**알려진 대비 예외(Phase 20 상속 · 이 phase 가 새로 만드는 것이 아님):** 라이트 테마에서 LED 토큰 글자(`--led-armed` #03b26c ≈ 2.7:1 · `--led-latent` #ff9f1a ≈ 2.0:1 · `--destructive` ≈ 3.6:1, 모두 `--group-bg` #f9fafb 대비)는 12px 본문 대비 4.5:1 에 못 미친다. 다크는 전부 통과(`--led-latent` #ffb13d on #2c2c35 ≈ 7.6:1). 완화: 색은 **보조 신호**이고 의미는 상태 **단어**가 싣는다(WCAG 1.4.1), 같은 단어가 접기 버튼의 접근성 이름에 들어간다. 상태색 재정의는 전 화면에 걸리는 일이라 이 phase 범위 밖이다.

### 매수 탭/열 순서 (스케치 009 D · LOCKED)

```
[매수주문]  ─ 상태 ─ (마스터 스위치 buyEnabled)          ← 접기 없음
   주문가격  13,000원 ›
   비교가격  13,000원 ›
[선매수 ›]  ─ 상태 ─ (preBuyEnabled)                   ← 접기 가능 · 기본 접힘
   접힘: 금액 4,000만원  매도잔량 10,000주  체결량 30,000주  한방 꺼짐
   펼침: 금액 · 매도잔량 · ○체결량 · ○한방 · 한방가격
[추가매수 ›] ─ 상태 ─ (extraBuyEnabled)
   접힘: 금액 4,000만원  최소 50,000주  최대 무제한
   펼침: 금액 · 최소 잔량 · 최대 잔량
[후매수 ›]  ─ 상태 ─ (postBuyEnabled)
   접힘: 금액 4,000만원  최대 3회 · 남은 2회  최소 100,000주  반등 30%  발동잔량 330,000주
   펼침: 금액 · 최대 · (소진 안내) · 최소 잔량 · 반등 · 발동잔량(읽기 전용)
「켤 수 없는 이유」 패널(열 맨 아래, 기존)
```

- 옛 매수 가격 섹션(제목 없는 [매수가격 · 주문금액])과 「한방체결」 카드는 **없어진다**. 주문금액(`buyOrderAmount`)은 선매수 카드의 「금액」이 되고, 한방은 선매수 카드 안 체크 행이 된다.
- 감시대상 행(`WatchTargetRow`)은 **삭제**한다(렌더 · 스펙 kind `'watch'` · 테스트).
- 매도 탭/열 구조는 Phase 20 그대로: [주문가격 · 매도비율] 가격 섹션 → 매도주문(비교가격 · 매수잔량 · ○잔량추적 · ○체결 · 조건부 잔량추적 기준선) → 매수취소(매수잔량 · ○체결 · ○잔량추적). 바뀌는 것은 라벨(D-09) · 상태 꼬리(D-15) · 흐림(⑩)뿐이다.

### 밴드별 동작 (§2.2b 4밴드 — 경계 숫자는 globals.css 정본)

| 밴드 | 매수 카드 4장 | 요약 줄 | 기타 |
|---|---|---|---|
| 폰 | 「매수 \| 매도 \| 수동」 탭의 매수 탭 한 열에 카드 4장 세로 스택(간격 10) | kv 단위로 줄바꿈 — 좁은 패널에서는 kv 하나당 한 줄이 흔하다. kv 안에서는 줄바꿈하지 않는다 | **기본 전부 접힘 상태의 매수 탭이 한 화면에 든다**(검증 훅: 뷰포트 390×844, 탭 줄 ~ 후매수 카드 끝 ≤ 660px). 행 폭이 넘치면 Phase 20 L3(폰 밴드 쉐브런 `›` 숨김)를 상따 설정 **전체**에 한 번에 적용한다(행마다 다르게 두지 않는다) |
| 컴팩트 | 매수 열(왼쪽)에 같은 스택 · 매도 열(오른쪽) 3그룹 | 열 폭이 좁아 폰과 비슷하게 접힌다 | 기본 접힘이 매수 열과 매도 열의 높이 차를 줄인다 |
| 와이드 | 같음 | kv 두세 개가 한 줄에 선다 | — |
| 데스크톱 | 같음 | 대부분 1~2줄 | 인라인 편집은 폭이 아니라 fine pointer 판정(Phase 20 D-12) |

- 네 밴드 모두 카드 구조·순서·기본 접힘이 **같다**. 밴드가 바꾸는 것은 가용 폭(요약 줄이 몇 줄로 접히는가 · 제목줄 상태가 둘째 줄로 내려가는가)뿐이다.
- 제목줄 상태 문구는 기존 규칙대로 제목 옆 흐름이다 — 길면(「켜짐 · 켠 매수 없음」 · 「무장 · 대기 · 후매수 발동」) 둘째 줄로 내려가고 말줄임하지 않는다. 헤더만 커지고 행 높이는 불변.
- 폭 분기는 `@min-[700px]/lc:` 등 **기존 컨테이너 쿼리 유틸만** 쓴다. 새 경계 숫자 0.

### 2. 그룹 카드 3장 (선매수 · 추가매수 · 후매수) — 접기

| 요소 | 값 |
|---|---|
| slot | `lc-group-pre-buy` · `lc-group-extra-buy` · `lc-group-post-buy` |
| 면 | `--group-bg` · radius 16 · 패딩 10 10 4 · 카드 사이 10(기존 그룹 카드 그대로) |
| 제목줄 | `flex items-center gap-2` 안에 **접기 버튼**(왼쪽, `flex-1 min-w-0`) + **그룹 스위치**(오른쪽 끝, 버튼 밖 형제) |
| 접기 버튼 | `<button type="button" aria-expanded aria-controls={행 영역 id}>` · `min-h-8`(32) · `-mx-0.5 px-1 pb-0.5` · radius 10 · fine pointer hover 면 `color-mix(--fg 5%)` · 포커스 링 전역. 내용 순서 = 제목(15/600 `--fg`, TY-1) → 쉐브런 `›`(14 `--faint`, `-ml-0.5`, `aria-hidden`) → 상태(12/400, 색은 「상태 문구 표」). 제목·상태 사이 공백 문자는 유지(줄바꿈 기회) |
| 쉐브런 | 접힘 = `›` 그대로 · 펼침 = 90° 회전 · `transition-transform 150ms` · `motion-reduce:transition-none` |
| 스위치 | 기존 `GroupSwitch` 그대로(40×24, 히트 44, 확인 없이 즉시). **접기 버튼 안에 넣지 않는다** — 버튼 안 스위치는 HTML 상 불가하고, 형제로 두면 전파 차단 없이 스위치가 접기와 독립으로 동작한다 |
| 접힘 | 제목줄 → (사전 검증 줄) → **요약 줄**. 행 영역은 `hidden`(display:none) — **언마운트하지 않는다** |
| 펼침 | 제목줄 → (사전 검증 줄) → 행 영역. 요약 줄은 `hidden` |
| 흐림 | 그룹 에코 OFF 면 요약 줄 또는 행 전체 흐림(아래 「흐림 규칙」) |

**접힘 상태 계약(재량 결정):**
- 보관: 폼 인스턴스(`LimitChaserForm`) 안 `useState` 하나 — `{ pre: false, extra: false, post: false }`(false = 접힘). 키는 그룹 slot 이라 **에코 재렌더·탭 전환(매수/매도)·밴드 변화에 풀리지 않는다**.
- 초기화: 폼 remount(삭제 후 `resetSeq` · 카드 제거/재추가 · 새로고침) 때만 기본값(전부 접힘)으로 돌아간다. localStorage 등에 저장하지 **않는다**.
- 기본: 네 밴드 모두, 그룹이 켜져 있어도 **접힘**(스케치 D 사용자 확정 — 켜진 그룹을 자동으로 펼치지 않는다).
- 자동 펼침은 **단 한 경우**: 그 카드 안 행의 값 확정이 거부·무응답으로 실패해 행 실패 말풍선(`FailureBubble`)을 띄워야 할 때 — 말풍선의 앵커 행이 숨어 있으면 실패가 보이지 않으므로 그 카드를 펼친다. 에코·그룹 켜기·사전 검증 실패로는 펼치지 않는다.
- 편집 중 접기: 인라인 편집기가 열린 채 그 카드 제목줄을 누르면 **기존 포커스 이탈 규칙이 먼저 돈다**(유효값 = 저장 · 위반값 = 취소, Phase 20 D-14 · A6) → 그 뒤 접힌다. 전송이 반영 중이어도 접힘은 진행된다(행은 CSS 숨김이라 확정 상태 기계는 계속 돈다). 터치 시트는 모달이라 열린 동안 제목줄을 누를 수 없다.
- 요약 줄은 접기 트리거가 **아니다** — 트리거는 제목줄(스위치 제외)뿐이다(스케치 README 사용자 확정).

### 3. 요약 줄 (`data-slot="lc-group-summary"`)

| 요소 | 값 |
|---|---|
| 상자 | `flex flex-wrap` · gap 세로 4 / 가로 10(SP-8) · 패딩 2(SP-2) 4 8 · 13px · line-height 1.4 |

**요약 항목 순서·표기(재량 — 스케치 009 D 순서 채택):**

| 카드 | 순서 | 값 표기 |
|---|---|---|
| 선매수 | 금액 → 매도잔량 → 체결량 → 한방 | 금액 「4,000만원」 / 0 → 「—」(꺼진 kv) · 매도잔량 「10,000주」 · 체결량 체크 ON 「30,000주」 / OFF 「꺼짐」(꺼진 kv) · 한방 체크 ON 「3건 @12,990원」 / OFF 「꺼짐」(꺼진 kv) |
| 추가매수 | 금액 → 최소 → 최대 | 최소 0 → 「1주」 · 최대 0 → 「무제한」(D-10 — 의미어는 꺼진 kv 가 아니다, 정상 색) |

| | 최대 | value · `postBuyReentry` · `lc-post-buy-reentry` | 회(0~255) · 「{설정}회」 / 단계 ≠ 0 「{설정}회 · 남은 {잔여}회」 |
| | (소진 안내) | 단계 3 일 때만 · `data-slot="lc-post-buy-exhausted"` | 아래 5절 |
| | 최소 잔량 | value · `postBuyFloorQty` · `lc-post-buy-floor-qty` | 주 · 0 → 「없음」 |
| | 반등 | value · `postBuyReboundPct` · `lc-post-buy-rebound` | % |
| | 발동잔량 | derived(읽기 전용) · `postBuyTriggerQty` · `data-slot="lc-post-buy-trigger"` | 아래 6절 |

- **표시 문자열(`valueText`)** 은 행 · 요약 · 시트 「지금 ○○」 · 접근성 이름이 **한 함수**에서 받는다(의미어 「무제한」「1주」「없음」, 「—」, 「3회 · 남은 2회」). 시트·인라인을 열면 숫자(0 포함)로 편집한다(D-10). 판정 지점이 둘이면 행과 요약이 다른 말을 한다.
- 「회」 단위: 상따 「최대」는 **0 을 허용**한다(0 = 사지 않음, D-30). 수동주문 조각 수의 「1회 이상」 규칙은 조각 수(`maxPieces` 가 있을 때)에만 건다. 시트 단축 칩은 기존 「회」 칩(1 · 3 · 5 · 10) 그대로, 0 은 키패드로 입력한다.
- 범위: 반등은 시트·인라인 입력 범위 1~100(후매수 켜는 방향 검증과 같은 값), 전송 직전 전 cfg 방어선(`lcRangeIssue`)은 0~100 — 레거시 에코 반등 0 이 다른 모든 확정을 막지 않게(RESEARCH Pitfall 4). 최대 0~255 · 한방 건수 0~255.

### 5. 후매수 소진 안내 줄

- 단계 3(소진) ∧ 펼침일 때 「최대」 행 바로 아래 한 줄. 12.5/400 `--muted-fg`(TY-4) · 패딩 2 6 6(SP-2 · SP-4) · line-height 1.45 · 역할 없음(정적 텍스트).
- 문구(스케치 원문): **「소진 — 「최대」에 횟수를 넣고 다시 켜면 그 값부터 세요」**.
- 접힘일 때는 그리지 않는다 — 접힌 카드는 상태 「소진」 + 요약 「3회 · 남은 0회」가 같은 사실을 말하고, 안내가 가리키는 「최대」 편집은 펼쳐야 가능하다.
- 소진의 세 신호는 **한 에코에서 동시에** 선다: 스위치 OFF(에코 `postBuyEnabled=false`) · 상태 「소진」(`postBuyPhase=3`) · 「남은 0회」(`postBuyReentryLeft=0`). 스위치만 보고 「꺼짐」이라 쓰지 않는다.

### 8. 체크 행 (선매수 「체결량」「한방」)

### 9. 흐림 규칙 (⑩ — WinForms 결)

| 대상 | 흐리는 조건 |
|---|---|
| 매수주문 공통 카드 행(주문가격 · 비교가격) | 마스터 에코 OFF |
| 선매수 · 추가매수 · 후매수 카드의 행 · 요약 줄 | 그 그룹 에코 OFF(마스터 OFF 면 D-32 로 세 그룹이 이미 OFF). 후매수 「보유중」은 에코 ON 이라 흐리지 않는다 |
| 체크 행의 라벨·값 · 체크에 딸린 행(한방 → 한방가격) | 그 체크 OFF |
| 매도 가격 섹션(주문가격 · 매도비율) · 매도주문 카드 행 | 매도 에코 OFF |
| 매수취소 「매수잔량」 · 「잔량추적」 | 매수취소 스위치(`cancelQtyEnabled`) OFF |
| 매수취소 「체결」 | 자기 체크 OFF 일 때만(독립 무장 축 — 스위치와 무관) |

- 흐림 = `opacity .45`(기존 값). **한 번만 곱한다** — 행마다 「그룹 OFF ∨ 체크 OFF」를 판정해 행 내용에 한 번 걸고, 그룹 컨테이너와 행에 겹쳐 걸지 않는다(.45 × .45 = .2 방지).
- 원형 체크 · 그룹 스위치 · 접기 버튼 · 사전 검증 줄 · 소진 안내 줄은 **흐리지 않는다**.
- 흐린 행도 **편집할 수 있다**(값을 미리 맞춰 두는 흐름 — Phase 20 D-01). 그래서 `aria-disabled` 를 쓰지 않는다(조작 가능한 것을 불가라고 말하게 된다).
- 가독성 복원: 흐린 행이 포커스를 가지거나(`:focus-within`) fine pointer 로 hover 되거나 편집 중이면 `opacity 1` 로 돌아간다 — 조작하는 순간에는 제 대비로 읽힌다. 비시각 경로: 행 값 버튼의 `aria-describedby` 가 카드 제목과 **상태 문구**를 함께 가리킨다(「주문가격 13,000원, 매수주문 꺼짐」).

### 10. 매수 LED (`latch-led.tsx` · D-12)

- 시트 「감시 중 — 적용하면 바로 반영돼요」 안내(D-05): 매수 쪽은 **그 행이 속한 카드의 스위치가 에코 ON 이면** 띄운다(공통 카드 = 마스터, 그룹 카드 = 그 그룹 — 「보유중」·「켜짐 · 켠 매수 없음」 포함). 매도 쪽은 기존 판정 그대로.

- 그룹 카드 안 행의 **보이는 라벨은 짧은 꼴**(「금액」「최소 잔량」「최대」「반등」)이다 — 카드 제목이 맥락을 준다. 시트는 카드 밖에 뜨므로 제목이 그룹 이름을 되살린다(위 표). 시트 「지금 ○○」 참고값은 `valueText` 그대로(예 「지금 무제한」 · 「지금 3회」 — 잔여가 아니라 설정값).
- **같은 라벨 두 벌의 구분(D-09):** 「매수잔량」(매도주문 · 매수취소) · 「주문가격」(매수 공통 · 매도 가격 섹션) · 「비교가격」(매수 공통 · 매도주문)은 **보이는 라벨·시트 제목이 같다**(WinForms 와 같게). 가르는 것은 ① 시트 설명(위 표) ② 행 값 버튼의 **접근성 이름 접두**:

| 행 | 접근성 이름(값 버튼 `aria-label`) |
|---|---|
| 매수 주문가격 · 비교가격 | 매수 주문가격 13,000원 · 매수 비교가격 13,000원 |
| 매도 주문가격 · 비교가격 · 매수잔량 | 매도 주문가격 13,000원 · 매도 비교가격 13,000원 · 매도 매수잔량 10주 |

- 구 형태 `lc.set`(신필드 없음): 「매수 설정 방식이 바뀌었어요 — 화면을 새로고침해 주세요」
- `lc.arm` `latch:"buy"`: 「매수 진입 래치는 없어졌어요 — 화면을 새로고침해 주세요」

## 접근성 계약

| 대상 | 계약 |
|---|---|
| 접기 제목줄 | `<button type="button">` · `aria-expanded="true|false"` · `aria-controls`=행 영역 id · 이름 = 보이는 제목 + 상태(「선매수 감시 중」 — 쉐브런 `aria-hidden`). Enter/Space 로 토글. 탭 순서: 접기 버튼 → 그룹 스위치 → (펼침이면) 행들. 접어도 포커스는 버튼에 남는다 |
| 그룹 스위치 | 접기 버튼 **밖 형제**(`role="switch"` · `aria-checked` · 이름 「{그룹} 켜기」). 접기와 독립 — 스위치를 눌러도 접힘이 바뀌지 않고, 접힌 카드에서도 스위치는 그대로 동작한다. 무장 불가면 `disabled` + 열 맨 아래 패널(기존) |
| 접힌 행 영역 | `hidden`(display:none) — 접근성 트리에서 빠지고 DOM 에는 남는다 |
| 요약 줄 | 정적 텍스트 · `aria-hidden` 없음 — 접힌 카드의 값이 스크린리더에도 읽힌다 |
| 사전 검증 줄 | `role="alert"` — 나타날 때 한 번 읽힌다. 문구 교체 때도 다시 읽힌다 |
| 소진 안내 | 정적 텍스트(역할 없음) |
| 발동잔량 행 | 비상호작용 텍스트 행(버튼 아님 · 탭 순서 밖) · 「—」 는 sr-only 「없음」 동반 |
| 흐린 행 | 조작 가능 그대로(`aria-disabled` 쓰지 않음) · `:focus-within`/hover/편집 중 `opacity 1` · `aria-describedby` 에 카드 상태 포함 |
| 매수 LED | 비상호작용 `<span>` · 보이는 라벨(OFF/감시/보유중)이 색 밖 텍스트 경로 · sr-only 「매수 상태 {라벨}」 · 보유중 툴팁은 포인터·포커스 모두에서 뜬다(기존 Tooltip) |
| 같은 라벨 두 벌 | 위 Copywriting 「접근성 이름 접두」 표 |
| 터치 대상 | 행 44 · 스위치 히트 44 · 체크 44 · **접기 버튼 높이 32**(가로는 제목줄 대부분 — WCAG 2.5.8 AA 24 이상 충족, 스케치 30 을 올린 값) |
| 색만으로 말하지 않기 | 상태 = 단어 · LED = 단어 · 발동잔량 = 숫자 자체(색은 보조) · 흐림 = 카드 상태 단어가 함께 있음 |

## UI Considerations

`ui-consideration-probe`(gsd-core 1.13.0 컴파일 엔진) 실행 2026-09-27 — 체커 승인(7/7) **뒤** 오케스트레이터가 실행. 요소 7개 · kind 확정은 오케스트레이터가 자율로 했다(휴리스틱 큐는 영어 전용이라 E3~E7 이 `unclassified` 로 나와 아래 kind 를 `elements` 오버라이드로 지정 — 사용자가 kind 를 고치면 이 절을 다시 만든다). **적용 29건 — resolved 27(explicit 22 · backstop 5) · dismissed 2 · unresolved 0.** 빈/오류 **문구**는 위 Copywriting 행을 가리키고 여기서 다시 적지 않는다.

**요소와 kind:** E1 매수 탭 카드 목록 = form + list-collection · E2 접기 제목줄 버튼 = interactive-control · E3 요약 줄 = static-content · E4 그룹 스위치 + 사전 검증 줄 = interactive-control + form · E5 후매수 상태(칩 · 최대 · 발동잔량 · 소진 안내) = static-content · E6 매수 LED = static-content · E7 전략 로그 줄 = list-collection.

표기: ✅ = resolved(explicit, 진술이 곧 검증 대상) · 🧪 = resolved(backstop, `{ statement, verification: backstop }` — 실측·e2e 증거 없으면 verify 때 `human_needed`) · ✖ = dismissed(사유 필수).

## relay 의존 (이 계약의 전제 — 범위 밖)

- ①~④ 가 먼저 서야 이 화면이 참이다: `buy3_schema=1` · 신필드 13 전송 · S→C 4필드(`extraBuyAbandoned` · `postBuyTriggerQty` · `postBuyReentryLeft` · `postBuyPhase`) 파싱 · `buyWatchSide` 미전송 · MsgType 38 경로 제거 · 후매수 에코 = cfg ∧ 마스터 무장 ∧ 단계 ≠ 소진(D-21).
- 무장 판정은 웹 `canArmOf`(첫 관문)와 relay `#strategyArmable`(마지막 관문)이 **같은 식**이어야 한다 — 이 계약의 「켤 수 없는 이유」·사전 검증 순서는 그 식의 표시일 뿐이다.
- 구 탭 거부 문구 2종(위 Copywriting)은 relay 가 소켓을 끊지 않고 거부 프레임으로 돌려줄 때 쓰는 문구다.
- 배포 순서(서버 → WinForms → relay → webapp push)는 CONTEXT 고정 — 이 문서는 바꾸지 않는다.

## 검증 훅 (감사·e2e 가 잴 것)

- 매수 탭 DOM 순서: `lc-group-buy` → `lc-group-pre-buy` → `lc-group-extra-buy` → `lc-group-post-buy`. `lc-group-buy-price` · `lc-group-sweep` · `lc-watch-row` **부재**.
- 첫 렌더에서 세 그룹 접기 버튼 `aria-expanded="false"` · 행 영역 `display:none` 이지만 DOM 존재 · 요약 줄 표시. 에코 재렌더 뒤에도 사용자가 펼친 카드는 펼친 채.
- 스위치 클릭은 `aria-expanded` 를 바꾸지 않는다. 접기 버튼 클릭은 `lc.set` 을 보내지 않는다.
- 모든 행(발동잔량 포함) 높이 정확히 44px · 접기 버튼 높이 ≥ 32px.
- 폭: 본문 344/700/830/992 최악값에서 패널 가로 넘침 0 · 라벨·값·요약 kv 잘림 0 · 말줄임 유틸 0.
- 폰 한 화면: 390×844 · 기본값 · 세 카드 접힘 → 매수 탭 높이 ≤ 660px.
- 흐림: 꺼진 그룹 행 `opacity .45` 한 겹(계산값 0.45, 0.2025 아님) · 원형 체크·스위치·접기 버튼 불투명.
- 사전 검증 6경로: 전송 0건 · 스위치 OFF 유지 · `lc-group-precheck` 문구 일치 · D-16 은 `lc-group-precheck` 부재 + 로그 원문 1줄.
- D-01: 전송 1건에 그룹 `true` + `buyEnabled: true` · 로그 「선매수 체크 — 매수주문도 켬」 1줄(마스터·그룹 전이 문장 없음).
- D-02: 마지막 그룹 끔 → 전송 1건에 `buyEnabled: false` · 서버 접힘 **하강 전이** 에코 → 다음 틱 전송 **1건**(`buyEnabled: false` · crud `C`) · 매도·취소 게이트 전부 OFF 면 0건 · 같은 에코 재수신/재접속 snap/자기 에코 → 0건 · 실패 시 마스터 ON 복원 · 재시도 0.
- LED: 매수 LED 가 모든 에코에서 `<span>`(버튼 부재) · 단계 2 → `data-tone="latent"` 라벨 「보유중」.
