Phase 16 — 트레이딩 › VI 변동성완화 종합주문 (채택안 · D-24 반영)

시나리오: | 데드라인 1단계:
gh-trade [0402] 변동성완화 종합주문 → 웹. 설정은 세션당 1건(종목 축 없음, KRX 전용, 주문가 = 상한가 고정이라 주문유형 UI 없음). 입력 4개: 계좌 · 금액(만원) · 상승률(%) · VI 마감알림(브라우저 로컬, 이 기기만).
D-24(a) 수정 — 「0.3초 자동 반영」 폐기. 계좌·금액·상승률을 바꾸면 더티 표시 + 하단 「수정」 액션 바가 나타나고, 「수정」이 SetVITrigger(run 은 현재값 유지)를 보낸다(D-07). 시작/중지는 확인 다이얼로그 — 호가주문 탭의 주문 확인과 같은 규율. 중지 상태에서 「시작」은 현재 폼 값으로 run=true 전송.
D-24(b) 수정 — 신규 토큰 0개. 110초/119초 데드라인은 2단계로만 표현한다: 여유(≥20초) = 중립 --muted-fg, 임박(<20초) = --destructive. 초안의 주황(--warn)은 globals.css 에 없으므로 쓰지 않는다(툴바에서 비교 가능).
VI 주문내역: 확인 체크(= 119초 미확인 자동취소 면제, ConfirmVIOrderReq 33 즉시 전송 · 수정 버튼 대상 아님, D-10) · 상태 6종(접수 전/접수/부분체결/체결/취소/거부). 모바일은 카드 행, 데스크톱은 표.
모바일 세로 순서: 상태줄 → 설정 → 시작/중지 → VI 주문내역 → 미체결 → 잔고 (미체결·잔고는 표 대신 2줄 카드 행). 데스크톱은 좌 420px(설정·시작/중지) / 우 미체결 → 잔고 2열이고, VI 주문내역(9열)은 그 아래 전폭이다.
