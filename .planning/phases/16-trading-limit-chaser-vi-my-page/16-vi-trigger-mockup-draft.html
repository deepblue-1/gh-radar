Phase 16 — 트레이딩 › VI 변동성완화 종합주문 (모바일 390 기준)

상태 시나리오:
gh-trade [0402] 변동성완화 종합주문 → 웹. 설정은 세션당 1건(종목 축 없음, KRX 전용). 입력 5개 그대로: 계좌 · 금액(만) · 상승률(%) · 시작/중지 · VI 마감알림(브라우저 로컬). 주문가 유형은 상한가 고정이라 UI 없음.
WinForms 의 "상승률 체크박스 = 시작" 을 웹에서는 확인 다이얼로그 붙은 시작/중지 버튼으로 바꿨다(오조작 방지, 호가창 주문 패널과 같은 규율). 금액·상승률 변경은 0.3초 뒤 자동 반영.
VI 주문내역: 확인 체크(=119초 미확인 취소 면제) · 110초/119초 데드라인 진행바 · 상태 6종(+부분체결). 모바일은 카드 행, 데스크톱은 표. 아래에 미체결(전체/KRX/NXT 필터 + 전체취소) · 잔고.
