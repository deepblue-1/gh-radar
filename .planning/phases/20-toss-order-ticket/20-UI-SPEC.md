**Accent 전용 자리(이 목록 밖에서 `--primary` 를 쓰지 않는다):**
1. 켜진 그룹 스위치 트랙
2. 켜진 체크 값 행의 원형 체크 채움
3. 「확인」 버튼 면(시트)
4. 인라인 편집 행의 1.5px inset 링
5. 시트 디스플레이 캐럿(2×26px) · 첫 입력 대기(전체 선택) 강조 면(`color-mix(--primary 32%)`) · 인라인 입력 선택 영역(`color-mix(--primary 35%)`)
6. 확정 직후 행 값 강조(900ms, D-18)
7. 포커스 링(전역 `--ring`, 기존)

**방향색(가격 방향 축 — accent 와 다른 축, 기존):** `--up` = 매수 버튼 면 · ≥700 「매수」 열 머리 점 / `--down` = 매도 버튼 면 · 「매도」 열 머리 점. `--down` 과 `--primary` 는 TDS 에서 같은 blue500 이다 — 매도 버튼은 **글자 「매도」와 위치(오른쪽)** 가 함께 말한다(WCAG 1.4.1, 기존 3중 일치 규율).

**상태색(기존 토큰 재사용):** 그룹 상태 「감시 중」 = `--led-armed` · 그 밖의 상태 문구 = `--muted-fg`. 감시대상 토글 선택 = `--seg-on-bg`/`--seg-on-fg`/`--seg-on-shadow`(중립 선택 — 260924-vj1 유지, 방향색 소멸 D-02) · 토글 트랙 = `--raised-2`. 행 hover·인라인 편집 행 면 = `color-mix(in srgb, var(--fg) 5%, transparent)`.

**텍스트:** 행 라벨·시트 설명·상태 = `--muted-fg`(grey600) · 행 값·단위·상자 라벨 = `--fg-2`(grey800) · 그룹 제목·시트 제목·디스플레이 숫자·상자 값 = `--fg`(grey900) · 쉐브런 `›`·자리표시 = `--faint`(grey400).
