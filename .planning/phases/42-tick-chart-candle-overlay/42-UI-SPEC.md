# Phase 42 — UI Design Contract

> 틱뷰어(`/analytics/ticks`) 차트 카드에 「봉 차트」 를 더한다 — 분봉 · 거래대금 막대 · 이동평균 · 수익률 판 · 누적 평단을 지금의 팀 매집 표시와 한 시간축에 겹친다. gsd-ui-researcher 가 만들고 gsd-ui-checker 가 검증한다.
> **이 계약은 채택 목업을 옮긴 것이다.** `42-CONTEXT.md` D-01 ~ D-20 과 채택 목업(`reference/mockup-combined-strip.html` = 종합본 · 최신, `mockup-candle-price-panel.html` · `mockup-return-lines.html` 은 CONTEXT 가 이름 붙인 부분만)이 보여 주는 배치 · 문구 · 판 높이 · 선 모양은 확정이다. 다시 열지 않는다. 목업의 hex(`--ma5` · `--ma20` · `--ma60` 등)는 프레임 값이다 — 구현은 `webapp/src/styles/globals.css` 토큰을 쓴다. 기존 틱 차트는 SVG 속성에 `var(--token)` 을 그대로 쓴다(`fill="var(--up)"`) — 봉 차트도 같다(oklch 를 거부하는 것은 `lightweight-charts` 뿐이고 이 차트는 그것을 쓰지 않는다 · D-01).
> **새로 정한 것**은 `(researcher decision)` 표시 — 「Researcher Decisions」 절에 모았다.
> **조작 목업 채택(사용자 검토 2026-11-12):** CONTEXT 가 「UI 설계 단계에서 목업으로 확정」 으로 미룬 세 모양은 `reference/mockup-chart-controls.html` 검토로 정해졌다 — 폰 제목 줄 = **B 둘째 줄 가로 밀기**(D-21) · 이동평균 더하기 창 = **A 한 장 양식**(D-22) · 봉 단위 메뉴 = **A 펼침 목록**(D-23). 같은 검토에서 **전환할 때 보던 시간 구간을 유지**(D-24)가 더해졌다. 목업 파일에는 기각된 B · A 화면도 남아 있다 — 정본은 각 절이 이름 붙인 화면(P1 ~ P9 · D1 ~ D6, 채택 고르기 상태)뿐이다.
> **용어:** 화면 낱말은 「선 차트」 「봉 차트」 「자동」 「5분봉(자동)」 「단순 5」 「지수 20」 「일 20」 「누적 평단(보고서)」. 「SMA · EMA · 캔들 · 오버레이」 는 화면에 쓰지 않는다.

## 표면별 계약

### S1. 「선 차트 | 봉 차트」 전환 스위치 + 보던 구간 유지 (D-02 · D-03 · D-05 · D-24)

- **자리:** 두 차트 모두 제목 줄 「타임라인」 바로 뒤. 같은 컴포넌트 하나를 두 차트가 같은 자리에 그린다. 선 차트 폰 제목 줄은 기존 `flex-wrap` 이 알아서 접는다(별도 손질 없음).
- **선 차트 파일(`tick-chart.tsx`) 변경 범위(성공 기준 1 = 「스위치 연결부 + 보기 창 주고받는 선택 입력 2개」):** 선택 입력 3개뿐 — ① 제목 뒤 스위치 노드 ② 처음 보기 창 받기 ③ 보기 창이 바뀔 때 알리기(이름은 예시: `titleAddon` · `initialView` · `onViewChange`). 셋 다 주지 않으면 지금과 똑같이 동작하고 기존 테스트는 그대로 통과한다. ②는 마운트 때 한 번만 적용한다(그 뒤 바뀌어도 다시 적용하지 않음). `useChartView` 훅 자체는 고치지 않는다.
- **모양:** 트랙 `inline-flex rounded-full bg-[var(--muted)] p-0.5` · 칸 데스크톱 `h-5 px-2 text-[11px]` / 폰 `h-7 px-2 text-[12px]` · 켜짐 `--seg-on-*` 600 · 꺼짐 `--muted-fg` 400 · hover 꺼짐 칸 글자 `--fg`.
- **동작:** 누르면 즉시 그 차트로 바뀌고 차트 종류는 S10 에 기억. 처음(기억 없음) = 선 차트(D-02). 같은 종목 · 같은 날짜 · 같은 현재 틱(커서)은 유지된다(둘 다 뷰어의 같은 `cursorRec` 을 받는다).
- **보던 구간 유지(D-24):**
  - 마지막 보기 창은 뷰어(`tick-viewer.tsx`)가 쥔다. 두 차트는 보기 창이 바뀔 때마다(휠 · 끌기 · 핀치 · 키 · 확대 버튼) 뷰어에 알린다. 뷰어는 이 값을 화면을 다시 그리지 않는 곳(ref)에 둔다 — 휠 한 번마다 뷰어가 다시 그려지지 않게.
  - 알리는 값 = 그 창의 `[시작, 끝]` 시각(수신 ms). 「전체」 프리셋이 켜져 있으면 프리셋 이름도 같이 보내고, 받는 차트는 숫자 창 대신 그 프리셋을 다시 적용한다(당일 화면에서 「전체」 가 새 틱을 따라 늘어나는 동작이 유지되게).
  - 바꾼 차트는 같은 `[시작, 끝]` 창으로 열린다. 그 차트의 최소 창(10초)과 하루 경계(08:00 ~ 20:00)로 자른다 — 두 차트가 같은 값이라 실제로는 그대로 열린다.
  - 봉 차트의 「자동」 봉 단위는 받은 창으로 다시 고른다(S2). 고정 단위는 그대로 쓴다.
  - **Shift+끌기 구간 합계는 지운다** (researcher decision): 구간은 선 차트 안 상태라, 유지하려면 받기 · 알리기 입력이 한 쌍 더 필요하다. 사용자가 받아들인 「입력 2개」 범위를 넘고, 구간은 Shift+끌기 한 번이면 다시 만든다.
  - **처음 창으로 돌아가는 경우:** 종목 · 날짜 · 거래소(KRX/NXT)가 바뀌면 기억한 창을 지우고, 그때 그리는 차트는 지금과 같은 기본 창으로 연다.
  - 보기 창은 **브라우저 저장소에 남기지 않는다**(그 화면의 메모리에만 · 새로고침하면 기본 창).
- 모든 틱뷰어 사용자에게 보인다(D-03 · 권한 분기 없음).

### S3. 이동평균 칩 · 「＋」 · 더하기 창 — A 한 장 양식 (D-10 · D-11 · D-22)

채택 = **A 한 장 양식**(사용자 검토 2026-11-12 · 정본 화면 = 목업 「이동평균 더하기 A」 상태의 P4 ~ P7 · D2 · D3). 기각 = B 자주 쓰는 선 버튼 묶음 + 「직접 넣기」(프리셋 목록을 따로 유지해야 함).

**칩:**
- 칩 하나 = 켜기 칸 + × 칸이 붙은 알약. 켜기 칸: 색 줄(8×2 `rounded-[1px]` `var(--ma-n)`) + 이름 · `aria-pressed`. × 칸: 글자 「×」 `--muted-fg`(hover `--fg`) · 데스크톱 20px · 폰 28px 폭.
- 켜짐 = `--muted` 면 · `--fg` 600 · 색 줄 불투명 1. 꺼짐 = 투명 면 · 안쪽 1px `--border-subtle` · `--muted-fg` 400 · 색 줄 .35. 켜기 칸을 누르면 켜고 끄기(선 · 판 제목 이름 · 값 띠 값이 같이 사라지고 나타난다). × 를 누르면 확인 없이 지운다.
- 순서 = 더한 순서(새 칩은 맨 뒤). 처음 상태 = 「단순 5」(`--ma-1`) · 「단순 20」(`--ma-2`) 켜짐(D-10).
- **색 배정** (researcher decision): 새 선은 비어 있는 가장 작은 번호(1 ~ 6)를 받고 S10 에 같이 기억된다. 지우면 그 번호가 빈다 · 켜고 끄기는 번호를 바꾸지 않는다(선 색이 바뀌지 않는다).
- **상한:** 칩 6개(켜짐 + 꺼짐 합)면 「＋」 는 `aria-disabled="true"` · 불투명도 .4 · 누르면 아무 일 없음 · `title` = 문구 표. (`disabled` 가 아니라 `aria-disabled` — 초점과 `title` 이 남게.)
- 데스크톱 칩 앞 머리 글자 「이동평균」 11 `--muted-fg`. 칩이 0개면 머리 글자 + 「＋」 만 · 폰은 「＋ 이동평균」.

**더하기 창:**
- 여는 면: 뷰포트 768 이상(앱 셸 아님) = `Popover`(「＋」 아래 `align="start"` `sideOffset={8}`) · 그 밖 = 바텀 `Sheet`(push 시트 꼴 — 손잡이 36×4 `--raised-2` · 제목 16/600 · `showCloseButton={false}`). 열림 상태는 하나(push-alert-bell 패턴).
- 줄(위 → 아래): 제목 「이동평균 더하기」 → 기준 나눔 칸 「봉 | 일」 → 기간 칸 + 「2 ~ 240」 → (오류 줄) → 종류 나눔 칸 「단순 | 지수」 → (일이면 안내 줄) → 버튼.
- 나눔 칸: 트랙 `--muted` `rounded-[10px] p-0.5 w-full` · 칸 `flex-1 h-7`(시트 `h-9`) `rounded-[8px]` · 켜짐 `--seg-on-*` 600. 일 기준이면 「지수」 칸 `disabled` 불투명도 .4 · 종류는 「단순」 으로 고정 · 안내 줄 「일 기준은 단순 평균만 있어요」.
- 기간 칸: `Input` · 폭 96(시트 120) · 높이 32(시트 40) · `--muted` 채움 · `rounded-[8px]` · 숫자 `mono` 오른쪽 정렬 14/600(시트 16/600) · 칸 안 뒤 글자 「봉」/「일」 · `inputMode="numeric"` · 숫자만 받고(다른 글자는 입력되지 않음) 최대 3자리 · 앞 0 은 지운다.
- 검증(입력할 때마다):
  - 빈 칸 → 오류 줄 없음 · 확인 버튼 「더하기」 꺼짐.
  - 2 미만 · 240 초과 → 칸 `aria-invalid`(안쪽 1px `--destructive`) + 오류 줄 「기간은 2 ~ 240 사이 숫자로 넣어 주세요」 · 버튼 꺼짐.
  - 같은 기준 · 기간 · 종류의 칩이 이미 있음(켜짐 · 꺼짐 무관) → 오류 줄 「이미 있는 선이에요 — 단순 20」 · 버튼 꺼짐.
  - 통과 → 버튼 「{이름} 더하기」 켜짐.
  - 오류 · 안내 줄 12px · 라벨 칸 뒤로 들여쓰기(팝오버 48 · 시트 60) · 오류는 `role="alert"`.

### S4. 봉 차트 제목 줄 배치 (D-05 · D-19 · D-21)

**데스크톱:** `flex flex-wrap items-center gap-x-2 gap-y-1 border-b px-3 py-[7px]`(선 차트 상속) — 「타임라인」 → 스위치 → 봉 단위 버튼 → [「이동평균」 + 칩들 + 「＋」](`inline-flex flex-wrap items-center gap-1`) → 우리 범례(선 차트와 같은 「◆ 우리 체결 · ○ 조건 근거」 · `own` 있을 때) → `ml-auto` [창 폭 글자 「2.0시간」 + 확대 버튼 5개](선 차트 `btn` 그대로). 선 차트의 긴 범례 글자(「가격 · 팀 평단 · …」)와 누적 범례 글자는 봉 차트 제목 줄에 두지 않는다 — 판 제목(SVG)과 카드 아래 캡션(S9)이 맡는다. 칩이 많아 넘치면 우리 범례 · 확대 묶음이 다음 줄로 내려간다(목업 D6).

**폰 — B 둘째 줄 가로 밀기**(D-21 · 사용자 검토 2026-11-12 · 정본 화면 = 목업 「제목 줄 접힘 B」 상태의 P1 ~ P3, 그리고 같은 상태로 그린 P4 ~ P9 의 제목 줄). 기각 = A 줄바꿈(칩 6개면 제목 줄이 4줄이 되어 차트가 내려감). 제목 줄은 칩 수와 무관하게 언제나 두 줄이다.

계약:
- 틀: `grid gap-y-1 border-b px-3 py-2`.

### S5. 가격 판 — 봉 · 거래대금 · 이동평균 · 겹침 (D-06 ~ D-11 · D-15 · D-16 · D-19)

- **시선 첫 자리(초점):** 가격 판의 봉. 가장 큰 판이고 화면에서 유일하게 방향색으로 채운 덩어리다. 그다음이 값 띠 첫 칸(종가 12/600), 마지막이 제목 줄 조작이다(`--muted` 면 · 11px · 낮은 대비 — 봉과 겨루지 않게).

- **봉 집계** (researcher decision): 체결(A3)을 **차트 시간축과 같은 수신 시각**으로 KST 벽시계 단위 경계에 묶는다(5분봉 = 10:15:00.000 ~ 10:19:59.999 · 60분봉 = 정시 시작). 시가 = 첫 체결가 · 고 · 저 · 종가 = 마지막 체결가 · 거래대금 = Σ(가격 × 수량). 단일가(시가 · 종가 동시호가) 체결도 따로 다루지 않고 수신 시각의 봉에 들어간다(09:00:0x → 09:00 봉 · 15:30:0x → 15:30 봉). 체결이 없는 구간은 봉이 없다(15:30 ~ 16:00 · 장전 빈 분). 세션 · 단위마다 한 번 집계해 캐시(성공 기준 7) · 당일 화면은 마지막 봉만 새 틱으로 갱신.
- **자리:** 봉 칸 = `[단위 시작, 단위 끝)` 의 x 구간 · 몸통 · 꼬리 · 막대는 칸 가운데.
- **몸통 폭** (researcher decision): `min(14, 칸 폭 × 0.7)` px · 칸 폭 < 3px 이면 몸통 없이 고–저 꼬리(1px 방향색)만. 몸통 높이 최소 1px(시가 = 종가). 꼬리 1px `vector-effect: non-scaling-stroke`.
- **색:** 종가 ≥ 시가 `--up` · 종가 < 시가 `--down` · 채움 불투명(목업).
- **거래대금 막대:** 가격 판 아래 32px(폰 22) · 몸통과 같은 x · 폭(꼬리만일 때는 `max(1, 칸 폭 × 0.7)`) · 높이 = 보기 창 안 봉 거래대금 최대 대비 · 최대 `영역 − 2` · `fill-opacity .38` · 축 글자 없음(값은 값 띠).
- **가격 범위:** 보기 창과 겹치는 봉들의 최저 저가 ~ 최고 고가 + `tickPriceRangeOf` 와 같은 여유(폭 × 8% · 폭 0 이면 가격 × 0.5%). 이동평균 · 누적 평단 · 일 이동평균은 범위를 넓히지 않는다(D-16). 왼쪽 축 = 보이는 최고 · 최저가 두 개(선 차트와 같은 자리).
- **틱 선 없음**(D-08).
- **이동평균 선:** 켜진 칩마다 봉 가운데를 잇는 선 · 1.25 · `stroke-linejoin="round"` · `var(--ma-n)` · 봉 영역으로 자른다(거래대금 막대 영역에 넘어가지 않는다).
  - 봉 기준 단순 N = 그 봉 포함 앞 N 봉 종가 평균 · 그날 N 번째 봉부터.
  - 봉 기준 지수 N = 계수 2 ÷ (N + 1) · 첫 값 = 처음 N 봉 단순 평균(N 번째 봉) — 그 전은 없음.
  - 일 N = (보는 날짜 앞 N − 1 거래일 종가 합 + 그 봉 종가) ÷ N(D-11) · 봉마다 한 점. 앞 거래일 종가가 N − 1 개 미만이면 그리지 않는다.
  - 봉은 그날 것만 센다(전날 봉 없음). 30분 이상 봉이 없는 구간(15:30 ~ 16:00 등)을 건너는 곳에서는 선을 끊는다 (researcher decision) — 그보다 짧은 빈 분은 잇는다.
- **가장자리 글자** (D-16 · researcher decision 으로 모든 이동평균에 같은 규칙): 어떤 선(누적 평단 · 이동평균)이 보기 창 안에서 **한 점도** 가격 범위 안에 들어오지 않으면 선 대신 글자 「{이름} {값} ▾/▴」 만 남긴다(값 = 보기 창 안 마지막 점). 일부라도 들어오면 선을 그리고 잘라 낸다.
  - 아래 밖(▾): 왼쪽 `x = L + 4` · 첫 글자 기준선 `봉 영역 아래 − 4` · 위로 13px 씩 쌓음. 위 밖(▴): 오른쪽 끝 정렬 `x = xr − 4` · 첫 기준선 데스크톱 `y1a + 24`(판 제목 줄 아래) · 폰 `y1a + 11` · 아래로 13px 씩.
  - 순서 = 누적 평단 먼저 · 이동평균은 칩 순서. 한 가장자리에 데스크톱 5개 · 폰 3개까지 · 넘치면 마지막 자리에 「외 {n}개 ▾/▴」.

## 접근성 계약

- 스위치 = `role="group"` + `aria-pressed` 버튼 2개. 봉 단위 = 버튼(`aria-haspopup="dialog"` `aria-expanded`) + `radiogroup`. 칩 = `role="group"` 안 켜기 버튼(`aria-pressed`) + 지우기 버튼(`aria-label`). 「＋」 상한 = `aria-disabled` + `title`.
- 더하기 창: 팝오버 · 시트 모두 `role="dialog"` · 제목으로 `aria-labelledby`. 라벨은 `<label htmlFor>`(나눔 칸은 `role="radiogroup"` + `aria-label="기준"` / `"종류"`). 기간 칸 `aria-invalid` + `aria-describedby` = 오류 줄 id.
- SVG `role="img"` + 접근 이름(문구 표) · 판 제목은 `aria-hidden`(선 차트와 같음).
- 키보드: 차트 래퍼 `+ − 0`(선 차트와 같음) · 목록 ↑ ↓ Enter Esc · 양식 Enter Esc · 닫히면 초점은 연 버튼으로.
- 터치에서는 포커스 링을 그리지 않는다(전역 규칙 · 되살리지 않는다).

## Researcher Decisions

CONTEXT 「Claude's Discretion」 과 목업이 정하지 않은 자리를 기존 출하 부품과 가장 가까운 보수적 선택으로 메웠다. 플래너가 근거 없이 바꾸지 않는다.

1. **봉 경계 = 수신 시각 · KST 벽시계 단위 경계** · 동시호가 체결은 수신 시각의 봉에 그대로 · 체결 없는 구간 = 봉 없음(S5).
2. **이동평균 색 6개 = 새 토큰 `--ma-1` ~ `--ma-6`**(초록 · 갈색 · 자홍 · 올리브 · 남색 · 청록 · 라이트/다크 둘 다 · 3:1 이상) · 목업 `--ma5` 노랑은 `--vi` 와 겹쳐 버림. 새 선 = 빈 가장 작은 번호 · 번호는 기억에 같이 저장(Color · S3).
3. **일 이동평균 = 단순만**(D-11 정의식이 단순 평균) · 일 기준이면 「지수」 칸 꺼짐 + 안내 줄(S3).
4. **기간 범위 2 ~ 240**(봉 · 일 같음 — 1분봉 하루 최대 ≈ 720 봉 · 일봉 240 ≈ 1년 · 일별 종가는 5년까지 있음) · 같은 선 금지(S3).
5. **저장 키 3개 · 실패 시 기본 · 항목 단위 검사 · 빈 배열 존중**(S10).
6. **봉 몸통 최대 14px · 칸 폭 × 0.7 · 칸 폭 3px 미만이면 꼬리만**(S5).
7. **수익률 판 0% 맞춤 = 목업 수식(z 공유 · 0.15 ~ 0.85)** · 눈금 = 위 · 아래 끝 값 하나씩 · 부호 + 소수 1자리(S6).
8. **가장자리 글자 규칙을 모든 이동평균에 적용**(일 이동평균만이 아니라) · 쌓는 자리 · 최대 개수 · 「외 n개」 · 글자 테(S5).
9. 이동평균 선은 30분 이상 봉이 없는 구간에서 끊는다(S5).
10. 당일 수익률 점 간격 = 그림 폭 1px 마다 + 팀 체결 시각마다(S6).
11. 값 띠 높이 고정: 데스크톱 88 · 폰 137 · 첫 칸 비율 1.5fr · 폰 이동평균은 색 줄 + 값 · 현재 틱 표시는 머리 글자 색(S8).
12. 봉 차트 제목 줄에 선 차트의 긴 범례 · 누적 범례를 두지 않고 판 제목 · 카드 아래 캡션으로(S4 · S9) · 폰 우리 범례도 캡션 줄로 · 폰 창 폭 글자 숨김(S4).
13. 칩 「×」 = 확인 없이 지움 · 「＋」 상한은 `aria-disabled`(S3).
14. 더하기 창: 열 때마다 「봉 · 빈 칸 · 단순」 으로 시작 · 첫 초점 팝오버 = 기간 칸 / 시트 = 컨테이너 · 팝오버 ↔ 시트 = 뷰포트 768(push 시트 규칙)(S3).
15. 봉 단위 목록은 `dropdown-menu` 설치 없이 `Popover` + `radiogroup`(Design System).
16. 전환 때(D-24 위에서) 보기 창은 뷰어 ref 에 두고 「전체」 프리셋은 이름으로 넘긴다 · Shift+끌기 구간은 지운다(입력이 한 쌍 더 필요해서) · 종목 · 날짜 · 거래소가 바뀌면 기억한 창을 지운다 · 저장소에 남기지 않는다(S1).
17. 봉 단위 버튼 글자 = 「5분봉(자동)」 / 「15분봉」 — 폰에는 판 제목이 없어 지금 단위를 버튼이 말한다(S2).
