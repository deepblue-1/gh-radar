  • 앞으로 「오늘 주문」은 브라우저 접속과 무관하게 계좌 기준으로 빠짐없이 기록됩니다. 화면을 닫아 둔 사이에 난 체결·취소도 다시 열면 그대로 있습니다.
  • 기준이 「로그인한 사람」에서 「계좌」로 바뀌므로 같은 계좌에서 WinForms(gh-trade 클라이언트)로 낸 주문, 다른 DMA 사용자가 낸 주문도 함께 목록에 섞입니다.
  • 기록을 맡는 관찰자 연결이 끊기면 카드에 「기록 지연」 표식이 뜹니다(이미 결정됨). 복구되면 빠진 줄이 채워집니다.
  • 채택: B′ — 계좌별 묶음(B)에 줄마다 출처 칩(상따·VI·수동)과 NXT 태그를 더한 안. 맨 위 절이 채택안이고, 0·A·B·C 는 검토 기록으로 아래에 남겨 둡니다.

초록 점선 = 이번에 새로 생기는 요소(상단 「새 요소 표시」로 끌 수 있음). 나머지는 지금 코드 그대로입니다. 각 안은 폰 390(본문 374px)과 데스크톱(뷰포트 1280 · 본문 992px — 이 카드가 표로 바뀌는 첫 폭)을 같이 그립니다.

예시 데이터 — 모든 안이 같은 8줄(통보 11건)을 씁니다. 계좌 12345678-01 · 위탁종합, 12345678-02 · 위탁CMA.

굵은 2줄 = 같은 계좌(-01)를 쓰는 WinForms 단말에서 낸 주문 — 지금 카드에는 안 보이고, 바뀐 뒤에는 보입니다. 출처(상따·VI)와 거래소(KRX·NXT)는 지금 카드에 표시되는 칸이 없어 0·A·B·C 그림에는 나오지 않고(「· 수동」 꼬리표만 있음), B′ 에서 새로 드러납니다.

B′ — 채택안 (계좌별 묶음 + 출처 + NXT) 채택

B 의 계좌별 묶음 위에 두 가지를 더합니다. ① 출처 칩 — 모든 줄에 상따 · VI · 수동 중 하나. 미체결 행의 출처 배지(account-panel OriginTag)와 같은 회색 칩이라 새 색이 없습니다. 칩이 「수동」을 말하므로 구분 칸의 「· 수동」 꼬리표는 뺍니다. ② NXT 태그 — NXT 주문에만, 종목 코드 옆에 붙습니다(ExchangeTag 채움형). KRX 는 기본값이라 태그가 없습니다.

폰: ①줄 = 종목명 · 코드 · NXT · 구분 · 출처 · (우) 상태. 종목명만 줄어들 수 있고(말줄임) 나머지는 고정 폭입니다. ②줄이 넘치면 주문번호가 다음 줄로 내려갑니다. 데스크톱: 「출처」 칸이 구분 뒤에 새로 생기고, NXT 는 종목 칸 안에 붙습니다.
