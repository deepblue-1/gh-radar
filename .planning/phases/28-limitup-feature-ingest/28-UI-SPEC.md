## Typography

**선언 척도(이 phase 가 새로 그리는 글자): 크기 4개(20 · 14 · 12 · 11) · 굵기 2개(400 · 600).** 위계는 크기보다 **색 대비**로 만든다(레퍼런스 실측 규율 — 과장 금지). 재사용 원자(`PageHeader` 제목 22/700 · 카드 탭 트리거 11/600 · 필터 칩 11 · F-A 로그 줄 11 · `DmaGate`)는 기존 그대로이며 이 척도에 새로 들어오지 않는다.

**상속 예외(명시):** `/analytics/limitup` 은 기존 `PageHeader` 22px/700 을 그대로 쓰므로 페이지에는 실제로 크기 5개(22 · 20 · 14 · 12 · 11) · 굵기 3개(400 · 600 · 700)가 보인다 — 22/700 은 앱 전체 페이지 제목 원자의 값이라 이 phase 가 재협상하지 않는다. 11px 과 12px 은 1px 차이라 위계가 약하지만 11px 은 카드 탭 기하(EX-1 행 높이 ≈23.8px 안의 행 머리 · 기존 탭 트리거 · F-A 줄)에 묶인 상속값이고, 보고서 페이지에서는 11px 을 **태그·배지·레인 오버레이** 세 자리에만 쓰고 본문 글자는 12px 이상으로 둔다.

**표면별 시각 앵커(가장 먼저 눈에 들어와야 하는 것 하나):** 카드 탭 「상한가」 = 지금 행 첫 칸 「잠김 N초째」(600 · `--up` — 나머지 8칸은 400 · `--fg`) · 주문로그 kind 15 줄 = 「잠김 N초」 조각(600 · `--up` — 나머지 본문 `--muted-fg`) · `/analytics/limitup` = **KPI 띠의 20px `mono` 값**(페이지에서 유일한 20px — 하루 격자·사건 카드는 14/12 로 그 아래 층) · 사건 카드 안 = 종목명 `h3`(14/600) 와 레인 2 의 깨짐 ● + 「깨짐 HH:MM:SS」 라벨(`--up` — 레인에서 유일한 관례색 글자).

## 표면별 계약

### ① 상따 카드 탭 「상한가」 (`card-tabs.tsx` — D-01~D-04 · 목업 A)

#### ①-1 탭 줄

- 순서: **정보 · 미체결(N) · 잔고(N) · 상한가**(네 번째) → 오른쪽 [주문로그][전략로그][접기] 그대로. `CardTab` 유니온에 `"limit"` 추가.
- 트리거 문법 = 기존 `CARD_TAB_TRIGGER`(24px · 11px/600 · 선택 알약 `--pill-on-*`). 탭 줄이 넘치면 기존 `TabsList` 가로 스크롤이 받는다 — 트리거 글자는 줄바꿈하지 않는다.
- **탭 제목 상태(D-04)** — 미체결 건수 괄호와 같은 자리 문법(트리거 안 접미):

  | 85 상태 | 트리거 글자 |
  |---|---|
  | 85 없음 · `lock_state` 0 | 「상한가」 |
  | `lock_state` 1 | 「상한가 · 」 + **「잠김 {dur}」**(`--up`, `mono` 숫자) — 1초마다 갱신 |
  | `lock_state` 2 | 「상한가 · 깨짐」(색 없음) |

  `{dur}` = `lock_elapsed_s` 를 WinForms `FormatDuration` 으로: 60 미만 「43초」, 이상 「1분 3초」. 탭 제목에는 「째」를 붙이지 않는다(D-04 문구).
  선택된 트리거(파란 알약)에서도 「잠김 …」 조각은 `--up` 을 유지한다.
- **자동 전환 없음.** 85 수신 · 잠김 전이 · 알림 클릭 어느 것도 이 탭을 열지 않는다(`alertTabFor` 가 `"limit"` 을 돌려주지 않는다). 사용자 클릭만. 접힘/재클릭 접힘 규칙은 다른 탭과 같다.

#### ①-2 탭 본문 — 3줄 9칸 표 (WinForms `tblLimitFeature` 동형)

- 본문 래퍼 = 기존 공통 고정 높이(EX-1). 표가 래퍼 높이를 **정확히 채우고** 스크롤이 생기지 않는다(3행 × ≈23.8px). 카드 높이 불변.
- 마크업: `<table data-slot="lc-limit-feature" aria-label="상한가 특징" class="h-full w-full table-fixed">` · 3 `<tr>` · 각 행 `<th scope="row">` + `<td>` 3개. `colgroup` = 행 머리 44px + 값 3칸 균등.
- 행 머리: 「지금」·「10초」·「창구」 — 면 `--muted` · 글자 `--muted-fg` · 11px/600 · 좌우 8px.
- 값 칸: 12px/400 `--fg` · 좌측 정렬 · 좌우 8px · `nowrap` + 말줄임. 행 사이 hairline `--border-subtle`(마지막 행 아래 없음). 열 사이 세로선 없음(목업).
- 85 없음(아직 안 옴 · 구 서버 · 대상 밖 키): 9칸 전부 「—」(`--faint`), `title` 없음.

**9칸 규칙 — 문구는 `limitup-feature.md` ⑥ 표와 글자 하나까지 같다(D-03).** 서버 값 그대로, 단위 변환·비율만:

| 행 | 칸 1 | 칸 2 | 칸 3 |
|----|------|------|------|
| 지금 · `lock_state` 1 | 「잠김 N초째」 / 「잠김 M분 S초째」 (`--up` 600) | 「대기 X.X억」(`q_krw`) | 「소진 N초」 / 「소진 M분 S초」 (`drain_s` −1 → 「소진 —」) |

- **숫자 표기(WinForms 함수 동형 — 웹 순수 함수 1벌):**
  - 억 `FormatEok`: 0 → 「0」(「매도벽 0」·「대기 0」), 그 밖 소수 1자리 + 천 단위 쉼표 + 「억」(「17.3억」·「1,234.5억」).
  - 초 `FormatDuration`: 60 미만 「43초」, 이상 「1분 3초」.
  - 등락률: `rate_bp / 100` 소수 1자리, 부호 항상(「+26.8%」 · 음수 「-1.2%」 · 0 「0.0%」).

  - 잔량 신규/취소: 0 이면 「잔량 신규 0」·「잔량 취소 0」, 그 밖 「+12,400」·「-2,300」(ASCII 하이픈 — ⑥ 문구 그대로).

  - 깨짐확률: `model_state` 1 이고 `p_break_bp` ≥ 0 일 때만 「깨짐확률 18.3%」(`/100` 소수 1자리).
- **폰 밴드 축약(D-03 · 카드 `lc` < 첫 경계):** 10초 행 칸 2·3 이 잠김 중일 때만 바뀐다 — 「잔량 」 접두를 떼고 수량을 `FormatManQty` 로: 「신규 +1.2만」 · 「취소 -2,300」. 분기는 **CSS 로만**(같은 칸 안 두 span — 폰 span `@min-[685px]/lc:hidden`, 넓은 span `hidden @min-[685px]/lc:inline`). 뷰포트·폭 측정 JS 금지(QuoteGrid10 규율). 그 밖 칸은 모든 밴드에서 같은 글자이고, 남는 잘림은 말줄임 + `title` 이 받는다.
- **툴팁(⑥ 동형):** 표 요소에 네이티브 `title` = 줄 3개 「지금 {칸1} · {칸2} · {칸3}」 / 「10초 …」 / 「창구 …」(항상 **넓은 밴드 문구**) + 4번째 줄 「HH:mm:ss 기준」(`gw_time_ms` KST) · 확률 적용 중이면 「 · 깨짐확률은 {p_horizon_s}초 안」. 같은 문자열이면 다시 쓰지 않는다(떠 있는 툴팁 깜빡임 방지). 관측 시각을 본문에 따로 그리지 않는다(72px 안에 자리 없음).
- **갱신:** 1초마다 값만 바뀐다 — 바뀐 칸 강조·깜빡임·전환 애니메이션 없음. 칸 단위 메모로 바뀐 칸만 다시 그린다.

- **레인 1 「진입 10분」** — 캡션 12px `--muted-fg`: 「진입 10분 · {HH:MM}~{HH:MM} — 가격(위) · 상한가까지 남은 매도벽 금액(아래)」. 높이 160px. 위 절반: 가격선 `last_px`(`--fg`) · 상한가 가로 점선(`--border-subtle`) + 라벨 「상한가 {px}」 · 등락률 25% 점선(`--led-latent`) + 라벨 「등락률 25%」. 아래 절반: 매도벽 금액 `wall_krw_visible` 곡선 `--fg` + 면 `--muted`. 마커: 「25% 도달」(`--led-latent` 점) · 「매도벽 소진」 · 「첫 상한가 체결」(`--fg` 점). x 눈금 라벨 4개(시작 · ⅓ · ⅔ · 끝, 「HH:MM」 11px `--muted-fg`).
- **레인 2 「잠김 전 구간」** — 캡션: 「잠김 전 구간 · {HH:MM}~{HH:MM} — 상한가 매수잔량 금액 · 큰 매도 ▼ · 취소 ✕ · 깨짐 ●」. 높이 120px. 잠김 음영(`--muted`) · 기준선 10억(`--led-latent` 점선 + 라벨 「기준 10억」) · 잔량 곡선 `q_krw`(`--fg`) · 최대 점(`--fg`) + 라벨 「최대 {X.X}억 @{HH:MM:SS}」 · 큰 매도 ▼(`--down`, `jumps.kind = burst_sell`) · 취소 ✕(`--muted-fg`, `kind = cancel`) · 깨짐 ●(`--up`) + 라벨 「깨짐 {HH:MM:SS}」(`--up`). 마커가 40개를 넘으면 `krw` 큰 순 40개만(제안 — 과밀 방지). 글자 라벨은 가장 큰 ▼ 1개(「{HH:MM} 매도 {N}주」) · 가장 큰 ✕ 1개(「취소 −{X.X}억」)에만, 나머지 마커는 `title` 만. 잠김이 없는 종목은 레인 2 대신 12px `--faint` 「잠김 구간이 없어요」.
- **레인 공통 그리기 규칙:** SVG 는 선·면·음영만(`preserveAspectRatio="none"` · `vector-effect="non-scaling-stroke"`), **글자와 점 마커는 HTML 오버레이**(x = 시각의 % 위치 · 11px 고정). 레인 SVG 는 `role="img"` + `aria-label` 요약(「{종목명} 잠김 전 구간 잔량 — 최대 17.3억 13:57:47, 깨짐 14:40:07」), 오버레이는 `aria-hidden`(같은 사실이 사실 문장 목록에 글자로 있다). 격자 파일은 카드가 화면 가까이 올 때 불러오고(제안), 그동안 레인 자리는 높이를 유지한 빈 면(`--muted` 점선 테두리 없음 · 12px `--faint` 「불러오는 중…」).
- **사실 문장** — 소제목 「사실 문장」(14/600) + 부제 「배치 생성 · 해석 없음」. `<ul>` · 행 = 시각 칸 72px(「HH:MM:SS」 12px `mono` `--muted-fg`) + 문장(14px/400 `--fg` · `facts.text` **그대로** · 줄바꿈 허용) + 문장 끝 출처 배지(`facts.source` 글자 그대로: 「실측」·「추정(분 단위)」·「모형」). 행 사이 점선 hairline. 순서 = `t_ms` 오름차순. 없으면 12px `--faint` 「사실 문장이 없어요」.
- **창구 비중** — 소제목 「창구 비중」 + 부제 「B9 1분 증분 배분」 + 배지 「추정(분 단위)」. 하위 캡션 「진입 1분 매수」(막대 `--up`) · 「깨짐 전 1분 매도」(막대 `--down`, 깨진 잠김이 있을 때만). 각 상위 3 행 = 이름 72px(12px, 말줄임) | 트랙 8px(`--muted`, radius 4px) 위 채움 | % 40px(12px `mono` `--fg-2`, 오른쪽 정렬). 행 간격 4px. 데이터 없으면 그 캡션 아래 12px `--faint` 「—」.

#### ④-5 창구 지문표 (gh-trade D-11)

- 섹션 제목 「창구 지문표」 + 부제 「사건 10건 미만은 관찰 중」. 집계 창 = 적재 보존 창(최근 90일, D 까지) — 제안.
- 표(가로 넘치면 래퍼 `overflow-x-auto`): 머리 12px `--muted-fg` 오른쪽 정렬(첫 열 왼쪽) 「창구 · 사건 · 진입 1분 매수 · 잠김 중 매수 · 깨짐 전 1분 매도 · 매도 선행 · 유지율 · 상태」 · 셀 14px `mono`(창구명 제외) · 행 hairline.
- 창구 칸 = 「{회원사명} {회원번호}」. 비율 = 정수 %, 매도 선행 = 「{선행}/{관여 깨진 잠김}」, 유지율 = 「{유지}/{관여 잠김}」.
- 사건 ≥ 10: 매수 비중 두 칸 `--up` · 매도 비중 칸 `--down` · 나머지 `--fg` · 상태 = 승격 라벨이 있으면 그 글자, 없으면 「—」(지금은 승격 전이라 전부 「—」).
- 사건 < 10: 행 전체 `--muted-fg` · 상태 = 「관찰 중」 태그(`--muted`/`--muted-fg` · 11px/600).
- 정렬 = 사건 수 내림차순. 상위 20행, 그 아래 텍스트 버튼 「창구 {N}개 더 보기」(12px/600 `--muted-fg`, 누르면 전부 펼침 · 다시 접기 없음) — 제안.

#### ④-6 어제 결과

- 섹션 제목 「어제 결과」 + 부제 「{MM/DD} 잠김 → 다음 날 시가」(MM/DD = D 바로 이전 적재 날짜).

## 접근성 계약

- 9칸 표: 진짜 `<table>` + `<th scope="row">` · `aria-label="상한가 특징"`. 1초 갱신이라 **라이브 영역이 아니다**(읽기 소음 금지). 탭 트리거 접근 이름은 보이는 글자 그대로(「상한가 · 잠김 43초」).
- 체크 칩: `<label>` 안 네이티브 체크박스 → 이름 「상한가 특징」 · Space 토글 · 포커스 링 `--ring`.
- 사이드바: 「분석」 링크 이름 = 보이는 글자 · 레일에서 `rail:sr-only` + `title`(기존 규율) · 아이콘 `aria-hidden`.
- 보고서 제목 계층: `h1`(PageHeader) → 섹션 `h2` → 사건 카드 종목 `h3`.
- 날짜 화살표: `aria-label` 「이전 보고서」/「다음 보고서」 · disabled 는 진짜 `disabled` · 32px 타깃(WCAG 2.5.8 24px 이상).
- 격자 행 버튼 접근 이름 = 「{종목명} {코드} — 사건 카드로 이동」(보이는 종목명이 이름 맨 앞 · 2.5.3). 활성화 뒤 사건 카드 `h3` 로 포커스 이동(`tabIndex={-1}`).
- 데스크톱 격자 머리줄 `aria-hidden` · 각 값 칸에 `sr-only` 라벨(폰 메타 라벨과 같은 DOM).
- 스파크라인 `aria-hidden`(값은 행 글자에 있다) · 레인 SVG `role="img"` + 요약 `aria-label` · 오버레이 마커 `aria-hidden` · 사실 문장 목록이 글자 대체물.
- 색만으로 말하지 않는다: 잠김/깨짐/유지/매수/매도/관찰 중은 모두 **글자**가 있다. ● ▼ ✕ 는 캡션 범례 + 사실 문장으로 글자 대체.
- 터치 타깃: 폰 격자 행 ≥ 44px · 날짜 화살표 32px · 체크 칩은 기존 필터 칩 높이(인접 칩과 같은 예외).
- 대비: 위 Color 절 「알려진 대비 예외」.

## 모션

- 격자 행 → 사건 카드: `scrollIntoView({ behavior: "smooth", block: "start" })`, `prefers-reduced-motion: reduce` 면 `"auto"`. 스크롤 뒤 포커스 이동(`preventScroll: true`).
- 9칸 · 탭 제목 · 칩: 값 변경 애니메이션 없음(깜빡임·하이라이트 금지).
- 차트: 등장/전환 애니메이션 없음.
- 기존 모션(새 로그 줄 강조 300ms · 탭 접기 화살표 회전)은 그대로.

## 검증 훅 (감사·e2e 가 잴 것)

- 9칸 문자열 단위 테스트: lock_state 0/1/2 × auction × model_state × 창구 없음 × 85 없음 × 폰/넓은 밴드 — WinForms `BuildLimitFeatureCells` 기대 문자열과 대조(「매도벽 0」 · 「잔량 신규 0」 · 「1분 3초」 · 짝수 반올림 포함).
