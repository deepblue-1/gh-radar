`webapp/src/lib/relay-url.ts`: `resolveRelayWsUrl(): string` — `process.env.NEXT_PUBLIC_RELAY_WS_URL?.trim()` 이 비어 있지 않으면 반환, 아니면 **모듈 스코프 1회 경고** 후 `ws://localhost:8090/ws` 폴백(D-41). `.trim()` 이 없으면 Vercel paste 의 trailing newline 이 클라이언트 번들을 깨뜨린다는 선례를 주석에 남긴다. `wss:`/`ws:` 스킴이 아니면 throw(오설정 조기 발견).

`webapp/src/lib/use-relay-socket.ts`: `"use client"`. `useRelaySocket({ isin, exchange, enabled }): RelaySocketState`.

반환 상태: `{ status: RelaySessionState | "idle", statusLabel, statusMessage, attempt, accounts, quote, tape, account, orders, messages, isStale, send, reconnect }`.

동작:
1. `enabled === false` 또는 `isin` 이 없으면 아무 연결도 만들지 않는다(비로그인·isin 미확보 상태).
2. `createClient().auth.getSession()` → 세션 없으면 `status: "unauthorized"` 로 두고 연결하지 않는다(로그인 게이트는 UI 가 표시).
3. `new WebSocket(resolveRelayWsUrl())` → `onopen` 에서 **첫 메시지 `{t:"auth", token}`** 전송(D-11). 토큰을 URL·쿼리스트링에 넣지 않는다.
4. `onmessage` → `JSON.parse` 후 `t` 로 분기하는 reducer. **파싱 실패 프레임은 throw 하지 않고 스킵**(chat-sse 선례). 분기:
   - `state` → `status`/`attempt`/`accounts` 갱신. 라벨은 `RELAY_STATE_LABELS[s]` 를 그대로 쓴다(브라우저가 switch 중복 금지 — D-36).
   - `q` → `quote` 갱신 + 스냅샷 캐시 `Map<"isin|ex", RelayQuote>` 에 저장.
   - `tape` → 링버퍼 상한 200 앞에 prepend(`snap` 이면 교체).
   - `acct` → 잔고·미체결(`snap` = 교체, delta = upsert + `rm` 제거).
   - `order` → 주문 상태 갱신.
   - `msg` → `messages` 에 최근 N(=20)건 누적.
5. **재접속**: 지수 백오프 1s→2s→4s→8s, 상한 30s, 시도 상한 10회. 상한 소진 시 `status: "manual_required"`. **무한 재시도 금지**. close code 가 `4401`(인증 실패)면 재접속하지 않고 `unauthorized`/`failed` 로 확정한다(재시도해도 같은 결과).
6. **재접속 중 데이터를 지우지 않는다** — `isStale: true` 만 세우고 마지막 값을 유지한다(UI-SPEC: `opacity:.55` 감쇠). 브라우저 재접속 시 스냅샷부터 다시 받으므로 `snap` 프레임 도착 시 전량 교체(D-37).
7. **거래소 토글**: `exchange` prop 변경 시 **이전 `{t:"unsub"}` 을 반드시 먼저 보내고** 새 `{t:"sub"}`. 캐시에 값이 있으면 즉시 표시하고 스켈레톤으로 되돌리지 않는다.
8. **종목 전환(같은 동적 라우트 → remount 없이 props 갱신)**: `isin` 변경 시 이전 구독 `unsub` + `quote`/`tape`/`account` **전부 리셋**. 리셋 누락은 **다른 종목 호가로 주문하는 사고**로 이어지므로 이유를 주석에 박제한다(PATTERNS F-2 WR-04 형식).
9. `cleanup`: `unsub` 전송 → `close(1000)` → 타이머·리스너 정리. `enabled` 가 false 로 바뀌어도 동일.
10. `send(msg: RelayInbound)` 를 노출해 주문 UI 가 아닌 구독 제어만 가능하게 한다. **주문은 wss 로 보내지 않는다**(D-08 — REST 전용). 주석으로 명시.
