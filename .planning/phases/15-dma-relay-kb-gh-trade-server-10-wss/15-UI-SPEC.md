## Spacing Scale

기존 4-point 토큰 스케일 상속 (globals.css `--s-*`). **신규 값 없음.**

| Token | Value | Usage (호가창) |
|-------|-------|----------------|
| `--s-1` | 4px | 잔량 바 여백, 부호·라벨 갭, 비율 버튼 갭 |
| `--s-2` | 8px | 호가 셀 좌우 패딩, 폼 행 갭, 알림 행 갭 |
| `--s-3` | 12px | 패널 헤더/본문 패딩, 표 셀 좌우(`--cell-pad-x`) |
| `--s-4` | 16px | 섹션 헤더·상태 바 좌우 패딩 |
| `--s-5` | 24px | 빈 상태 박스 내부 패딩 |
| `--s-6` | 32px | 권한 없음 게이트 상하 패딩 |
| `--s-8` / `--s-10` | 48 / 64px | 페이지 레벨(기존 `space-y-8` 상속) |

**Radius:** `--r-sm`(4, 잔량 바·칩·소형 토글) · `--r`(6, 입력·버튼) · `--r-md`(8, 결과 배너·표 래퍼) · `--r-lg`(12, 섹션 카드·다이얼로그).

**행 높이 — 밀도 계약 (핵심):**

| 표면 | density scope | `--row-h` | 근거 |
|------|---------------|-----------|------|
| 호가 10단 사다리 | `data-density="compact"` | **32px** | 20행 × 32 = 640px. globals.css 의 모바일 자동 comfortable 규칙은 `[data-density]:not([data-density="compact"])` 이므로 **compact 를 명시하면 모바일에서도 32px 이 유지된다** — 새 토큰 없이 밀도를 지킨다 |
| 체결 테이프 | `data-density="compact"` | 32px | 사다리와 시각적 baseline 정렬 |
| 잔고 / 미체결 | `data-density="default"` | 36px | 취소 버튼(26px) 터치 여유 |

Exceptions:
- **주문 제출 버튼 40px** — `ui/button.tsx` `size="lg"`. 스케일 내 값이므로 예외 아님.
- **미체결 취소 버튼 26px** — `size="sm"`(32px)보다 작다. **의도된 예외**: 36px 행 안에 들어가야 하고, 오조작 위험이 낮은 2차 액션이며 확인 다이얼로그가 뒤에 있다. 좁은 폭(<900px)에서는 행 높이를 44px 로 두고 취소 버튼을 32px(`size="sm"`)로 키운다.
- **연결 상태 배지 24px** — `ui/badge.tsx` 기본 높이 상속.
- **컴포넌트 내부 패딩**(배지/토글/칩/다이얼로그 세부)은 `--s-*` 레이아웃 그리드 대상이 아니라 Phase 3 에서 락된 `button.tsx`/`badge.tsx` 자체 값을 따른다.

## Typography

기존 타입 토큰 상속 (globals.css `--t-*`). 호가창에서 실제 사용하는 롤만 명시. **4 사이즈 · 2 웨이트.**

| Role | Size | Weight | Line Height | 적용 |
|------|------|--------|-------------|------|
| 호가 가격 / 체결가 | 14px (`--t-sm`) | 600 | 1.2 (`--lh-tight`) | 사다리 가격 열, 체결 테이프 가격 — **`.mono`** |
| 잔량 / 수량 / 시각 / 표 셀 | 12px (`--t-caption`) | 400 | 1.5 | 사다리 잔량, 체결 수량·시각, 잔고·미체결 숫자 — **`.mono`** |
| 라벨 / 표 헤더 / 배지 / 알림 | 12px (`--t-caption`) | 600 | 1.5 | 열 헤더, 패널 헤더, 상태 배지, 폼 라벨 |
| 섹션 실시간 현재가 | 20px (`--t-h3`) | 600 | 1.2 | 섹션 헤더의 실시간 체결가 — **`.mono`** |
| 본문 / 안내 / 버튼 | 14px (`--t-sm`) | 400 / 600 | 1.5 | 상태 문구, 빈 상태 본문, 주문 버튼 |

**Weights:** 표준 계약 **regular 400 + semibold 600** 2단. (locked exception: 기존 `ui/button.tsx` 의 `font-medium 500` 은 Phase 3 lock 상속 — 호가창에서 500 을 새로 도입하지 않는다.)

**마이크로 라벨 예외:** 마이크로 라벨(사다리 헤더·현재가 칩·틱 스텝 배지·`tfoot`·출처 태그·알림 칩)은 **11px 고정**, 4-사이즈 스케일 밖 예외. 기존 `stock-comovement-section.tsx`·`stock-limit-up-section.tsx` 관례와 동일.

**숫자 규칙 (전 표면 강제):**
- 모든 가격·수량·금액·비율은 **`.mono`**(Geist Mono, `tabular-nums slashed-zero`) + **우측 정렬(`.num`)**. 예외: 사다리의 가격 열은 **중앙 정렬**(좌우 잔량 열과 시각적 축을 맞추기 위해).
- 방향색이 필요한 숫자(등락, 평가손익, 수익률)는 반드시 `ui/number.tsx` 를 통과시킨다(`withColor`). 방향색이 **필요 없는** 숫자(잔량, 수량, 주문가)는 `withColor` 를 쓰지 않는다.
- `%` 스케일 함정: 서버는 정수 %(11.56 = 11.56%)를 주고 `<Number format="percent">` 는 소수(0.1156)를 기대한다 — `stock-hero.tsx` 선례대로 `/100` 변환.
- 한글 혼용: `html[lang="ko"]` 전역 규칙(`word-break:keep-all`, `letter-spacing:-0.01em`) 상속.

## Color

60/30/10 배분은 앱 전역 계약 상속. 호가창 매핑:

| Role | Token (light / dark) | Usage |
|------|----------------------|-------|
| Dominant (60%) | `--bg` (#FFFFFF / oklch .08) | 페이지 배경, 표 본문 배경 |
| Secondary (30%) | `--card` · `--muted` · `--secondary` | 섹션 카드면, 상태 바, 표 헤더, 패널 헤더, 결과 배너, 총잔량 행 |
| Accent (10%) | `--primary` / `--accent` / `--ring` | **아래 3곳 한정** |
| Semantic — 상승/매수 | `--up` · `--up-bg` (빨강 oklch 22) | 아래 열거표 |
| Semantic — 하락/매도 | `--down` · `--down-bg` (파랑 oklch 250) | 아래 열거표 |
| Semantic — 보합 | `--flat` | 기준가와 같은 호가, 등락 0 |
| Destructive | `--destructive` | 주문 취소 확인, 연결 실패/거부 배지, 거부 결과 배너 |

### `--up` / `--down` 사용처 — 명시 열거 (이 표에 없으면 쓰지 않는다)

| 요소 | 색 | 규칙 |
|------|-----|------|
| 섹션 헤더 등락액·등락률 | `--up` / `--down` / `--flat` | 기준가 대비 |
| **사다리 가격 열 텍스트** | `--up` / `--down` / `--flat` | **기준가(전일종가) 대비.** 급등 종목에서는 20단 전부 `--up` 이 된다 — 이는 정상이며, **매도/매수 구분을 색에 의존하면 안 되는 이유**다 |
| 사다리 매도호가 행 배경 | `--down-bg` 65% 틴트 | 국내 HTS 관례(매도=파랑 면) |
| 사다리 매수호가 행 배경 | `--up-bg` 65% 틴트 | 국내 HTS 관례(매수=빨강 면) |
| 사다리 잔량 바 | 매도 `--down` 16% / 매수 `--up` 16% | 숫자 뒤 배경 레이어. 숫자는 `--fg` 유지 |
| 체결 테이프 체결가 | `--up` / `--down` / `--flat` | 기준가 대비 |
| 체결 테이프 매수/매도 구분 | `--up` / `--down` | **`▲ 매수` / `▼ 매도` 부호+라벨 병기 필수** |
| 주문 패널 매수 탭(선택) | `--up-bg` 배경 + `--up` 텍스트/테두리 | |
| 주문 패널 매도 탭(선택) | `--down-bg` 배경 + `--down` 텍스트/테두리 | |
| 주문 제출 버튼 | 매수 `--up` 채움 / 매도 `--down` 채움 (텍스트 `--primary-fg`) | 탭 색과 동일 — 색·문구·위치 3중 일치 |
| 미체결 행 구분 태그 | `--up`(▲ 매수) / `--down`(▼ 매도) | 부호 병기 |
| 잔고 평가손익·수익률 | `--up` / `--down` / `--flat` | `ui/number.tsx` `withColor` |

### `--up` / `--down` **금지** 목록

- **연결 상태 배지·상태 문구** — 사다리의 의미색과 충돌한다. `--muted`/`--muted-fg`/`--fg`/`--destructive` 만 사용.
- **잔량 숫자 자체** — 바(배경)만 틴트, 숫자는 `--fg`.
- **주문 취소 버튼** — 아래 토큰 충돌 항목 참조.
- **로딩·스켈레톤·빈 상태·권한 없음 안내** — 전부 중립.

### 토큰 충돌 경보 (실측)

| 충돌 | 값 | 대응 |
|------|-----|------|
| `--destructive` == `--up` | light 둘 다 `oklch(0.66 0.20 22)`, dark 둘 다 `oklch(0.72 0.19 22)` | **주문 취소 버튼을 `variant="destructive"`(채움 빨강)로 만들면 매수 버튼과 구분되지 않는다.** 취소는 반드시 **테두리 + `--destructive` 텍스트 + `✕` 아이콘**(투명 배경). 확인 다이얼로그의 `주문 취소` 버튼도 동일 |
| `--primary` == `--down` | light 둘 다 `oklch(0.63 0.18 250)`, dark 둘 다 `oklch(0.72 0.16 250)` | **사다리 내부·주문 버튼에 `--primary` 를 절대 쓰지 않는다**(매도 파랑으로 오독). accent 사용처를 아래 3곳으로 제한 |

### Accent (`--primary`/`--accent`/`--ring`) reserved for

1. **거래소 토글 활성 상태** (`--accent` 배경 + `--accent-fg` 텍스트)
2. **입력 포커스 링** — globals.css 전역 double-ring(`--ring`) 규칙 상속, 별도 지정 없음
3. **호가 가격 클릭 반영 피드백** — 주문 가격 입력칸 테두리 1회 플래시(260ms)

그 외 인터랙티브 요소(사다리 hover, 탭, 더보기, 계좌 셀렉터)는 `--border` + `--muted` hover 로 처리한다. **accent 남용 금지.**

### 국내 색상 관례 (D-07 / 15-CONTEXT `Claude's Discretion` 고정)

상승·매수 = **빨강 `--up`**, 하락·매도 = **파랑 `--down`**. Phase 14 와 동일. 전 표면에서 반전 금지.

## Interaction Contract

### 탭 전환 (페이지 레벨)

- **URL 동기화:** 탭 전환 시 `?tab=chart|orderbook|info|news` 를 갱신한다. `router.replace`(history 누적 없음)가 아니라 **`router.push`** 를 써서 브라우저 뒤로가기가 이전 탭으로 돌아가게 한다.
- **딥링크 진입:** 페이지 로드 시 `?tab=` 값을 읽어 해당 탭을 활성화한다. 값이 없거나 알 수 없는 값이면 **기본 탭 `chart`**.
- **스크롤 위치는 탭별로 보존하지 않는다.** 탭 전환 시 **탭 바 바로 아래로 스크롤**(히어로는 지나간 상태). 탭별 스크롤 복원은 도입하지 않는다 — 단순성 우선.
- **탭 바 sticky:** 스크롤해도 상단 고정. 히어로는 함께 스크롤되어 사라진다.
- **키보드:** Radix Tabs 기본 동작 상속 — `←`/`→` 로 탭 이동, `Home`/`End` 로 처음/끝, `Tab` 으로 패널 진입. 별도 override 하지 않는다.
- **탭 라벨에 상태 표식을 붙이지 않는다** — 연결 상태는 `호가주문` 탭 안의 상태 바가 단독으로 소유한다.

### 호가 → 주문 연결

- **호가 가격 클릭 → 주문 패널 가격 입력에 반영.** 반영 피드백은 **입력칸 테두리 1회 플래시(260ms, `--ring`)** — 사다리에는 잔상을 남기지 않는다(다음 100ms 갱신에 덮인다).
- **매수/매도 탭은 절대 자동 전환하지 않는다.** 매도호가를 클릭해도 매수 탭은 그대로다. 자동 전환은 오조작의 직접 원인이 된다.
- 가격 스텝퍼 `−`/`＋` 는 **호가 단위(tick)** 단위로 증감. 직접 입력 후 blur 시 가장 가까운 tick 으로 스냅하고, 스냅이 일어나면 힌트를 `호가 단위(100원)에 맞춰 {값}원으로 맞췄어요` 로 1회 교체.
- 수량 입력은 `inputmode="numeric"`. **매도 탭에서만** 비율 버튼(10/25/50/100%)을 노출한다 — 기준은 잔고의 `sellable_qty`. **매수 비율 버튼은 만들지 않는다**: `AccountState` 에 주문가능금액이 없어 근거 데이터가 존재하지 않는다.

### 오조작 방지 (되돌릴 수 없는 액션)

1. **색·위치·문구 3중 일치** — 매수는 항상 빨강·왼쪽 탭·`매수`, 매도는 항상 파랑·오른쪽 탭·`매도`. 제출 버튼은 활성 탭 색을 그대로 이어받는다.
2. **단일 제출 버튼** — 매수/매도 버튼을 나란히 두지 않는다(인접 버튼 오클릭 차단).
3. **확인 다이얼로그 필수** — 신규 주문·취소 모두. 다이얼로그 **기본 포커스는 취소/닫기**. Enter 연타로 제출되지 않는다.
4. **제출 후 즉시 재활성 금지** — 응답(또는 5초 타임아웃) 전까지 제출 버튼 비활성 + `주문 전송 중…`.
5. **취소 버튼은 채움 금지** — `--destructive` == `--up` 이므로 테두리 + `✕` 아이콘으로 매수 버튼과 물리적으로 구분한다.

### 실시간 갱신 시각 피드백 (과도한 애니메이션 금지)

- 업스트림 100ms 코얼레싱(D-35)을 그대로 받는다. **브라우저에서 추가 코얼레싱을 하지 않는다.**
- 변경된 잔량/가격 셀에 **배경 플래시 1회, ≤150ms**(`background-color` 만 — `transform`/`width` 애니메이션 금지, 레이아웃 shift 0).
- **플래시는 큐잉하지 않는다.** 갱신이 겹치면 최신 것만 남기고 이전 플래시는 즉시 종료. 초당 10회 갱신에서 애니메이션이 밀리면 안 된다.
- 잔량 바 폭 변화는 **transition 없이 즉시 반영**(폭 애니메이션은 100ms 주기에서 항상 뒤처진다).
- 체결 테이프는 200ms 배치 → **배치 단위로 1회 플래시**. 행마다 개별 애니메이션 금지.
- `prefers-reduced-motion: reduce` → **플래시·점멸 도트·스켈레톤 shimmer 전부 비활성**, 값만 교체(globals.css 전역 규칙 + 컴포넌트 로컬 가드).

### 체결 테이프 스크롤

- 신규 체결은 **상단 prepend**.
- `scrollTop <= 4px` 일 때만 자동으로 맨 위 유지. 사용자가 스크롤을 내리면 **자동 스크롤 정지**.
- 정지 상태에서 신규 체결이 쌓이면 상단에 핀 버튼 `새 체결 N건 · 맨 위로`. 클릭 시 맨 위로 + 카운터 리셋.
- 링버퍼 상한 200건(relay 캐시와 동일). 상한 초과분은 하단부터 제거.

### 재접속·거래소 전환 (깜빡임 금지)

- **재접속 중 데이터를 지우지 않는다.** 사다리·테이프는 마지막 값을 유지하고 `opacity:.55` 로 감쇠 + 상태 바에 `표시된 호가는 마지막으로 받은 값이에요.` 주문 버튼만 비활성. 빈 화면으로 되돌리면 사용자가 문맥을 잃는다.
- **거래소 토글 전환:** 이전 `{t:"unsub"}` 를 반드시 보낸다(참조계수 누수). 새 스냅샷 도착 전까지 이전 값을 유지하고 사다리 상단에 `{거래소} 호가 불러오는 중` 인라인 표시 — **스켈레톤으로 되돌리지 않는다.** 훅 내부 `Map<isin|ex, quote>` 캐시로 토글 왕복 시 즉시 복원.
- 브라우저 재접속(D-37) 시에는 스냅샷부터 다시 받으므로 사다리 전량 교체 — 이때만 1회 전체 플래시 허용.

### 키보드 접근성

- **사다리는 roving tabindex.** 사다리 전체가 tab stop 1개(`tabindex=0`)이고, `↑`/`↓` 로 행 이동, `Enter`/`Space` 로 그 행의 가격을 주문 입력에 반영. 20개 버튼이 tab 순서를 잡아먹지 않게 한다.
- 탭 순서: 거래소 토글 → 사다리(1 stop) → 매매 구분 탭 → 계좌 → 주문 거래소 → 가격 → 수량 → 제출 → 계좌 탭 → 미체결 취소 버튼들.
- 다이얼로그는 `ui/dialog.tsx`(Radix) 포커스 트랩·ESC·복귀 포커스 상속. 기본 포커스만 취소 버튼으로 override.
- 포커스 링은 globals.css 전역 double-ring(`--ring`) 상속. 사다리 행은 `data-focus-ring` opt-out 하지 않는다.

### 색 비의존 (WCAG 1.4.1)

- 매수/매도는 **부호 + 라벨 병기**: `▲ 매수` / `▼ 매도`. 색만으로 구분하지 않는다.
- 매도/매수 호가는 **열 위치**(좌 매도잔량 / 우 매수잔량) + **열 헤더** + `sr-only` 단계 라벨로도 식별된다.
- 사다리는 시맨틱 `<table>` — `<thead>` 열 헤더 + 가격 셀 `<th scope="row">`.
- 상태 배지는 색 + **텍스트 라벨** + 도트 형태(점멸/채움) 3중.

### 반응형

**모바일이 기준이다.** 좁은 폭을 먼저 만족시키고 넓은 폭에서 2축으로 펼친다.

| 폭 | 배치 |
|----|------|
| ≥900px `호가주문` | L1=B 2축 그리드 — `grid-template-columns: 380px 220px minmax(360px,1fr)`, `gap: 1px`. 1280px 뷰포트(컨텐츠 1232px, 좌우 여백 24px) 기준 실폭 **사다리 380px / 체결 220px / 우측 628px**. 우측 컬럼이 미체결 표 자연 폭 **422px** 를 담고 206px 여유 — 잘리지 않는다 [실측 2026-09-05 · `15-tabs-mockup.html` 과 `15-orderbook-mockup.html` 이 동일값 산출] |
| ≥900px 그 외 탭 | 현행 `max-w-4xl`(896px) 중앙 정렬 유지 |
| **<900px `호가주문` 세로 순서 (확정)** | ① **연결상태 배지**(+ ServerMessage 누적) → ② **호가 사다리 기본 5단** + `10단 전체 보기` 버튼 → ③ **주문 패널** → ④ **체결 테이프** → ⑤ **잔고** → ⑥ **미체결** |
| <900px 주문 패널 | **sticky 아님.** 스크롤과 함께 움직인다(단순성 우선) |
| <900px 잔고·미체결 | 탭 전환이 아니라 **각각 독립 섹션**으로 세로 나열. 표는 가로 스크롤 허용 |
| <900px 호가 | 기본 5단(매도5~매수5). 10단 × 32px = 640px 은 모바일 1.5스크린 |
| <900px 밀도 | 사다리·테이프는 `data-density="compact"` 유지(32px). 잔고·미체결은 44px + 취소 버튼 32px |
| <900px 탭 바 | 4탭이 390px 한 줄에 들어간다. 넘치면 가로 스크롤(스크롤바 숨김) |

## Registry Safety

| Registry | Blocks Used | Safety Gate |
|----------|-------------|-------------|
| shadcn official | badge, button, dialog, toggle, toggle-group, skeleton, table, card, tooltip, separator — **기존 설치본**(`webapp/src/components/ui/`) | not required (already vetted, in-repo) |
| shadcn official | **`tabs`** (Radix Tabs) — **신규 설치** (`npx shadcn add tabs`) | **not required** — shadcn 공식 registry(1st-party). 3rd-party 아니므로 `npx shadcn view` 벳팅 게이트 대상이 아니다 |

**`tabs` 도입 사유:** 종목상세가 4탭으로 재구성되면서 **탭 패널 전환**(URL 동기화·딥링크·`←`/`→` 키보드·`role="tabpanel"` 연결)이 필요해졌다. `toggle-group` 은 모드 토글용이라 패널 시맨틱이 없다. 페이지 레벨 탭(P1/P2)에만 쓰고, 호가창 **내부**의 매수/매도·미체결/잔고 전환은 기존대로 `toggle-group` 을 유지한다(모드 토글이지 패널 전환이 아님).

**여전히 비채택:**

| 후보 | 비채택 사유 | 대체 |
|------|-------------|------|
| `select` | 계좌 2~3개. Radix Select 의 포털·타이핑 탐색이 과잉 | 네이티브 `<select>` + 토큰 스타일 + `<label>` 연결 |
