무엇을 보는가. 7차 — VI 와 상따를 한 트레이딩 페이지(/trading)로 합친 모습. 위에서 아래로 「상태줄 → VI 설정 2줄(KRX·NXT) → VI 발동 스트립 → 돌파감지 스트립 → 종목 추가 → 종목 카드 격자 → 공용 패널」. 합친 이유: 탐색(VI 발동·돌파) → 추가 → 거래가 한 화면에서 이어지고, VI 는 설정값이 상승률·금액 2개(+스위치)뿐이라 카드가 아니라 줄로 충분하다.
  • VI 설정 2줄(vi-settings-card 의 값만): 거래소 태그 · on/off 스위치(= run 시작/중지 — 켜는 쪽 확인 다이얼로그 「VI 전략 시작 [KRX]」는 기존 그대로, 여기선 생략) · 상승률 % · 금액 만원 · 가동중이면 빨간 「가동중」 + 서버 반영 시각 · 값을 바꾸면 줄 끝 「수정」(더티, run 은 유지). 계좌는 상태줄(공용) · 마감알림은 표시하지 않음. 섹션 제목 없이 거래소 태그로만 구분.
  • VI 발동 스트립(돌파 스트립과 같은 문법): 「VI N · 미확인 M」 + 칩(종목명 · 발동가 · 전일대비 · 시각 · 상태 배지 접수/체결/부분체결/취소/거부). 미확인(접수 ∧ 미체크) 연노랑. 「더보기」 → vi-order-list 표(확인 ☐ · 주문시간 · 종목 · 거래소 · 발동가 · 전일대비 · 주문가 · 수량 · 체결 · 상태 · 110초 진행바). 확인 체크는 표에서 — 체크하면 confirm_locked 로 잠기고 즉시 전송(더티 아님). 접수 전·잠김 행은 비활성. 폰 밴드는 열을 줄이고 종목 셀 아랫줄에 접는다.
  • 사이드바: 「트레이딩」 제목 자체가 /trading 링크(활성). 3단 목록 = 등록 전략들 — 「VI · KRX 가동중」「VI · NXT」 + 상따 카드들(종목명 · LED 3점). 개별 「상따」「VI」 메뉴는 없앰.
4차까지의 상따 부분은 그대로다:
  • 돌파 목록은 상단 한 줄 칩(가로 스크롤, 신규 도착 연노랑)이고 「더보기」로 전 열 표를 편다. 칩/행 클릭 → 바로 아래 격자에 카드가 생기고(KRX 로 시작) 그 행은 「거래중」으로 바뀐다. 돌파 목록에는 거래소 태그가 없고, 거래소(KRX | NXT)는 카드 헤더의 세그먼트로 카드 안에서 고른다. 종목 검색 입력란은 스트립 바로 아래.
  • 단 수(1·2·3단)는 페이지 안 옵션 — 상태줄 오른쪽 끝 세그먼트로 바꾼다. 폰 밴드(본문 ~699)에서는 세그먼트가 숨고 항상 1단.
  • 스위치(매수주문·한방체결·매도주문 켜기)는 옵션 세팅의 그룹 제목줄 우측 끝(기존 폼 패턴 44×26). 카드 헤더는 종목명·코드·KRX|NXT·현재가·등락률·LED 3칩·캐럿·닫기뿐이고, 접힌 카드의 스위치 상태는 LED(OFF/대기/감시)로 읽는다. 카드 정렬: 펼친 카드 먼저 각각 한 칸, 접힌 카드는 「접힌 종목 N」 스택 한 칸에 세로로 — 초기 상태 펼침 1(한미반도체) + 접힘 3.
  • 수동주문(gh-trade 상따창 수동주문 탭) — 적응형 한 규칙: 카드 폭 <700(매수/매도가 탭인 밴드) → 「매수 | 매도 | 수동」 3탭 · ≥700(옵션 2열) → 옵션 우상단 「수동주문」 버튼 → 옵션 영역 덮기 + ✕(옵션 값 보존). 폼 = 가격 · 수량 · (예약구간 ∧ KRX) 조각 수 · 주문금액 · 「매수 · 매도 · 정정 · 취소」 4버튼 한 줄. 정정·취소는 하단 공용 미체결 행을 눌러 고르면 켜지고(폼 위 「원주문 …」 칩, 가격·수량이 원주문 값으로), 초기값은 미선택. 사다리 클릭 시 가격 채움. 시간외종가 유형 없음(카드).
  • 77 힌트 시뮬레이터(컨트롤 바 「구간」): 라벨·콤보만 바꾼다(벽시계 판정 없음 · 주문을 막지 않음). 예약구간(open) ∧ KRX → 「예약매수/예약매도」 + 조각 수 스테퍼(기본 5 · 상한 maxPieces 10) · 장전(preopen ∧ KRX, nxtPreopen ∧ NXT) → 예약 라벨 + 조각 숨김 + 「예약: 증권사 보관 후 09:00 처리」(NXT 08:00) · G2/G3 는 카드에는 영향 없음(종합주문창 전용 — 호가 탭 목업 참고) · 모름 = 전부 false. 상태줄에 구간 배지.
  • 종목정보 팝업: 카드 헤더 ⓘ → 모달(폰 전체화면 시트 · 700 이상 960px 중앙) 탭 「차트 | 종목정보 | 뉴스·토론」 — 종목상세 4탭에서 호가주문을 뺀 3탭의 축약판. 닫기 ✕ · ESC.
  • 종목정보 10칸(기준·시가·고가·저가·상한·하한·상승VI·거래·시총·발행1% — lc-quote-grid 라벨 그대로)이 카드 헤더 바로 아래에 온다: 카드 ~699 2단×5행 · 700–991 5단×2행 · 992+ 한 줄 10칸.
  • 카드 본문은 어느 폭에서도 「좌 호가(+체결) | 우 옵션」 나란히 — globals.css §2.2b 4밴드를 카드 컨테이너 폭으로 옮겼다: ~699 호가 42% 1단 + 옵션 탭(매수/매도)·라벨 위/입력 아래 · 700–829 2단 호가 260px + 옵션 2열 · 830–991 3단 호가표 400px · 992+ 460px. 2·3단 격자에서도 카드 안은 좌우 배치.

설계 메모 · 7차 (VI + 상따 한 페이지)

합친 대가: 첫 화면에 VI 설정 2줄 + VI 스트립 + 돌파 스트립 세 띠가 카드 위에 쌓여 카드 첫 줄이 폰에서 약 300px 아래로 내려간다 — 두 스트립이 접힌 한 줄(30px 칩)인 것이 그 상쇄다. VI 발동과 돌파는 서로 다른 신호(주문이 이미 나간 것 / 아직 후보)라 한 스트립으로 합치지 않는다.

VI 줄에 없는 것: 계좌(공용 → 상태줄) · 마감알림(이 기기 전용 토글이라 My page 성격) · 시작/중지 확인 다이얼로그(존재하되 목업에선 스위치 즉시 반영). 확인 체크는 표에서만 — 칩에서 누르게 하면 30px 칩 안의 15px 체크가 오터치 축이 된다.

수동주문 적응형: 좁을 때는 매수/매도 탭 옆에 「수동」이 자연스럽게 서고, 넓을 때는 옵션 2열을 건드리지 않는 덮기 오버레이라 한 규칙으로 두 밴드를 덮는다. 대가는 밴드 경계(700)에서 진입점의 자리가 바뀐다는 것 — 폼 상태(가격·수량·선택 칩)는 두 표면이 공유한다.

77: 카드 수동주문은 시간외종가 유형이 없으므로 G2/G3 창에서도 라벨이 「매수/매도」 그대로다 — 종합주문창(호가 탭 목업)과 달라 보이는 것이 맞다. 팝업은 컨테이너 쿼리 containment 때문에 document.body 포털(뷰포트 기준)이다.

스택: 2단이면 [펼친 A | 접힌 3장 스택], 펼친 카드가 2장이면 [A | B] 다음 줄 [스택]. 접힌 카드를 펼치면 스택에서 빠져 앞쪽으로, 펼친 카드를 접으면 스택으로(재렌더, 애니메이션 없음). 스택이 펼친 카드보다 훨씬 짧아 아래 빈 공간이 남는 것이 대가다.

거래소 토글: 거래소는 전략 키(ISIN:계좌:거래소)의 일부라 실제로는 전략이 등록된 뒤에는 잠긴다(지금 상따 규칙 그대로). 카드 안 토글은 등록 전·전략 없는 카드에서만 눌린다고 보면 된다.

+ 스트립은 세로 공간을 가장 덜 먹고 카드 격자가 본문 폭 전체를 쓴다. − 칩 한 줄에 4~6 종목만 보여 임계·기준가·시각 비교는 「더보기」 한 번을 더 거친다 — 신규 도착이 스크롤 밖일 수 있어 「신규 N」 필을 라벨 옆에 항상 둔다.

카드 좌우 배치의 대가: 폰 폭 카드(≈358)에서는 호가 42%(≈140px) 가 2단(가격+등락 세로 · 잔량)으로 압축되고 옵션은 탭 + 라벨 위/입력 아래 1열이라 카드 세로 길이가 길다(호가 박스 330px(헤더 22 + 9행×34) 스크롤로 상쇄). 3단 격자의 카드(≈376)도 같은 폰 밴드다.

더티 바는 이 목업에선 옵션 칸 하단 인라인이다. 프로덕션은 컨테이너 쿼리(layout containment) 때문에 document.body 포털로 화면 하단 고정 — 카드가 여럿이므로 「어느 카드의 더티인지」를 바 문구에 종목명으로 써야 한다.
