# 계좌 메뉴에서 예수금 · 수수료 · 매도세 · 주문자 IP/MAC 설정 + 사이드바 Admin 하위 순서 — 결정 (잠금)

사용자 교정: 「예수금, 수수료도 계좌에서 세팅되게 해야지」 + 「주문자 IP·MAC 도 계좌로」 + 사이드바 순서 지정.
261106-lwu D-04(연결별 설정은 사용자 시트에 그대로)를 아래로 **대체**한다.

- **N-01 계좌 수정 시트(`account-master-sheet.tsx`)에 「예수금 · 수수료」 그룹 추가(목업 ③).** 예수금(원) · 수수료(%) · 매도세(%) 세 칸 —
  지금 사용자 카드 `AccountCostRow` 와 같은 규칙: 칸마다 Enter · 포커스 이탈 시 즉시 저장(저장 버튼 없음) · 예수금 = op 6(`…/budget`) ·
  수수료+매도세 = op 7(`…/fee` 두 값 함께) · 0 = 해제 · 범위 검증 · 「변경 없음」 · 문구는 `ACCOUNT_EDITOR_TEXT` 의 cost* 재사용.
  저장 = **그 계좌를 쓰는 DMA 사용자 모두에게 기존 per-user budget/fee 경로로 팬아웃**(각 사용자의 active 등록 서버) →
  결과 칩은 「<DMA id> · <서버>」 단위. 표시값 = 사용자·서버 값들 중 정본 하나(기존 `summarizeAccountCosts` 규칙을 사용자마다 적용한 뒤
  첫 사용자 기준) · 다른 값은 경고 한 줄 「<DMA id> · <서버> 은/는 <값> — 저장하면 모두 같아져요」. 87 을 모르는 곳은 「확인 전」.
  **연결 0명 계좌는 세 칸 비활성** + 「사용자에게 연결된 뒤 설정할 수 있어요 — 값은 연결된 사용자의 서버에 저장돼요」.
- **N-02 주문자 IP/MAC 도 계좌 수정 시트로(KB 만 · 목업 ③).** 지점·트레이더 아래 「주문자 IP」 · 「MAC 주소」 2칸 + 기존 도움말(`ipmacHelp`) ·
  검증은 shared `validateOrderEndpointInput` 한 벌 · 기존 「저장」 버튼(계좌명·지점·트레이더와 함께)으로 저장 = 사용자마다 기존 계좌 PUT 에
  `orderEndpoint` 실어 팬아웃. 보낼 조건은 기존 `editSaveBodyOf` 규칙(정규화 비교로 바뀌었거나 불일치일 때만 IP/MAC 을 싣는다 · 계좌명만 바뀐
  저장엔 싣지 않음)을 따른다. 값 · 불일치 판정은 shared `summarizeOrderEndpoint` 를 사용자마다 · 불일치 줄 「<DMA id> · <서버> 값이 달라요(…) — 저장하면 모두 같아져요」.
  교보는 칸 없음. 연결 0명이면 칸 비활성(N-01 과 같은 안내).
- **N-03 사용자 시트 계좌 카드(목업 ④):** 예수금·수수료·매도세 입력 행 → **읽기 전용 한 줄** 「예수금 <값>원 · 수수료 <값>% · 매도세 <값>% · 설정은 「계좌」 메뉴에서」
  (미설정/확인 전 표기는 기존 문구). IP/MAC 읽기 줄 끝에도 「설정은 「계좌」 메뉴에서」. **카드 「편집」 버튼과 편집 모드를 없앤다**(계좌명 · IP/MAC
  모두 계좌 메뉴로 갔으므로 편집할 것이 없다). 등록 서버 토글 · 주문 서버 · 「연결 해제」 는 그대로.
- **N-04 사이드바 Admin 하위 순서 = 매매손익 · 계좌 · 사용자 · 서버 · 발사.** Admin 그룹 제목 링크(`NAV_ADMIN.href`)는 첫 항목 `/admin/pnl` 로.
  My page 가 Admin 위인 것은 그대로.
