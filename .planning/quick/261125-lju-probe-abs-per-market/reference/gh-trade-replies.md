## 최종 계약 (변경 2 · 변경 3 답신 합본)

- 값 = **정각 기준 부호 있는 µs 목록**(op 8 `launch_offsets_us` 와 같은 축 — 16:00:00.000000 · 09:00:30.000000). kind 17 round −2 `planned_us` = `offsets_us[i]` 그대로.
- 범위: Q16 **−3000 ~ +1000** · N **−2000 ~ +2000** (shared `LAUNCH_PLAN_LIMITS` q16 · n0930 의 minUs/maxUs 와 같음). 발 수 **0 ~ 10**(빈 목록 = 끔, 중복도 한 발).
- 서버 거부(86 code 1): 범위 밖 · **비감소 위반**(서버는 정렬하지 않는다 — 웹이 오름차순으로 보낸다) · 11발 이상. 위치(실조각 앞 · 사이)는 거부하지 않는다. 같은 µs 면 실조각 먼저.
  86 문구 후보: 「발 수는 0 ~ 10」 · 「오프셋은 1 ~ 1000µs」(→ 절대 축 문구로 바뀜) · 「오프셋은 작은 값부터 차례로(같은 값 허용)」 — **정확한 원문은 gh-trade 구현 때 확정**.
- **시장별(B)**: 94 `tail_probes` **4행 순서 [Q16·K, N·K, Q16·Q, N·Q]**, `LaunchTailProbe` 말미 append `market: string` · `offsets_us: [int]`.
  앞 두 행이 지금 두 행(Q16 · N) 자리 그대로 → 구 relay(profile 첫 일치 `find`)는 K 행을 본다.
  94 구 칸: count = 목록 길이 · step_us = 0(「등간격 아님」).
- op 10 목록 모드: `launch_tail_probe_offsets_us: [int]`(44 말미 append, **필드 존재로 판정 — 빈 벡터 = 끔**) + `launch_tail_probe_count = -1`(구 서버 보호 — 구 서버는 CountOutOfRange 거부) + `launch_market` "K" | "Q" **필수**(빠지면 86 거부) + `launch_profile`.
  구 (count, step) 모드는 시장 칸 없이 K · Q 두 행에 같이 적용(지금 의미).
- **교보 N = 공통 한 목록**: K · Q 어느 쪽으로 와도 두 행에 같은 값 저장, 94 N·K = N·Q, plan_rev +1 한 번, 로그 「market=K·Q(교보 공용 세션)」. 웹은 교보 N 패널에서 한 칸(op 8 교보 N 공통 칸 규칙과 같음 — 인박스 261109-kyobo-n-single-field).
- 이행: 시장마다 그 시장 계획 마지막 실조각 + (i+1)·step 절대값으로 한 번 펼쳐 저장(상한 넘으면 상한으로 잘라 중복).
- 배포 순서: 어느 쪽 먼저든 안전. 94 에 offsets_us 가 없으면(구 서버) 웹은 탐침 편집 불가(읽기 전용 · 「이 서버 버전은 … 몰라요」 계열).
- 계획 파일 · RT 루프 · kind 17 은 gh-trade 몫.

## 교보 16:00 합친 레인 (gh-trade 별도 phase)

- KB: 시장마다 FEP 회선 · 소켓이 따로라 시장 간 묶음 불가(이미 K · Q 스레드 병렬 송신). 교보: K · Q 가 한 주문 세션(D-29).
- 교보 'N' 은 이미 합친 레인(quick-261109-eqv). 교보 16:00 은 사용자 결정으로 합친 레인을 새로 만든다(기본 꺼짐 설정 스위치 · 교보 두 서버 같은 값).
- 「스위치 켜짐 표시」 = **94 말미 bool `kyobo_q16_combined` 확정**(교보 16:00 합친 레인 스위치 실제 값 · KB 는 늘 false) — gh-trade Phase 50 에서 .fbs 에 넣는다.
  → 웹 「⇄ 한 번에 쏨」 판정은 어댑터 한 곳: bool 이 true 일 때만 켜짐. **칸이 없으면(구 서버) 꺼짐**(gh-trade 정정 2026-11-25 — 합친 레인은 Phase 50 에서 처음 생긴다).
- 86 범위 문구는 절대 축 문구로 바뀐다(「1 ~ 1000µs」 아님) — 원문은 .fbs 확정 때 gh-trade 가 준다.
- gh-trade 는 A(탐침) + B(교보 16:00 합친 레인)를 Phase 50 하나로 진행, 첫 플랜 = .fbs · relay 생성물.

## 사용자 결정 (gh-radar 쪽)

- 화면 이름 「뒤탐침」 → 「탐침」(서버 로그 · kind 17 · 내부 식별자는 그대로 둬도 됨).
- 입력은 − 기본(숫자만 = 정각 −X, `+숫자` = 정각 뒤), 저장할 때만 오름차순 정렬(입력 중 칩 이동 없음).
- 편집 = C안 칩 한 묶음 + 전체 이동 ±1 · 3 · 5 · 10(그 시장만, 한도 밖으로 나가게 되는 버튼 disabled).
- **위치 경고 없음**(사용자 「경고는 필요없어」 — 넣지 말 것).
- 경계 지도 축은 값에 맞춰 늘린다(축 상한 · ◂▸ 폐기) — 지도 전체.
- 「⇄」 표시 유지(교보 16:00 · 다른 시장과 같은 µs) — KB 에는 붙이지 않는다.
