# 교보 SecuwaySSL VPN 상시화

## 배경
교보증권 SSL VPN 리눅스 클라이언트(secuway.tar.gz)를 radar-gw VM `/opt/SecurwaySSL` 에 설치·수동 접속 검증 완료(tun1, 교보 서버 10.16.207.112/.119:22 도달). 이를 KB VPN(openconnect@kb) 패턴을 본떠 systemd 로 상시화한다.

## 결정 (사용자)
- 기동 정책: **부팅 자동기동 + Restart=always** (완전 상시화).
- 라이브 배포: 사용자가 settings 권한 규칙 추가 후 Claude 가 실행.

## 태스크
1. Secret Manager 시크릿 `kyobo-vpn-cred`(User ID/Password 2줄) 생성 + VM SA `gh-radar-relay-sa` 에 `secretAccessor` 부여. 값은 어떤 아티팩트·로그에도 기록하지 않는다.
2. 배포 파일을 repo `infra/relay/secuway/` 에 버전관리:
   - `secuway-fetch-secret`(ExecStartPre → /run/secuway.cred 0600)
   - `secuway-connect`(ExecStart, sslvpn 추적 blocking, Type=simple 결정성)
   - `secuway-watchdog` + `securwayssl-watchdog.{service,timer}`(3분 keepalive+복구)
   - `securwayssl.service`(Type=simple, Restart=always, KillMode=control-group)
   - `install.sh`(멱등 설치)
3. VM 설치·enable·기동, 죽음→자동 재연결 실증.
4. `infra/relay/README.md` 문서화(운영 상태 표 + 전용 섹션 + 동시접속 금지 상호배제 경고).
5. 평문 자격증명 흔적·VM 임시파일 정리.

## 검증 기준
- 서비스 active + enabled, MainPID = connect 래퍼.
- 교보 서버 :22 도달, 기본 경로 ens4 유지, KB tun0·wg0 무영향.
- sslvpn 강제 종료 시 자동 재연결(NRestarts 증가, 도달성 복구).
