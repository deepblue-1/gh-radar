포커스 = --ring 테두리 + 부드러운 3px 헤일로(브라우저 기본 링은 끔). 더티 = 테두리 --primary + 아주 옅은 배경 틴트(링 제거) + 라벨의 ●. 셋째 줄은 더티이면서 포커스인 상태 — 헤일로가 있으면 포커스, 배경 틴트가 있으면 더티라 겹쳐도 구분됩니다. 더티의 색·문자 2중 표기 규율(WCAG 1.4.1)은 그대로 유지합니다.
