# Quick 260930-e30 — 사이드바 접기 + 스크롤 헤더 원형 햄버거 — 결정 (locked)

시각 정본: `mockup.html` (같은 폴더, 사용자 검토·채택 2026-09-30).

## D1. 데스크톱 사이드바 접기 = A 아이콘 레일 (240 → 64px)
- 적용 범위: 브라우저 `lg`(≥1024) 고정 사이드바(`[data-slot="app-aside"]`)만. 모바일 드로어(Sheet)와 앱(`html.native-app`, aside 숨김)은 변화 없음 — 드로어 안 사이드바는 항상 펼친 모양.
- 토글 버튼: 헤더 왼쪽, 로고 앞 — 모바일 햄버거와 **같은 자리**. 아이콘 lucide `PanelLeft`. `lg` 에서만 보이고(<lg 는 햄버거), 앱(native-app)에서는 숨김. aria-label 「사이드바 접기」/「사이드바 펼치기」 + `aria-expanded`. `hideSidebar` 화면에는 없음.
- 접힘 상태 영속: localStorage (try/catch). 새로고침·페이지 이동 후 유지. 첫 페인트 전에 적용해 펼침→접힘 깜빡임이 없어야 함(기존 `<head>` 인라인 스크립트 패턴 참고: `lib/native/native-detect.ts`).
- 레일 모양: 아이콘만 가운데 정렬, 라벨 숨김(각 링크는 접근 이름·`title` 툴팁 유지), 트레이딩 하위목록(VI·전략) 숨김, 트레이딩 아이콘 우상단에 켜진 전략 수 배지(`--led-armed` 초록, 0이면 없음), 하단은 아바타 원만 + 테마 토글을 세로로 쌓음.
- 폭 전환 애니메이션 ~200ms. 본문(main)은 늘어난 폭을 그대로 씀.
- 사이드바 sticky 3종 묶음(app-shell.tsx 주석: aside sticky/self-start · 부모 overflow-hidden 금지 · main min-w-0) 깨지 않기.

## D2. 스크롤 헤더 = 「상단에서만 헤더」
- 적용 범위: 햄버거가 있는 화면만 — 브라우저 `<lg` + 앱(`html.native-app`, 전 폭). 브라우저 `lg+` 는 종전 그대로(헤더 고정 유지).
- 동작: 창 스크롤이 맨 위(약 8px 이내)일 때만 헤더 표시. 조금이라도 내리면 헤더 배경·로고·검색(nav slot)이 위로 빠지고(~250ms), **햄버거만** 남아 반투명 원형 배경(44px 터치 타깃 유지, `color-mix(--card 82%)` + backdrop-blur + 그림자)을 입고 뜬다. 맨 위로 돌아오면 헤더 복귀. (위로 스크롤 시 복귀 방식은 채택 안 함.)
- 원형 버튼 위치: 헤더 상태의 햄버거 자리에서 약간 안쪽(좌 8px · 위 약간) — 현행 `-ml-2` 는 폰에서 버튼 박스가 화면 끝(0px)에 붙어 원형이면 잘려 보이므로 떠 있을 때만 안쪽으로 이동.
- 숨김 중 헤더 영역은 클릭 통과(pointer-events none), 햄버거만 클릭 가능.
- 앱: 상태바 띠(`--app-safe-top`)는 흐린 배경 유지 — 본문이 시계 밑으로 비치지 않게.
- 드로어가 열려 있거나 헤더 안에 키보드 포커스가 있으면 헤더 강제 표시.
- 알림 토스트(`alert-toasts.tsx`, 헤더 아래 상단 앵커)는 위치 그대로 유지.
- 헤더 여백·잉크 불변식(`e2e/specs/home.spec.ts`, 헤더 px 램프 == main 패딩 램프, 햄버거 음수 마진)은 **헤더 보임 상태**에서 그대로여야 함.
- `prefers-reduced-motion` 이면 전환 애니메이션 생략.
