# Quick 260930-lq5 — 카드 주문로그 · 전략로그 → 버튼 + 팝업 — 결정 (locked)

시각 정본: `mockup.html` (같은 폴더, v2 · 사용자 검토 · 채택 2026-09-30). v1(전 종목 팝업)은 폐기.

## 범위
- **종목 카드(`card/card-tabs.tsx`)만** 바꾼다. 작업대 하단 공용 패널(`workbench/shared-panels.tsx`)의 「주문로그」 · 「전략 로그」 탭은 **지금 그대로 둔다** (사용자 결정).
- 창 분리 페이지(`/trading/order-log`)와 `/me` 는 건드리지 않는다.

## D1. 진입 = 카드 탭 줄 오른쪽 버튼 두 개 (목업 ①)
- 카드 탭은 「정보 · 미체결 N · 잔고 N」 셋만 남는다. `주문로그` · `전략로그` 탭(값 `orderlog` · `log`)은 탭에서 빠진다.
- 탭 줄 오른쪽(접기 버튼 바로 앞)에 작은 outline 버튼 「주문로그」 · 「전략로그」. 주문로그 버튼에는 **안 본 동안 새로 온 줄 수** 배지(primary 원, 0 이면 없음) — 지금 탭 괄호 숫자와 같은 뜻. 「가려짐」 = 팝업이 닫혀 있음. 팝업을 열면 0. 전략로그 버튼은 배지 없음.
- 접근성 이름: 배지 N>0 이면 「주문로그, 새 로그 N건」(기존 문구 재사용).

## D2. 팝업 = 가운데 다이얼로그(shadcn `Dialog`), 한 종목 전용
- 범위 = 그 카드의 종목 · 거래소 · 카드 계좌 (기존 카드 탭 `inScope` 범위 그대로). 새 조회 경로 0 — 작업대 공용 피드 · 카드 훅 로그 그대로.
- 제목: `[주문로그|전략로그 알약] 종목명 거래소` — **종목명 · 거래소만**. 코드 · 계좌 · 날짜는 표시하지 않음.
- 폭 최대 ~880px, 높이 화면 대부분(약 80vh), 머리 고정 · 본문만 스크롤. 닫기 X.
- **위 → 아래 = 시간 흐름(오래된 줄 위)**, 열면 맨 아래(최신)로 스크롤. 새로 온 줄은 왼쪽 primary 선(기존 `newKeys` 3초 강조).

## D3. 주문로그 팝업 = 변형 A (시간순 한 줄 목록 표)
- 제목 아래 **오늘 요약 한 줄**: 주문 N · 체결 N · 거부 N(빨강) · 취소 N · 누적 N (범위 안 이벤트에서 kind 로 셈 — 주문=매수/매도 주문 kind, 체결=첫 체결, 거부, 취소; 누적 = 마지막 행 cumVolume).
- 필터 = 구분 하나(전체 · 매수 · 매도 · 시세) — 기존 `OrderLogFilters` 의 kind 축 값 재사용. 종목 · 거래소 필터 없음. 오른쪽에 건수.
- 머리의 「창 분리」 아이콘 유지 — 기존 창 분리 URL 에 그 종목 · 거래소 · 계좌 · 구분 필터를 실어 연다.
- 표 열: **시각 · 주문번호 · 구분 · 행위 · 내용 · 누적(우측 정렬)**. 종목 · 거래소 칸 없음.
  - 시각 = `formatKstMs`(HH:MM:SS.mmm), muted.
  - **주문번호 = 뒤 4자리만** (예 `0000012451` → `2451`). 시세 이벤트는 빈 칸, 번호가 빈 주문 이벤트는 `—`.
  - 구분 = 배지(tone: 매수 `--up-bg/--up` · 매도 `--down-bg/--down` · 시세 `--accent/--accent-fg` · 모름 muted).
  - 행위 = 600, 거부면 `--destructive`.
  - 내용 = 줄바꿈 허용(잘림 없음). 문장 조각은 `strategyEventParts` 출력 그대로 — 문장을 새로 짓지 않는다(D-09).
  - 거부 행 = 줄 배경 옅은 빨강(`--up-bg` 기반) + 내용 빨강.
- 상태: 로딩 · 실패(다시 시도) · 빈 상태는 기존 `OrderLogList` 규약 문구 재사용.

## D4. 전략로그 팝업
- 같은 틀. 열 = **시각 · 내용** 둘. 오류(level error) 행 = 옅은 빨강 배경 + 빨강 글자.
- 필터 = 「전체 · 오류만」 세그먼트 + 건수.
- 순서 = 위 → 아래 시간 흐름, 열면 맨 아래. (카드 로그 배열이 최신 index 0 이면 뒤집어서 그림.)

## D5. 폰 폭 (`@container/lc` 가 아니라 다이얼로그 자체 — 뷰포트 < 640 정도)
- 다이얼로그가 전체 화면. 표 대신 **두 줄 행**: 1줄 = 시각(초까지) · 구분 배지 · 행위 · 주문번호 4자리 · 오른쪽 `누적 N` / 2줄 = 내용 전체. 전략로그는 1줄 시각 / 2줄 내용.
- 기존 폰 밴드 줄 펼침(탭 펼침) 동작은 팝업에서는 불필요(내용이 이미 전부 보임).

## D6. 알림 탭 요청 통로
- 토스트 클릭(VI · 돌파)이 요청하던 `"log"` 탭은 없어진다 → `alertTabFor` 는 그 경우 `"info"` 를 돌려준다(팝업을 자동으로 열지 않는다). `CardTab` 유니온에서 `orderlog` · `log` 제거, 저장된 값 가드가 있으면 알 수 없는 값은 `info`.
