`scripts/dma-tunnel.sh` 를 새로 만든다. `#!/usr/bin/env bash` + `set -uo pipefail` (개별 점검 항목을 끝까지 추적해야 하므로 `-e` 는 켜지 않는다 — smoke-relay.sh 와 같은 이유). 만든 뒤 `chmod +x`.

시작 전에 `git hash-object scripts/smoke-relay.sh` 를 찍어 두고 Task 3 끝에서 같은 값인지 확인한다. **`scripts/smoke-relay.sh` 는 다른 세션이 수정 중이므로 열어서 쓰지 않는다.**

**헤더 주석 박스** — `═` 라인으로 감싸고 목적·사용법·왜 이 구조인지를 적는다. 반드시 담을 것: ① 이 터널 너머는 **실계좌가 걸린 실 게이트웨이**이며 스크립트는 TCP 도달성까지만 한다 (D-27), ② `127.0.0.1` 이 아니라 `10.41.1.120` 그대로 리슨하는 이유는 WinForms `settings.ini` 를 고치지 않기 위해서다, ③ 접근 경로가 IAP 뿐인 이유(22 가 IAP 대역에만 열려 있음).

**인자 처리** — `--check` · `--stop` · `--verbose` 세 개만. 조합 가능(`--check --verbose`). 그 외 인자는 `usage: bash scripts/dma-tunnel.sh [--check|--stop] [--verbose]` 를 stderr 로 찍고 `exit 1` (deploy-relay.sh 관용구).

**실계좌 경고 배너** — `--stop` 을 제외한 모든 경로에서 **가장 먼저** 출력한다. 게이트웨이 주소·"로그인/주문 프레임을 보내지 않는다"·`D-27` 근거를 담고 시각적으로 눈에 띄게(`🚨` + 박스) 찍는다.

**선행 점검** — `<interfaces>` 의 P1~P7 을 각각 독립 함수로 구현하고 `check()`/`skip()`/`summary()` 로 보고한다. `--check` 는 전 항목 평가 후 요약, 정상 실행은 첫 하드 실패에서 중단. P5 는 `curl -sf --max-time 10 "$HEALTH_URL"` 응답에서 `"vpn":true` 를 grep 한다.

**로컬 VPN 충돌 감지** — `ifconfig -a` 를 인터페이스 단위로 파싱해 `10.41.1.` 로 시작하는 inet 주소를 인터페이스명과 함께 모은다. `lo0` + `10.41.1.120` 조합만 우리 것으로 간주하고 나머지가 있으면 exit 3. 관측된 인터페이스·주소를 메시지에 그대로 찍는다(사용자가 무엇 때문에 막혔는지 알아야 한다).

**별칭 추가 (멱등)** — `ifconfig lo0 | grep '10.41.1.120'` 이 이미 있으면 추가하지 않고 `ALIAS_ADDED=0` 으로 기록(=우리가 만들지 않았으므로 정리 때 지우지 않는다… 단, netmask 가 `0xffffffff` 인 lo0 별칭은 구조적으로 우리 잔여물이므로 이 경우는 `ALIAS_ADDED=1` 로 이어받아 정리 대상에 포함한다. 판단 근거를 주석으로 남긴다). 없으면 `sudo ifconfig lo0 alias 10.41.1.120 255.255.255.255` 로 추가하고 `ALIAS_ADDED=1` 기록. 추가 후 실재를 재확인하고, 실패하면 exit 4.

**터널 기동** — `gcloud compute ssh radar-gw --tunnel-through-iap --zone=asia-northeast3-a --project=gh-radar -- -N -L 10.41.1.120:9100:10.41.1.120:9100 -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=3` 를 백그라운드로 띄우고 PID 를 상태 파일에 기록. `-f` 는 쓰지 않는다 — 데몬화하면 PID 추적과 정리가 불가능해진다. 기본은 stderr 를 로그 파일로, `--verbose` 면 콘솔로 흘린다.

**도달성 확인** — 터널 기동 후 최대 15초 동안 `nc -z -w3 10.41.1.120 9100` 을 폴링해 성공하면 「연결됨」을 찍는다. **여기서 끝이다 — 어떤 프레임도 쓰지 않는다.** 성공 시 사용자에게 "이제 WinForms 를 설정 변경 없이 실행하면 된다"를 안내하고 `Ctrl+C` 로 종료하라고 알린다.
