# 260913-0em — 헤더 아이콘 잉크를 본문 여백선에 맞춘다

## 무엇이 문제인가 (사용자 신고 + 실측)

사용자: 「본문 좌우 여백과 헤더 좌우여백이 다른데?」 (뷰포트 ~1004 스크린샷)

**패딩 박스는 이미 정확히 같다.** 260912-u58 이 맞춰 놓은 `p-2 md:p-4 lg:p-6` / `px-2 md:px-4 lg:px-6`
는 모든 폭에서 일치한다(실측: 390·767 → 8/8, 768~1023 → 16/16, 1024↑ → 24/24, 박스 좌우 끝까지 동일).

어긋나 보이는 것은 **보이는 잉크**다. 헤더의 좌우 끝 컨트롤이 44×44 터치 타깃 안에 20px 아이콘을
가운데 둔 아이콘 버튼이라, 버튼 상자는 여백선에 붙어 있어도 **아이콘은 12px 안쪽**에서 시작한다.
본문 카드는 테두리가 여백선에 딱 붙으므로 둘이 12px 어긋나 보인다.

실측(뷰포트 1004):

| 대상 | 좌표 |
|---|---|
| 본문 `h1`(상따) · `lc-stock-card` 왼쪽 | **16** |
| 햄버거 **버튼** 왼쪽 | 16 (박스는 맞다) |
| 햄버거 **아이콘 잉크** 왼쪽 | **28** ← 12px 안쪽 |
| 로고 `gh-radar` 왼쪽 | 68 |
| 본문 카드 오른쪽 | **988** |
| 검색 아이콘 잉크 오른쪽 | **976** ← 12px 모자람 |

## 고치는 법 (브라우저에서 CSS 주입으로 **검증 완료**)

좌우 끝 아이콘 버튼을 잉크 기준으로 바깥으로 당긴다. **터치 타깃(44×44)은 그대로 두고 음수 마진만** 쓴다.

- `webapp/src/components/layout/app-header.tsx` — 햄버거 버튼(`aria-label="사이드바 열기"`, `lg:hidden`)에
  `-ml-2 md:-ml-3` 추가.
- `webapp/src/components/search/search-trigger.tsx` — **모바일 아이콘 버튼**(`lg:hidden`, 두 번째 `<button>`)에
  `-mr-2 md:-mr-3` 추가. **데스크톱 readonly input 버튼(`lg:flex`)은 건드리지 마라** — 그것은 헤더 가운데에
  있고 여백선과 무관하다.
- `app-header.tsx` 의 `themeToggle` 블록(`<div className="flex items-center gap-2">`)도 그 화면에서는
  **오른쪽 끝 컨트롤**이다. 같은 이유로 `-mr-2 md:-mr-3` 을 그 래퍼에 준다. `ThemeToggle` 컴포넌트 자체는
  고치지 마라 — 사이드바 하단에서도 쓰이고 거기서는 이 보정이 틀린다. 호출부에서만 준다
  (그 컴포넌트의 `className` 은 「크기·여백만 덮어쓰라고 있는 구멍」이라고 주석이 말한다).

### 왜 폰에서는 12 가 아니라 8 인가 (실측 근거)

12px 을 그대로 쓰면 폰(패딩 8)에서 **오른쪽 버튼이 뷰포트 밖으로 4px 나가 가로 스크롤이 생긴다**
(왼쪽은 음수 오버플로가 스크롤을 만들지 않아 안전하지만, 오른쪽은 만든다). 그래서 폰 구간은 8 까지만
당긴다 — 좌우가 **대칭으로 4px 안쪽**에 서고, 지금의 12px 어긋남보다 3배 낫다. `md`(768) 부터는 패딩이
16 이라 12 를 다 당겨도 안전하고 **정확히 일치**한다.

CSS 주입으로 흉내내 실측한 결과(수정 후 예상값):

| 폭 | 본문 좌/우 | 헤더 잉크 좌/우 | scrollW/clientW |
|---|---|---|---|
| 390 | 8 / 382 | 12 / 378 | 390 / 390 |
| 768 | 16 / 752 | **16 / 752** | 768 / 768 |
| 1004 | 16 / 988 | **16 / 988** | 1004 / 1004 |
| 1023 | 16 / 1007 | **16 / 1007** | 1023 / 1023 |

## 주석

두 파일 모두 **왜 음수 마진인지**를 주석으로 남겨라. 다음 사람이 「패딩이 안 맞네」라고 읽고 패딩을
고치면 박스가 어긋난다 — 박스는 맞아 있고 보정 대상은 잉크라는 사실, 그리고 폰에서 8 인 이유(오른쪽
오버플로)를 적어라. 44×44 를 줄여서 맞추지 말라는 금지도 함께.
