# 260913-g4c — KRX 애프터마켓(2026-09-14 월 시행) 대응: 급등 탐색 20:00 연장 · 홈 테마 1분 · 자동 새로고침

## 배경

KRX 가 **2026-09-14(월)부터 16:00~20:00 애프터마켓(연속매매, 가격제한폭 전일종가 ±30% 동일)** 을 연다. 지금 gh-radar 는 15시대까지만 시세·급등 테마를 갱신하므로, 저녁 4시간 동안 상승률 상위(`/scanner`)와 홈(`/`)이 멈춘다. **월요일 16:00 전 배포**가 목표다.

## 사용자 결정 (잠김 — 그대로 구현)

- **사용자 결정 1:** home-sync 는 **전면 1분**이다. Claude(Haiku) 호출도 매분 허용한다(비용 증가 수용). 단 나중에 "목록/등락률 1분 + AI 재분류 N분 쿨다운" 으로 나눌 수 있도록 **호출 게이트를 한 곳에 모으는 정도의 확장 여지만** 둔다. 과설계 금지(쿨다운 로직·죽은 config knob 추가 금지).
- **사용자 결정 2:** 16:00~20:00 저녁에도 intraday-sync·home-sync **둘 다** 실행한다.
- **사용자 결정 3:** 월요일 16:05 이후 키움 애프터마켓 반영 실측은 **배포 후 오케스트레이터(Claude)가 직접** 한다. 이 플랜의 실행 범위가 아니다. SUMMARY 의 후속 확인 항목으로만 기록한다(키움은 Static IP 화이트리스트라 로컬 호출 불가 → stock_quotes/top_movers DB + Cloud Logging + 공개 시세 대조).

## 재량 판단 (근거 포함)

1. **thinning 은 RPC 마이그레이션 없이 워커 JS 로 한다.** PostgREST 필터로는 "분 % 5" 를 표현할 수 없다. 그렇다고 RPC 를 쓰면 프로덕션 `supabase db push` 단계가 추가되는데, 과거 quick 들은 이 단계를 범위 밖으로 다뤘다(`--include-all` 함정 이력 포함). 그래서 **08:00~08:09 사이클에서만**(최대 10회 idempotent 재시도) `trade_date < 오늘` 최신 1000행(= max_rows 이내)의 `captured_at` 을 읽는다. 분이 5의 배수가 아닌 슬롯은 100개 청크로 delete 한다. 스캔 창이 최근 ~1000행이라 하루치 실패는 다음 거래일에 자연 복구된다. 이전 이력(5분 floor·10분·:30)은 전부 5의 배수라 영향이 없다.
2. **Claude 게이트 = 이름 붙은 타입 가드 함수 1개.** knob 을 추가하지 않는다. 기본값 0 knob 은 읽는 코드가 없는 죽은 설정이 된다.
3. **server index 는 `.range` 로 2페이지를 받는다.** `supabase/config.toml` `max_rows = 1000` 이라 `.limit(1500)` 은 조용히 1000 에서 잘린다. server 테스트 mock(`server/tests/fixtures/supabase-mock.ts` `DB_MAX_ROWS`)이 이 캡을 재현하므로 회귀 테스트가 실제로 빨개진다. 두 요청 사이에 새 슬롯이 끼면 경계 행이 중복될 수 있어 `captured_at` 으로 중복을 제거한다.
4. **보조 Scheduler 이름은 `-cron-20h`.** 하나의 cron 식으로는 08:00~20:02(04) 를 표현할 수 없다.
5. **smoke-home-sync.sh 에 `--check-scheduler` 모드를 추가한다.** 주말은 KRX_HOLIDAYS 에 없다(주말은 cron 1-5 가 막는 설계). 그래서 일요일에 잡을 수동 실행하면 home-sync 가 **일요일 빈 스냅샷 행을 써서 날짜 네비를 오염**시킨다. 배포 당일(일요일) 검증은 잡을 실행하지 않는 모드로만 한다.
6. **visibility 복귀 재조회도 KST 창 게이트를 탄다.** 게이트 예외는 요구에 명시된 "수동 새로고침·초기 로드" 둘뿐이라 규칙을 한 줄로 유지한다(창 밖 자동 요청 0).
7. **슬라이더 라벨 규칙은 워커 marketStatus 경계와 같게 둔다.** 08시대 프리마켓 / 15:30~19:59 애프터마켓 / 20:00~ 마감. 과거 거래일의 15:30 슬롯도 "애프터마켓" 으로 보인다. NXT 애프터마켓 구간이라 사실과 어긋나지 않는다.
