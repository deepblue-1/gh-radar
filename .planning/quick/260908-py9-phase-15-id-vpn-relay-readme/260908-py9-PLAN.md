**Step 1 — 사전 실측 캡처(단일 SSH 왕복).** GCP 인증은 `export GOOGLE_APPLICATION_CREDENTIALS=$HOME/.config/gcloud/gh-radar-deployer.json CLOUDSDK_CORE_PROJECT=gh-radar`.
